เรื่องแรก.
ข่าวที่ใหญ่ที่สุดในสัปดาห์นี้สำหรับวงการ enterprise agent คือดีลที่ ADNOC บริษัทน้ำมันของ UAE เซ็นกับ OpenAI และ G42 เมื่อวันที่ 2 พฤศจิกายน ทำให้ ADNOC กลายเป็น energy company รายแรกของโลกที่ deploy OpenAI Frontier technology ที่สำคัญคือ GPT models จะรันบน sovereign infrastructure ของ G42 ใน UAE ไม่ใช่ public cloud ของ OpenAI โดยตรง และ ADNOC ยังอ้างว่า ChatGPT Enterprise ที่ rollout ให้พนักงานกว่า 40,000 คนมีอัตราการใช้งานเกิน 97% ซึ่งเป็นตัวเลขที่หายากในองค์กร heavy industry ขนาดใหญ่ ดีลนี้ครอบคลุม agent ใน 3 ชั้น ตั้งแต่ operational ที่ monitor wellhead และ refinery, investment ที่ช่วย capital allocation, และ commercial ที่ช่วย trading desk สำหรับคนที่สร้าง agent platform signal ที่สำคัญคือ sovereign infrastructure กำลังเป็น default ไม่ใช่ premium ของดีลระดับประเทศ model vendor ยอมแยก compute ถ้าดีลใหญ่พอ สำหรับ CFO ของบริษัทไทยที่กำลัง deploy AI pattern ที่ใช้ได้คือ ขาย chat assistant ให้พนักงานคุ้นก่อน แล้วค่อย layer agentic workflow ทีหลัง มากกว่าการ push agent ตั้งแต่ day 1 โดยที่ยังไม่คุ้นกับ AI เลย แต่ caveat คือ ADNOC ประกาศเฉพาะตัวเลข adoption กับดีล ยังไม่มี production milestone ที่บอกว่า agent ช่วยลด downtime หรือเพิ่มกำไรเท่าไหร่ รอดู 12 เดือนข้างหน้าว่าจะเปิด case study แบบที่ Klarna หรือ Target เคยทำหรือไม่.

เรื่องที่สอง.
Traversal startup ที่สร้าง AI agent สำหรับ site reliability engineering ปิด Series B 120 ล้านเหรียญที่ valuation 1 พันล้านเหรียญ นำโดย Kleiner Perkins, Redpoint, และ Khosla ร่วมกับ Sequoia และ Battery รอบนี้ใหญ่ประมาณ 2.5 เท่าของรอบก่อน ก่อนหน้านี้ Amex Ventures เคยลงทุน strategic ในเดือนมีนาคม Product ของ Traversal ประกอบด้วย 2 ชิ้น หนึ่งคือ Traversal Workers ที่เป็น long-running agent ซึ่ง subscribe กับ alert system เมื่อ incident เกิดก็เริ่ม investigate ทันที ไล่ logs, traces, deployment history เพื่อหา root cause สองคือ Traversal MCP ที่ป้อน production intelligence กลับไปยัง coding agent เช่น Claude Code หรือ Cursor เพื่อให้ engineer เขียนโค้ดบน context ที่รู้ว่า production เป็นอย่างไรจริง ตัวเลขที่น่าสนใจคือ ORCA-bench ที่ Traversal co-publish กับ Cornell Tech และ Columbia — frontier agent 5 ตัวทำได้สูงสุดแค่ 25% บน medium task และ 10% บน hard task ชี้ว่า general coding agent ยังไม่พอ ต้องมี vertical agent สำหรับ ops โดยเฉพาะ สำหรับ builder signal ชัดเจนว่า MCP ของ production system กำลังกลายเป็น product surface ไม่ใช่ internal tool สำหรับ CIO ไทยที่มีทีม on-call engineer 20+ คน Traversal กับคู่แข่งเป็น default ที่ต้อง evaluate ภายในปี 2027 ROI argument คำนวนง่าย — 1 night shift senior engineer 1-2 พันเหรียญ ลด mean time to resolution จาก 5 ชั่วโมงเหลือ 35 นาที คุ้มในระยะเวลาไม่ถึงปี.

เรื่องที่สาม.
Firmly startup ที่ทำ infrastructure สำหรับ agentic commerce ปิด Series A 15 ล้านเหรียญเมื่อวันที่ 5 พฤศจิกายน พร้อมเปิดตัว product ใหม่ชื่อ Ask Agent lead investor คือ Squarepoint Capital ส่วน J.P. Morgan Payments, Mastercard, และ Samsung NEXT ร่วมด้วย ที่น่าสนใจคือ Mastercard ไม่ได้เป็นแค่นักลงทุน แต่ใช้ Firmly เป็น merchant catalog และ cart layer สำหรับ product ของตัวเองชื่อ Agent Connect Ask Agent คือ chatbox ที่ merchant embed บน site ของตัวเอง ด้วย JavaScript 1 บรรทัด ลูกค้าพิมพ์ว่าอยากได้อะไร Ask Agent ก็ค้น แนะนำ และ checkout ให้จบใน chat Firmly อ้างว่า early deployment ได้ conversion lift สูงสุด 18% และ AOV สูงสุด 23% ตัวเลขเหล่านี้ยังเป็น company-reported ที่ตลาดต้อง verify สำหรับ merchant ไทยที่ขายผ่าน Shopify, Shopee, Lazada คำถามจริงไม่ใช่ว่า AI agent จะมาซื้อของจาก store เราไหม แต่เป็นว่าเมื่อ agent มาแน่ปี 2027 product ของเรา indexable ใน MCP catalog หรือยัง และเรา control ราคา stock promotion ที่ agent เห็นได้ไหม Agentic commerce กำลังสร้าง stack 3 ชั้นชัดเจน agent surface, agent gateway, และ merchant storefront Firmly ยืนในชั้นกลาง และคู่แข่งอย่าง Envive, Perplexity Native ก็อยู่ชั้นเดียวกัน เงิน tier 1 ไหลเข้าชั้นนี้ก่อน.

เรื่องที่สี่.
Snowflake ประกาศ always-on upgrade สำหรับ agent สองตัวของตัวเองที่ Expedition 2026 เมื่อวันที่ 3 พฤศจิกายน CoCo เป็น coding agent สำหรับ data team ส่วน CoWork เป็น personal AI work agent สำหรับ knowledge worker การ upgrade แกนกลางมี 3 ชิ้น หนึ่งคือ Async Agent API ที่ทำให้ CoWork รัน multi-step work ยาวเป็นชั่วโมงใน background user ปิด laptop ได้ และถ้า agent โดน interrupt มัน resume จากจุดที่หยุด สองคือ persistent memory ที่เก็บ context และ decision ข้ามรอบ และสามคือ CoWork Profiles ที่ให้ admin ตั้ง access และ routing rule ที่ end user ลบไม่ได้ ซึ่งเป็น governance ที่ compliance team ชอบ Snowflake ยังปล่อย AI data package 60 industry datasets พร้อม ready-to-use agent สำหรับ vertical ที่อยาก deploy เร็ว pattern ที่สำคัญคือ async บวก persistent memory บวก governance เท่ากับ agent จริง ไม่ใช่ chatbot ที่ dress up pattern นี้เริ่มเห็นใน Claude Code, Cognition Devin, OpenAI Operator และ Snowflake CoWork ปี 2027 จะเป็น norm ของ enterprise agent สำหรับคนที่สร้าง agent framework ยุคใหม่ async execution และ durable checkpointing กำลังเป็น table stake ถ้ายังสร้างแบบ request-response stateless จะเริ่มลำบาก ส่วนองค์กรที่ใช้ Snowflake อยู่แล้ว CoWork เข้าถึงง่าย แต่ต้องมี FinOps budget ชัดเจน เพราะ agent รันยาวในชั่วโมงเท่ากับ query หนักที่ CFO จะถาม.

เรื่องที่ห้า.
Walmart ประกาศเมื่อวันที่ 21 ตุลาคม เปิดบ้านให้ AI shopping agent มาซื้อของแทนลูกค้าบน Walmart.com และ Sam's Club โดย rollout customer-facing เริ่มพฤศจิกายน ประกอบด้วย 3 ชิ้น หนึ่งคือ Agent Profiles ที่ให้ลูกค้าตั้ง agent ของตัวเองพร้อม spending cap และ preference สองคือ Walmart Agent Gateway ซึ่งเป็น technical layer ที่ route request จาก agent ภายนอก เช่น ChatGPT, Comet, Gemini, Meta Muse ผ่าน Sparky AI assistant ของ Walmart ก่อนถึง catalog และ checkout และสามคือ terms of use เฉพาะ agent ที่ห้าม override intent ลูกค้า ห้ามเปลี่ยน payment method และห้ามเก็บ card data สิ่งที่ technically สำคัญคือ Agent Gateway ใช้ Model Context Protocol หรือ MCP ซึ่ง Anthropic open-source ปี 2024 การที่ Walmart ที่เป็น Fortune #1 retailer commit MCP ใน customer-facing gateway เป็น proof ว่า MCP ไม่ใช่แค่ dev tool แต่เป็น commerce protocol จริง Walmart เดินทางตรงข้ามกับ Amazon ที่ block third-party agent และฟ้อง Perplexity เมื่อปี 2025 bet ของ Walmart คือ เมื่อ agent ecosystem โต retailer ที่ agent-friendly จะได้ share จาก Amazon เพราะ agent ตัวใหม่เลือก Walmart first สำหรับ retailer ไทยอย่าง Central, CP, Big C, Makro ควรเริ่มคิดเรื่อง MCP server ของ product catalog, policy ว่า agent ซื้อได้แค่ไหน และ measurement framework ว่า sales จาก agent นับอย่างไร timeline ที่ ChatGPT shopping จะเปิดในไทยคือ 2027-28 — Walmart playbook เป็น reference ที่ใช้ได้.
