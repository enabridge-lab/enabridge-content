รอบนี้มี 5 เรื่อง เน้น Agentic AI, business use case, และ trend ที่เอามาใช้กับ OpenBridge ได้.

เรื่องแรก.
ข่าวแรกวันนี้คือเรื่อง Town สตาร์ทอัพจากซานฟรานซิสโกที่เพิ่งปิดรอบ Series B หนึ่งร้อยแปดล้านดอลลาร์ ที่ valuation ทะลุพันล้าน ห่างจากรอบก่อนหน้าแค่ 4 เดือนเท่านั้น. คนที่ก่อตั้ง Town คือ Jean-Denis Greze อดีต CTO ของ Plaid สินค้าที่เขาทำชื่อว่า Townies เป็น AI assistant ที่ไม่ได้เอาไว้ให้พนักงานแต่ละคน prompt เองเหมือน ChatGPT แต่เป็นระบบ assistant ต่อคน ที่คุยกันเองได้ข้ามแผนก. ของใหม่ที่น่าสนใจคือ shared workflow ถ้า Townie ของทีม sales เรียนรู้ข้อมูลลูกค้าใหม่ Townie ของทีม finance จะได้ข้อมูลนั้นอัตโนมัติ ไม่ต้องมี training ซ้ำ. ตัวเลขที่บริษัทเปิดเผยคือ paying customers โต 4 เท่า paying teams โต 9 เท่า ตั้งแต่กรกฎาคม. คำถามที่น่าคิดคือ shape ของ AI assistant ที่ชนะในที่ทำงานในอนาคต อาจจะไม่ใช่ chatbot เดี่ยว ๆ แต่เป็นเครือข่าย agent ที่ส่งงานต่อกันเอง เหมือนกับที่ Plaid เคยทำกับ financial data เมื่อสิบปีก่อน.

เรื่องที่สอง.
ข่าวที่สองวันนี้เรื่อง Daytona บริษัทจากโครเอเชียที่เพิ่งเป็นยูนิคอร์นลำดับที่สามของประเทศ จากการปิดรอบ Series B 60 ล้านดอลลาร์ที่ valuation พันล้าน. สินค้าที่ Daytona ทำคือ sandbox สำหรับ AI agent คือ environment แยกที่ agent เอาไว้ run code เอาไว้เรียก tool โดยไม่กระทบระบบหลัก. จุดที่ Daytona ชนะคู่แข่งคือเปิด sandbox ใหม่ได้ในเวลาแค่ 60 มิลลิวินาที เร็วกว่า AWS Lambda หลายเท่า เพราะใช้วิธี pre-load snapshot เอาไว้ก่อน. ลูกค้าของ Daytona ตอนนี้คือ Anthropic, OpenAI, Nvidia, Cursor, Cognition, Meta, Cohere ซึ่งใช้ sandbox เป็น runtime สำหรับ train และทดสอบ model. ซีอีโอบอกว่ารายได้บริษัทโต 25 เท่าตั้งแต่มกราคม. เรื่องนี้สำคัญเพราะมันบอกว่า agent มี workload แปลกใหม่ที่ hyperscaler เดิมอาจจะ serve ไม่ดีพอ ถ้าคุณสร้าง agent ที่ parallelize งานหลาย task ย่อย คุณต้องเริ่มคุ้นกับ vocabulary ใหม่ของ agent-native compute.

เรื่องที่สาม.
ข่าวที่สามวันนี้เป็นเรื่อง Claude Duet แอปใหม่ที่ Anthropic เพิ่งเปิดตัวเมื่อวันพุธที่ 21 ตุลาคม เป็น research preview สำหรับ Pro และ Max subscriber ที่อยู่ในอเมริกาและเข้า waitlist. จุดที่ Duet ต่างจาก Claude ปกติคือมันไม่ได้รอให้คุณถาม แต่ monitor context ของคุณเองและเริ่มพูดก่อน. ตอนเช้าจะส่ง morning brief แล้วทุก 2 ถึง 3 ชั่วโมงจะ check in ว่ามีอะไรที่คุณควรรู้ไหม. ก่อนจะทำ action จริงเช่นส่งข้อความหรือจ่ายเงิน Duet ต้องขอ confirmation จากคุณก่อน. Duet รันบน Opus 5.5 และ Anthropic เตือนเองว่าช่วงนี้ Duet ยังอาจจะตัดสินความเร่งด่วนผิดได้. เรื่องนี้สำคัญเพราะมันคือการเปลี่ยน UX pattern พื้นฐานของ AI จาก chatbot ที่รอ prompt กลายเป็น agent ที่มี clock ของตัวเอง. OpenAI, Microsoft และ Google ก็มี proactive agent ของตัวเองในตลาด platform war ของ default agent ประจำผู้ใช้คนหนึ่งเริ่มแล้ว.

เรื่องที่สี่.
ข่าวที่สี่วันนี้เรื่อง Microsoft ประกาศของใหญ่ 2 ชิ้นในวันเดียวกันเมื่อวันที่ 19 ตุลาคม ที่น่าจะเป็นจุดเปลี่ยนของการใช้ AI agent ในองค์กรใหญ่. ของแรกคือการขยาย Project Perception ให้ครอบคลุม agent ที่อยู่ภายในองค์กรเอง ไม่ใช่แค่ภัยคุกคามจากข้างนอก. ของที่สองคือ Microsoft Entra Agent ID คือ identity สำหรับ agent ที่แยกออกจาก identity ของพนักงานเจ้าของ. Hayete Gallot หัวหน้าทีม security ของ Microsoft พูดตรง ๆ ว่า frontier AI model ตอนนี้ trust ไม่ได้ และต้องมีสิ่งที่เขาเรียกว่า Guardian Agent คอยกำกับ agent อื่นตลอด 24 ชั่วโมง. การ discover agent ที่อยู่บนเครื่องพนักงานขยายจาก 35 เป็น 60 ชนิด รวม Claude Code และ GitHub Copilot ด้วย. เรื่องนี้สำคัญเพราะ Microsoft กำลัง claim บทบาท identity provider สำหรับ AI agent ในองค์กร ซึ่งคือ choke point ที่ platform ไหนก็อยากคุม สำหรับคนที่สร้าง agent ที่จะขายให้ enterprise ภายใน 2 ปีข้างหน้า ต้อง comply กับ Entra Agent ID ไม่งั้นจะไม่ผ่านด่าน procurement.

เรื่องที่ห้า.
ข่าวที่ห้าและสุดท้ายวันนี้เรื่อง Opsin สตาร์ทอัพจาก San Jose ที่เพิ่งปิด Series A 21 ล้านดอลลาร์ นำโดย SYN Ventures กับ Race Capital. Opsin สร้าง control plane สำหรับ AI agent ที่ enterprise สร้างบน Copilot, Claude, ChatGPT Enterprise และ Gemini. ลูกค้ายี่สิบรายแรกของเขารวม Culligan, Barry-Wehmiller, Wellstar Health System และ UiPath. ตัวเลขที่น่าสนใจที่ Opsin เปิดเผยจาก analysis ของลูกค้าคือ 93% ของเครื่องมือที่ agent ต่ออยู่ มี access แบบไม่จำกัด และมีเพียง 1 ใน 200 agent ที่ต้อง human approval ก่อนทำ action. ตัวเลขนี้ถ้าจริง หมายความว่าในองค์กรใหญ่หนึ่งแห่งอาจจะมี agent หลายร้อยตัวที่กำลัง act autonomous โดยไม่มีใครคุม. เรื่องนี้สำคัญเพราะเดือนตุลาคมเดือนเดียว หมวด agent governance รับเงินมากกว่า 150 ล้านดอลลาร์ จาก Opsin, Mave Security และ Microsoft เอง — pattern เดียวกับที่ SIEM เคยโตเมื่อสิบปีก่อน ตลาดกำลังตื่นว่า agent sprawl คือ enterprise risk ที่จับต้องได้.
