เรื่องแรก.
วันพุธที่ 21 ตุลาคม John Furner ซีอีโอ Walmart US ประกาศ Agent Gateway ที่งาน Masters of Scale Summit ซานฟรานซิสโก — เป็น MCP server ของ Walmart ที่เปิดให้ AI agent ที่ approved แล้ว ค้น inventory และซื้อของแทนลูกค้าทั้งใน Walmart และ Sam's Club. ตัว gateway มีสามส่วน หนึ่งคือ API สำหรับ search และ buy สองคือ Agent Profiles ที่ลูกค้าจะตั้ง spending limit ให้ agent ซื้อแบบ auto-approve หรือต้อง approve ทุก transaction. สามคือชุด 7 Agent Terms ที่ developer ต้องยอมรับก่อนเข้าใช้ รวมถึงกฎว่า agent ไม่ได้ card details และเปลี่ยน payment method ไม่ได้. agent ที่ไม่ compliant จะโดน block อัตโนมัติ. ที่น่าสนใจที่สุดคือ Walmart เลือกคนละขั้วกับ Amazon — Amazon block agent จาก amazon.com ตั้งแต่กลางปี เพราะมอง agent เป็น traffic หนีจาก Prime ecosystem. Walmart มอง agent เป็น demand channel ใหม่ที่ Amazon ไม่ยอมรับ ถ้า agent commerce โตเท่าที่ Gartner คาด 20% ของ online transaction จะผ่าน agent ภายใน 2028, Walmart ชนะ. ที่สำคัญกว่าคือ Walmart เลือก MCP ของ Anthropic เป็น protocol — ไม่ build REST API ของตัวเอง นี่คือครั้งแรกที่ retailer ระดับ Fortune 1 commit MCP เป็น commerce protocol. ถ้า Target, Costco, Best Buy ตาม MCP จะกลายเป็น de facto standard ของ agent commerce เหมือนที่ HTTPS คือ default ของ web commerce. สำหรับ builder — ถ้า agent คุณไม่พูด MCP, พลาด channel ของ retailer รายใหญ่ที่สุดในสหรัฐ และ agent identity กลายเป็น primitive แยกเลเยอร์ที่ Walmart, 1Password, ServiceNow เริ่มสร้างพร้อมกัน.

เรื่องที่สอง.
วันพุธที่ 21 ตุลาคม Microsoft ประกาศว่า Volkswagen Group deploy Copilot ให้พนักงานมากกว่า 330,000 คนทั่ว 10 กว่าแบรนด์ ตั้งแต่ Volkswagen, Audi, Porsche, Škoda ไปจน Lamborghini และ Ducati. rollout เป็น phase — เริ่มที่ Copilot Chat ที่ไม่ต้อง premium license ปัจจุบันมี 300,000 คนใช้งานต่อเดือน คิดเป็น adoption เกิน 90% ของ workforce. ขั้นที่สองคือ Copilot with Work IQ ที่เป็นเลเยอร์ premium มี RAG และ agent builder และ Microsoft บอกว่ามี 26,000 agent live ในเดือนที่ผ่านมา กระจายไป engineering, production, procurement, sales. แต่ Caveat สำคัญคือ Microsoft ไม่เปิด license count, ไม่เปิด ROI, ไม่เปิด cost saved — ทุก announcement ของ hyperscaler ตอนนี้มี pattern เดียวกันคือจำนวนคนบวกจำนวน agent แต่ไม่มีเงินที่ประหยัด เพราะเลขเหล่านี้ยังวัดไม่ครบ steady state และถ้าเปิดจะทำให้คู่แข่งคำนวณ cost per output ของ Copilot ได้. ที่สำคัญกว่าคือ VW ประกาศวันเดียวกันว่าเตรียม job cut หลักหมื่น ไม่มีหลักฐาน causal link แต่ narrative AI เท่ากับ productivity บวก headcount reduction กลายเป็น template ของ enterprise rollout ที่ CEO Fortune 100 รายอื่นต้องเตรียมตอบ. สำหรับทีมที่ build agent — Work IQ กลายเป็น agent factory ของ enterprise ถ้า framework คุณไม่ interop กับ Copilot Studio จะโดนตัดจาก default option. สำหรับ CIO manufacturing — บทเรียนคือ phased chat-first premium-later ไม่ใช่ roll premium ตรง 100% ตั้งแต่ day 1 เพราะ waste. และสำหรับ observability vendor อย่าง Opsin หรือ Arena — ตลาด 26,000 agent ที่ไม่มีใครรู้ว่าทำอะไรเป็น tailwind ชัดเจน.

เรื่องที่สาม.
วันพุธที่ 21 ตุลาคม ที่งาน NVIDIA GTC Berlin ServiceNow ประกาศ Arc GA — personal enterprise agent ที่รันบน Mac แล้ววันนี้ Windows ตามภายในไม่กี่สัปดาห์ รวมในทุก SKU ของ EmployeeWorks ไม่คิดเงินเพิ่ม Arc ทำงานผ่านสามเลเยอร์ หนึ่งคือ agent execution ที่รับ goal แล้ว plan execute self-check ปรับ ถ้า integration ยังไม่มี Arc build on the fly รันในขอบเขตของ NVIDIA OpenShell. สองคือ Super Intelligence Control Tower ที่ CIO ตั้ง rule ว่า agent ทำอะไรได้บ้าง และ OpenShell รับ rule นั้นมา enforce ที่ runtime monitor action vet permission ตรวจ prompt injection วัด performance. สามคือ AI Passport credential ที่ ServiceNow ออกให้ agent และ NVIDIA BlueField DPU อ่านได้เพื่อ validate ที่ silicon layer ตรงนี้ sources ยังไม่ตรงกัน Investing บอกว่า live แล้ว Shashi กับ StockTitan บอกยัง roadmap ตีความแบบ conservative คือ spec live แต่ hardware enforcement ยังไม่. สองสัญญาณสำคัญคือ ServiceNow bundle Arc ลง base SKU ไม่คิดเงินเพิ่ม = narrative ว่า agent เป็น platform feature ไม่ใช่ product แปลว่า pricing ของ agent runtime กำลัง race to zero เงินจะไปอยู่ที่ domain context กับ workflow data ไม่ใช่ที่ agent builder. และสองคือ AI Passport กับ BlueField ดัน identity ของ agent ลงไปที่ silicon ชนกับ AWS AgentCore และ Google Titanium IPU — สงคราม silicon ของ agent compute เริ่มแล้วบนเลเยอร์ที่ลูกค้ามองไม่เห็น. สำหรับ builder ต้อง compatible กับ 3 identity standards พร้อมกัน และ identity adapter เป็นช่องตลาดที่ยังว่าง สำหรับ CIO ที่ใช้ ServiceNow อยู่แล้วคำถามไม่ใช่ซื้อ agent platform ไหมแต่คือใช้ Arc เป็น default แล้วเพิ่ม Copilot กับ Agentforce บน workflow เฉพาะหรือกลับกัน.

เรื่องที่สี่.
วันพฤหัสที่ 22 ตุลาคม 1Password เปิดตัว 1Password for Agents พร้อมประกาศ $500M ARR และบอกว่าตอนนี้ serve 85% ของ Forbes AI 50. product ตอบคำถามที่ enterprise ถาม hyperscaler ตลอดครึ่งปีที่ผ่านมา ถ้า agent ต้อง login เว็บไซต์แทนฉัน จะเก็บ password ยังไงให้ agent ไม่เห็น ไม่ cache ไม่ exfiltrate. Flow คือ user สร้าง agent policy บอกว่า agent ตัวไหนใช้ credential ไหนได้นานเท่าไร agent ตัดสินใจเองไม่ได้. agent เจอ login form ยื่น unique digital key ให้ 1Password verify ลูกค้า approve แล้ว 1Password fill password ลงฟอร์มของเว็บเป้าหมายโดยตรงไม่ส่งผ่าน agent context — agent ไม่เคยเห็น password. launch partners ที่ press ยกชื่อคือ Claude Duet, ChatGPT Work, Meta Muse, Grok Bot, Dots, Town. ที่ไม่อยู่ลิสต์คือ Google Gemini Spark และ Microsoft Scout — น่าจะเดิน identity primitive ของตัวเอง สองสัญญาณใหญ่คือ identity ของ agent กำลังแยกเป็นเลเยอร์ของตัวเองไม่ใช่ feature ของ agent runtime ตลาดเดียวกับที่ Walmart Agent Gateway กับ ServiceNow AI Passport กำลัง build. และสองคือ $500M ARR กับ 85% ของ Forbes AI 50 แปลว่า personal บวก enterprise agent สร้างความต้องการ credential management ใหม่หมด ตลาดที่ CyberArk Okta HashiCorp เคยครองต้องปรับตัว. สำหรับทีมที่ build agent — ถ้า agent ต้อง login ที่ไหน integrate 1Password for Agents คือทางเร็วที่สุดเข้า enterprise agent ที่เก็บ password เองจะโดน CISO reject ตั้งแต่ POC. สำหรับ ecosystem — Dashlane, Bitwarden, Keeper, Okta ต้องตอบใน 6 เดือน เพราะ agent vendor ไม่อยาก integrate กับ password manager 5 รายพร้อมกัน.

เรื่องที่ห้า.
วันพฤหัสที่ 22 ตุลาคม ที่งาน AGNTCon ซานโฮเซ Agentic AI Foundation ของ Linux Foundation รับ 4 โปรเจกต์ใหม่ รวมเป็น 10 โปรเจกต์แล้ว จาก 3 ตอนเปิดตัวเมื่อ ธันวาคม 2025. โปรเจกต์แรก Anthropic donate Agent Skills ซึ่งเป็น standard ที่ grow มาจาก Claude skills Anthropic อ้างว่ามี 1 ล้าน skill published และ 280 ล้าน installs AAIF รับทั้ง brand logo GitHub org และ domain agentskills.io. โปรเจกต์ที่สอง OpenAI donate Open Responses spec ของ LLM interface ที่ขยายจาก Chat Completions รองรับ async และ background execution — ก่อนหน้านี้ Chat Completions เป็น de facto มา 3 ปี Open Responses จะเป็นรอบที่สอง. โปรเจกต์ที่สาม Hugging Face donate OpenEnv สำหรับสร้าง reinforcement learning environment ตอน train agent. โปรเจกต์ที่สี่ Alibaba donate OpenSandbox runtime ที่ Qwen team ใช้ simulate production infrastructure ตอน train model คู่แข่งคือ Daytona กับ Replit แต่ OpenSandbox เป็น open-source. สองสัญญาณที่สำคัญกว่าเนื้อหาคือ Anthropic ยอมปล่อย Agent Skills brand ที่เป็น moat ของ Claude ecosystem = bet ว่า ยิ่งเป็น standard ยิ่งชนะ เพราะ skill ที่ community สร้างยังรันบน Claude ได้ดีที่สุด OpenAI logic เดียวกัน. สองคือ layer stack ของ agent consolidate เร็วมาก ปีที่แล้ว 3 โปรเจกต์ ตอนนี้ 10 น่าจะ 20 ภายใน Q2 2027 ภายในปี 2027 ความต่างระหว่าง AWS Google Microsoft Oracle จะเหลือแค่ compute data gravity กับ workflow integration — ไม่ใช่ที่ใครมี skill พิเศษ. สำหรับ builder ติดตาม spec AAIF ให้ครบ ถ้า agent คุณไม่พูด Agent Skills Open Responses MCP A2A ภายใน Q2 2027 คุณพลาด enterprise channel. สำหรับ CIO ก่อนซื้อ agent platform ให้ถาม support สี่ตัวนี้ครบไหม ถ้าไม่ครบ lock-in risk สูง สำหรับ ecosystem layer ที่ AAIF ยังว่าง identity payment observability คือ greenfield market ที่ startup ที่ donate spec ให้ AAIF ก่อนจะได้ brand default standard.
