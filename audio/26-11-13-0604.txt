เรื่องแรก.
Mercor ปิด Series D ที่ 750 ล้านเหรียญ valuation 20 พันล้านเหรียญเมื่อวันที่ 10 พฤศจิกายน เพิ่มขึ้นเป็นสองเท่าจากรอบตุลาคมปีที่แล้ว รายชื่อ investor ชี้ชัดว่าใครยังเดิมพันตลาด evaluation ของ AI Agent — Nvidia, Salesforce เข้ามาเป็น corporate investor, Benchmark และ Felicis กลับมาลง, Apollo ร่วมด้วย ตัวเลขที่สำคัญกว่า valuation คือ revenue annualized run rate ทะลุ 2 พันล้านเหรียญไปแล้วตั้งแต่กลางปี ทำให้ Scale AI และ Surge AI ต้องกลายเป็น benchmark ที่หลวมขึ้น ธุรกิจ Mercor มีสองด้าน ด้านแรกคือ matching expert วิชาชีพกับ AI lab สำหรับ post-training ด้านที่สองคือ enterprise evaluation สร้าง custom benchmark เฉพาะบริษัท ปีนี้ Mercor ซื้อ Deeptune ที่สร้าง realistic environment ของ enterprise app กว่าร้อยตัว ให้ agent ฝึกในสภาพแวดล้อมใกล้ production ซึ่งเป็น moat ที่สร้างยาก pattern ที่สำคัญคือก่อนที่ตลาด agent จะโตเต็ม infrastructure ของการวัดว่า agent ทำงานได้จริงไหมโตเร็วกว่า agent เอง CFO และ CIO ต้องการเลขที่ defendable ก่อน sign budget ให้ agent autonomous สำหรับคนที่ขาย agent platform ในไทย คำว่า custom evaluation environment ควรกลายเป็น deliverable ที่เก็บเงินแยก ไม่ใช่ freebie มันคือ defensible service ที่ commodity ยากสำหรับ system integrator.

เรื่องที่สอง.
Rox ปิด Series B 100 ล้านเหรียญที่ valuation 1.3 พันล้านเหรียญเมื่อวันที่ 11 พฤศจิกายน General Catalyst กลับมา lead อีกรอบคู่กับ March Capital, Sequoia และ GV ลงเพิ่ม, Prosperity7 เข้าเป็น investor ใหม่ Rox positioning ตัวเองไม่ใช่ CRM ที่มี AI แต่เป็น AI revenue agent ที่ทำงานตั้งแต่ prospect research จนถึง account expansion แทน sales rep ลูกค้าที่เปิดคือ Puma, Groq, และ Ramp เป็น reference ที่ target ต่างกันชัด เมื่อ Salesforce ประกาศ Agentforce Coworker 185,000 users เมื่อสัปดาห์ก่อน ตลาดคิดว่า incumbent ปิดช่องแล้ว แต่ Rox 100 ล้านที่ 1.3 พันล้านชี้ว่า investor ยังเชื่อว่ามีช่องให้ startup เพราะคำถามพื้นฐานยังไม่มีคำตอบ agent ที่ bolt-on CRM เดิมจะดีหรือแย่กว่า agent-native stack ประวัติศาสตร์ SaaS บอกว่าเมื่อ foundation technology เปลี่ยน โปรดักต์ที่ชนะมักเป็น native built ไม่ใช่ bolted-on สิ่งที่ Rox พิสูจน์คือ agent ที่ทำงาน end-to-end ของ function ใดฟังก์ชันหนึ่งได้ valuation สูงกว่า copilot ที่ช่วยทำงานบางส่วน agent-as-labor pricing ที่คิดตามผลงานจะกินตลาด seat-based ในระยะยาว สำหรับคนที่ขาย agent ในไทย เคส Rox ชี้ว่า agent ตัวหนึ่งที่ทำงานของ function ทั้งฟังก์ชันขายได้แพงกว่า assistant 10 ตัว แต่ caveat คือ Rox ยังไม่เปิด active user หรือ revenue ถ้า Q1 2027 ยังไม่โชว์ตัวเลขชัด investor จะเริ่มถาม tough question เรื่อง unit economics.

เรื่องที่สาม.
Adobe ประกาศที่งาน MAX 2026 เมื่อวันที่ 10 พฤศจิกายน Creative Suite จะรองรับ Model Context Protocol หรือ MCP external AI agent เช่น ChatGPT, Claude Desktop, หรือ Microsoft Copilot จะเข้ามาควบคุม Photoshop, Illustrator, Premiere Pro, After Effects ได้ตรง ๆ ผ่าน MCP server ที่ Adobe รัน feature จะเข้า private beta ช่วงต้นปี 2027 Demo ที่ MAX ใช้ ChatGPT เป็น client คำสั่งเดียว agent สร้าง 9 artboard ของ Photoshop ภายใน 9 นาที ทุก layer ยัง editable จุดสำคัญคือไม่ใช่ wrapper API ที่ render จาก server แต่เป็น agent ควบคุมแอป desktop จริงบน machine ของ user แก้ไฟล์ native project ไฟล์ psd, ai, prproj โดยตรง pattern ที่เห็นคือ walled garden ยอมเปิด protocol เมื่อรู้ว่า standalone agent กำลังโตจนลูกค้าจะเริ่มถามว่าทำไม connect Photoshop กับ Claude ไม่ได้ Adobe เลือก acquisition แทน resistance Adobe ที่ชนะด้วย lock-in file format ไม่สามารถชนะ AI-era ด้วย lock-in เดิมได้เพราะ agent รุ่นใหม่ transcode format ได้เร็วและ cheap มากขึ้น MCP เป็นทางเลี่ยงเดียวที่ Adobe รักษา relevance ได้ สำหรับทีม creative ขนาดเล็กได้ประโยชน์ก่อน เพราะ agent เข้ามาเร่ง task ซ้ำที่ปกติต้อง junior designer 1-2 คน สำหรับ agency ไทยที่ขาย creative service เริ่มคิดตั้งแต่ตอนนี้ว่าถ้า agent ทำ work ของ junior ได้ 70-80% ทีมต้อง reprice เป็น outcome ไม่ใช่ hour.

เรื่องที่สี่.
Bay บริษัท Israeli ที่ทำ AI agent security ออกจาก stealth เมื่อวันที่ 10 พฤศจิกายน ระดมทุนรวม 50 ล้านเหรียญ แบ่งเป็น Series A 37 ล้านเหรียญ lead โดย Battery Ventures และ seed round 13 ล้านเหรียญเก่าโดย YL Ventures และ Striker ที่ไม่เคยประกาศมาก่อน ใน Series A มีชื่อ Micron Ventures, Microsoft M12, และ Assaf Rappaport CEO ของ Wiz ร่วมลง สิ่งที่ Bay ทำคือ runtime enforcement ของ AI agent ทุก action ที่ agent เสนอจะทำ Bay evaluate ที่ context ของ session ทั้งหมด แล้วตัดสินใน millisecond ว่า allow, block, หรือ require approval policy ที่ guide การตัดสินไม่ได้เขียนด้วย human-rule แต่ build โดย AI ภายในชื่อ Lighthouse จาก activity history ขององค์กรเอง Architecture เป็น agentless ไม่ต้องติด persistent endpoint agent deploy ใน 5 นาที หมวด AI agent security หนาแน่นขึ้นปีนี้ แต่ส่วนใหญ่ทำ pre-deployment scanning Bay เป็น handful ที่ทำ runtime enforcement จริง สัญญาณสำคัญคือ Assaf Rappaport ของ Wiz ลงเงินส่วนตัวใน Bay เป็น endorsement founder-to-founder จากคนที่เพิ่งสร้าง category ใหญ่สุดของ cloud security ให้ Google ซื้อ สำหรับคนที่ deploy agent ใน enterprise ไทย คำว่า guardrail ที่คุณเขียนเองจะไม่พอ enterprise security team ต้องการ enforcement ที่ separate จาก agent process มี opportunity ให้ integrate กับ enforcement layer ตั้งแต่ design phase.

เรื่องที่ห้า.
Kindo ประกาศ Series B 30 ล้านเหรียญเมื่อวันที่ 12 พฤศจิกายน Crosspoint Capital และ Forgepoint Capital co-lead รวมทุนที่ระดมได้ทั้งหมดเป็น 57.6 ล้านเหรียญ Revenue 2026 โต 800% YoY ตัวเลขที่สูงผิดปกติสำหรับ enterprise software ที่ขาย IT security compliance แปลว่า product-market fit ของควบคุมและ monitor agent กำลัง clicking จริงจัง Kindo ขาย AI Control Center และ Deep Hat policy engine ตัวโปรดักต์ไม่ใช่ chatbot แต่เป็น backoffice dashboard ที่ IT และ finance ใช้บริหาร agent fleet ขององค์กรทั้งหมด ดูว่า agent ตัวไหนใช้ token กี่ตัว ครั้งไหน failed และ failed เพราะเหตุผลอะไร มี agent ตัวใดเข้าถึง data ที่ไม่ควร feature cost tracking include agent outcome คือ task ที่ fail ที่ปกติ hide ไว้ ปีนี้ชัดว่าก่อน agent จะโตเต็มตลาดจะมี layer ของ control และ observability เกิดก่อน เหมือน DevOps เกิดก่อน container economy สิ่งที่น่าสังเกตคือ Kindo ต่างจาก Bay ตรงที่ Bay enforce action ที่ agent เสนอจะทำ ขณะที่ Kindo monitor และ cost tracking และ policy management เห็นว่า agent ทำอะไรบ้างเทียบกับ expected behavior 2 layer นี้ complementary ไม่ compete กัน สำหรับคนที่ deploy agent ในองค์กรไทย เริ่มถามตัวเองว่าใครเป็น owner ของ agent fleet cost มักไม่มีใครเพราะ finance ไม่เข้าใจ token economy IT ไม่ cared cost security focus block อย่างเดียว บทบาท AI agent FinOps กำลังเป็นสายอาชีพใหม่ที่ pay ดีมากในปี 2027.
