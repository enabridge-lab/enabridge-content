เรื่องแรก.
วันจันทร์นี้มีข่าวใหญ่สุดสำหรับคน build บน AI ครับ Anthropic ยื่น S-1 สาธารณะกับ SEC เมื่อ 26 ตุลาคม เตรียมเข้า Nasdaq ด้วย ticker ANT คาดว่า IPO ก่อน Thanksgiving ที่ valuation หนึ่งจุดห้าถึงสองล้านล้านดอลลาร์ Revenue 12 เดือนย้อนหลังอยู่ที่สิบเก้าจุดเจ็ดพันล้านดอลลาร์ ครึ่งปีแรก 2026 แตะสิบหกจุดสามพันล้านโตจากพันล้านของปีก่อนประมาณสิบสี่เท่า ที่สำคัญกว่าตัวเลขรายได้คือ customer breakdown Anthropic มีลูกค้าสองร้อยห้าสิบรายที่ใช้ Claude เกินสิบล้านดอลลาร์ต่อปี มีพันเก้าร้อยรายที่ใช้เกินหนึ่งล้าน และหนึ่งหมื่นหนึ่งพันเก้าร้อยรายที่ใช้เกินแสนดอลลาร์ ตัวเลขหลังโตจากเก้าร้อยห้าสิบของปีก่อนราวสิบสองเท่าครึ่ง นี่คือหลักฐานว่า Claude ไม่ใช่ consumer chatbot แต่คือ enterprise agent runtime ที่มีลูกค้า tier 1 จ่าย eight digit จำนวนร้อยราย ตัวเลข compute commitment สำนักข่าวต่างคิดต่างกันตั้งแต่สองร้อยหกสิบห้าพันล้านถึงหกร้อยสามสิบเจ็ดพันล้านดอลลาร์ ความต่างคือ definition ของ commitment ยังไงก็เป็นดีลที่หนักที่สุดในประวัติศาสตร์ private tech IPO ที่น่าสังเกตคือ risk factor เขียนตรงว่า usage limit และ model capability อาจเปลี่ยนได้ทุกเมื่อ ซึ่งสอดคล้องกับการที่ Anthropic เปลี่ยน Max เป็น Ultra ปลด 5-hour limit สัปดาห์นี้ สำหรับทีมที่ build บน Claude SDK ตัวเลขนี้ตอบคำถาม CFO ว่าทำไมควรลงทุนต่อ แต่ควรระวัง concentration risk ย้อนกลับ ถ้าคุณ bet ทั้ง workflow กับ Anthropic และบริษัทเปลี่ยน policy เร็วเกินไป workflow จะกระทบครับ.

เรื่องที่สอง.
ข่าวใหญ่สองวันนี้ที่ enterprise agent builder ต้องรู้ ServiceNow เพิ่งซื้อ Sweep สตาร์ทอัพ agentic AI อิสราเอลด้วยดีลที่สื่อประเมินราวสี่ร้อยล้านดอลลาร์ ไม่มี press release ทางการ ServiceNow ปฏิเสธคอมเมนต์เรื่อง term ที่น่าสนใจคือ Sweep ไม่ใช่ CRM แต่เป็น agentic workspace ที่วางบน Salesforce HubSpot และ ServiceNow พร้อมกัน มี MCP server ของตัวเอง ลูกค้าที่เปิดชื่อคือ LG Electronics Brex NBC Sports ก่อตั้งปี 2021 ระดมได้สี่สิบหกล้านดอลลาร์ก่อน exit สิ่งที่สำคัญคือ ServiceNow เลือกซื้อ layer ที่ข้าม CRM หลายเจ้าไม่ใช่ CRM เอง นี่คือ Trojan Horse migration strategy ที่ปล่อย Sweep ทำงานบน Salesforce ของลูกค้าก่อนแล้วค่อยย้าย workflow เข้า ServiceNow ซึ่งเป็น program ที่ ServiceNow เรียกว่า Now Next CRM สนามรบของ CRM เปลี่ยนไปแล้ว Salesforce Agentforce ServiceNow CRM Microsoft Dynamics Copilot ทั้งหมดแตะ scale หนึ่งพันล้านดอลลาร์ต่อปี ปีหน้า enterprise จะเลือก CRM จากคุณภาพของ agent และ MCP ecosystem ไม่ใช่จาก UI สำหรับทีมที่ build vertical agent บน SaaS cross หลายเจ้าดีลนี้คือ playbook เริ่มจาก niche ที่ data metadata กระจัดกระจาย build MCP server เป็น primitive วัน day one มีลูกค้า tier หนึ่งสามรายคือ validation สำหรับทีมในไทยที่ run Salesforce ServiceNow HubSpot พร้อมกันควรเริ่มมองหา agent broker ไม่ใช่รอให้ vendor สร้าง feature นี้เองครับ.

เรื่องที่สาม.
สองข่าวสำคัญจาก Google ที่คน build coding agent ต้องรู้ 29 ตุลาคม Google ประกาศปิด Jules async coding agent ของ Labs 11 พฤศจิกายน sessions จะกลายเป็น read-only 31 ธันวาคม service ปิดสมบูรณ์ Google ย้าย learning ทั้งหมดเข้า Antigravity 2.0 ซึ่งคือ IDE agent platform ที่ Google เปิดตัวที่ I/O พฤษภาคมปี 2026 สร้างใหม่ 100% เป็น desktop app CLI และ SDK ที่น่าสนใจมากกว่าการปิด Jules คือ Google เปิด Antigravity Plugin Marketplace ในวันเดียวกัน launch partner คือ Atlassian Teamwork Graph CLI ซึ่งคือ MCP สำหรับ Jira Confluence Bitbucket Stripe MCP server ให้ agent query customer payment subscription ของ Stripe โดยตรง Databricks และ Unity install plugin ด้วย CLI command agy plugin install ที่เลียน npm install pip install ตรงๆ pattern ที่เห็นชัดคือ ยักษ์ใหญ่กำลัง consolidate coding agent ของตัวเองเหลือ product เดียว Google ปิด Gemini CLI มิถุนายน ปิด Jules วันนี้ GitHub ปิด Copilot Workspace OpenAI ปิด AgentKit 30 พฤศจิกายน ทุกเจ้าเหลือ coding agent 1 ตัว agent SDK 1 ตัว เพราะพื้นที่ dev relations ไม่พอดูแล 3-4 product ซ้ำกันเอง จุดที่ต้องสังเกต Google ไม่ปิด MCP ตรงกันข้าม launch partner ของ Marketplace ยืนยันว่าใช้ MCP เป็น protocol มาตรฐาน Google รับว่า A2A เป็น protocol agent คุยกับ agent MCP เป็น protocol agent คุยกับ tool สองเลเยอร์ไม่ชนกัน สำหรับทีมที่ใช้ Jules อยู่ตอนนี้ควรเริ่ม export session ทันที อย่า wait-and-see เพราะสองเดือนไม่พอ migrate workflow ของทีมใหญ่ครับ.

เรื่องที่สี่.
มีข่าวสำคัญทางด้าน security ที่คนใช้ agent ควรต้องรู้ 30 ตุลาคม Chainalysis ซึ่งเป็น vendor blockchain analytics ที่ FBI IRS FinCEN และ exchange ใหญ่หลายเจ้าใช้ ประกาศ security notice ว่าถูกเจาะด้วยสิ่งที่บริษัทเรียกว่า offensive agentic techniques นี่คือครั้งแรกที่ vendor ระดับ production grade เลือกใช้คำว่า agentic ใน post-breach disclosure ตามรายงานของ International Cyber Digest ข้อมูลที่หลุดคือ ชื่อ email role label ของ user ไม่มี password MFA secret session token และที่สำคัญสุดไม่มี investigation content ซึ่งคือเนื้อหา case ของ law enforcement ที่กำลังสืบ สิ่งที่ Chainalysis ทำหลัง detect น่าสังเกต บริษัทจ้าง third-party expert และ sophisticated LLMs มาช่วย review platform แปลว่าเราเห็น agent vs agent incident response ครั้งแรกที่ public ประเด็นสำคัญคือ 2 ปีที่ผ่านมา security researcher เตือนว่า AI agent จะเปลี่ยน attack pattern จาก manual recon ที่ใช้ชั่วโมงเป็น autonomous recon ที่ใช้วินาที Chainalysis เป็น big name vendor แรกที่ยืนยันว่าเจอของจริง ก่อนหน้านี้มี research paper tabletop exercise แต่ไม่มี vendor ยอมพูดใน notice สำหรับทีมที่ใช้ Chainalysis Reactor KYT Hexagate ควรเปลี่ยน password MFA token ของทีมที่ login บ่อย bump awareness training เรื่อง phishing ที่ใช้ email role เป็น pretext และควรประเมิน vendor อื่นที่ประเภท similar เช่น TRM Labs Elliptic Nansen เพราะอยู่ในสายตา attacker group เดียวกัน สำหรับทีม build agent ควร integrate security logging audit log ที่ record intent tool call output ตั้งแต่ day one ปี 2027 enterprise จะเริ่มถาม built-in audit ของ agent action ใน procurement vendor ที่ไม่มีจะ fail security review ครับ.
