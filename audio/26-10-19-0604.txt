รอบนี้มี 4 เรื่อง เน้น Agentic AI, business use case, และ trend ที่เอามาใช้กับ OpenBridge ได้.

เรื่องแรก.
วันเสาร์ที่ 18 ตุลา Financial Times รายงานว่า Anthropic กำลังเรียก law firm มาร่าง norm ว่า AI agent ควร negotiate แบบไหน — ต่อราคา เถียง customer service คุยเงินเดือน. โจทย์หลักสองข้อคือ agent ควร check back กับ human บ่อยแค่ไหนระหว่างปิดดีล และควรระแวง agent ฝั่งตรงข้ามแค่ไหนโดยไม่กลายเป็น paranoid. Idea หนึ่งที่คุยกันคือ signed user mandate เอกสารที่ user เซ็นให้ agent ของตัวเอง อีกฝั่งเชื่อ scope โดยไม่ต้องอ่าน prompt เต็ม — เป็น verification layer ที่ MCP กับ A2A ยังไม่ได้ handle. Context สำคัญคือ Project Deal ของ Anthropic เมษายนปีนี้ รัน 186 deal ที่ office ซานฟรานซิสโก Opus agent ชน Haiku เฉลี่ย 2.68 ดอลลาร์ต่อ item และ participant ที่ใช้ model อ่อนกว่าไม่รู้ว่าตัวเองแพ้. Pattern ที่น่าสังเกตคือ Anthropic ทำสองเรื่องพร้อมกัน runtime behavior กับ legal infrastructure และ timing ก็ไม่บังเอิญ — ก่อน IPO ที่ Bloomberg บอกจะ raise $100 พันล้าน ต้อง show governance ก่อน regulator ถาม. สำหรับทีมที่กำลังสร้าง agent framework ตัวที่ยังไม่มีใน MCP หรือ A2A คือ signed mandate layer — ใครเสนอ spec ที่ทั้ง law firm กับ framework ยอมรับก่อนจะได้ moat จริง และถ้าธุรกิจคุณจะ deploy agent ไปปิดดีลกับคู่ค้า ให้เริ่มจาก transaction ที่ reversible ก่อน อย่าเพิ่ง binding commitment.

เรื่องที่สอง.
วันพุธที่ 15 ตุลา Opsin ที่ซานโฮเซ่ ปิดรอบ 21 ล้านดอลลาร์ นำโดย SYN Ventures กับ Race Capital — ไม่เปิด valuation ไม่บอก round stage. Product คือ Risk Graph ที่ join 4 มิติ identity ของ agent purpose ที่ประกาศไว้ permission grants กับ observed activity. ถ้า agent ทำผิด purpose ระบบตัดสินได้สามชั้น restrict quarantine หรือ notify owner. ครอบคลุม Copilot Claude ChatGPT Enterprise Gemini กับ tool อื่น ๆ ที่ IT อนุมัติ. จุดที่ Opsin publish แล้วทำให้คนที่คุม security ตกใจคือ 93% ของ tool ที่ agent connect อยู่มี unrestricted access เข้าได้ทุกตัวโดยไม่มี gate และ 1 ใน 200 action เท่านั้นที่ require human approval ก่อนรัน แปลเป็นภาษาคนคือ 199 ใน 200 action ที่ agent ทำใน production enterprise ไม่มีมนุษย์ขั้น. Customer confirm 20 เจ้ารวม Culligan Barry-Wehmiller Wellstar กับ UiPath. UiPath น่าสังเกตมากที่สุดเพราะเป็น vendor automation ที่มี agent runtime เองแต่ยัง outsource security layer ให้ Opsin — confirm ว่า agent security ไม่ใช่ feature ของ runtime มันคือ layer แยกที่ต้อง vendor-neutral. Pattern ที่ emerg คือ agent sprawl กลายเป็น shadow IT รุ่นใหม่ Reco $55M ก.ย. Opsin $21M ต.ค. ตามหลัง Anthropic กับ CrowdStrike ที่ build in-house. ข้อเสนอสำหรับทีมที่ใช้ Copilot หรือ Claude ใน production คำถามแรกที่ CISO ควรถามคือ agent ของเรา connect ไปที่ไหนบ้าง ถ้าตอบไม่ได้ภายใน 10 นาที security ยังไม่พร้อม scale.

เรื่องที่สาม.
วันศุกร์ที่ 17 ตุลา OpenCode open-source coding agent ของบริษัท Anomaly Innovations ที่เพิ่งรีแบรนด์จากชื่อ SST disclose breach — กระทบประมาณ 1.4% ของ Console user ที่ store API key ของ OpenAI Anthropic กับ Google เข้าไป. จุดเข้าของ attacker ไม่ใช่ zero-day — มันคือ legacy system ที่บริษัทเองวางแผนจะปลดระวางอยู่แล้ว เป็น pattern เดียวกับ Equifax 2017 ของเก่าที่ยังเปิดอยู่คือ attack surface ที่โดนเจอก่อนของใหม่. OpenCode framing เป็น large-scale distillation attack คือมีคนขโมย key เพื่อยิง request รีด output ของ frontier model ไป train model ของตัวเอง — เศรษฐศาสตร์ของ attack ชัดเจน Opus call ราคา 1-10 เซ็นต์ แต่ output ที่เอาไป fine-tune ขายต่อได้มาก. User บางคนรายงาน Anthropic charge 400 ดอลลาร์ที่ไม่รู้จักหลัง breach ตัวเลขยัง unverified. Context: ก.พ. ที่ผ่านมา Anthropic เอง publish ว่า identify fraudulent account 24,000 บัญชีที่เปิดเพื่อ distillation — attack class นี้ไม่ใช่ของใหม่ มันแค่ย้าย target จาก account signup มา dev tool แทน. Pattern สำคัญคือ defense perimeter ของ frontier model ไม่ใช่ API เอง แต่คือ wallet ของ developer หลายล้านคนที่ store key ไว้ใน SaaS หลายสิบตัว ตัว weakest link decide ว่า distillation ทำง่ายแค่ไหน — OpenCode คือตัวอย่างสัปดาห์นี้. Action rotate key ทันที ตั้ง spend cap ที่ provider dashboard ใช้ project-scoped key ไม่ใช่ org-level ตรวจ usage log รายสัปดาห์ ไม่ใช่รายไตรมาส.

เรื่องที่สี่.
วันเสาร์ที่ 18 ตุลา Anthropic ประกาศแผนแบ่ง 5% ของ shares เข้า Anthropic Public Benefit Fund ใหม่ Bloomberg เป็น primary source. ยังไม่ binding — ต้องรอ stockholder approval ก่อน. Structure ที่น่าสังเกตคือ ตั้งเป็น LLC ที่ Anthropic owns 100% ไม่ใช่ nonprofit แยกตัว แปลว่าควบคุม fund เองในฐานะ owner แค่กันเงินกับกำหนด purpose. และมี scaling clause ที่สำคัญ board มี discretion เพิ่มอีก 2% ทุกครั้ง valuation เพิ่ม 50% เหนือ threshold. Scope ของ fund คือการกุศลภายนอก safety work biomedical research Claude discount สำหรับ nonprofit ยังอยู่ inside the company ไม่ใช้เงินจาก fund. Fund เอาไว้สำหรับ donation ก้อนใหญ่กับ direct cash distribution ให้ประชากรที่โดน impact จาก AI ตัวอย่างที่ Anthropic อ้างคือ labor-market work ที่ commit 200 ล้านดอลลาร์ไว้แล้ว. Constraint สำคัญ shares ที่ fund ถือห้ามใช้ lobbying หรือ political donation. Timing ไม่ใช่บังเอิญ — Bloomberg บอก Anthropic เตรียม IPO ที่อาจ raise $100 พันล้าน valuation แตะ $2 ล้านล้าน. ประเมิน 5% ที่ IPO $2T = $100 พันล้าน ถ้า scaling clause trigger 3 รอบไปถึง 11% ที่ $8T = $880 พันล้าน ใหญ่กว่า endowment ของ Harvard 17 เท่า. จุดที่ differ จาก Patagonia คือ Anthropic retain control ไม่ใช่ transfer จริง — ไม่ใช่ scam แต่เป็น pragmatic pre-IPO Delaware PBC. Big picture วันเดียวกันเราเห็น Anthropic consult law firm เรื่อง agent negotiation กับ Microsoft ถอน Nscale UK deal — Anthropic กำลัง stage pre-IPO narrative หลายชั้นพร้อมกัน governance ความพร้อมด้าน legal ของ agentic product และ public-benefit positioning.
