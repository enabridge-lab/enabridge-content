เรื่องแรก.
วันที่ 13 พฤศจิกายน LangChain ประกาศ Series C สามร้อยล้านเหรียญ ที่ valuation สามพันล้านเหรียญ นำโดย CapitalG ซึ่งเป็น venture arm ของ Google round นี้สูงกว่า Series B ปีก่อนถึง 2.4 เท่า แต่ตัวเลขที่สำคัญกว่าคือ LangSmith ซึ่งเป็น paid platform สำหรับ observability และ evaluation ของ agent มีลูกค้าจ่ายเงิน 7,000 ราย นี่คือสิ่งที่ CapitalG ซื้อ ไม่ใช่ download count ของ open source framework Pitch ของ LangChain คือ neutral layer ที่ enterprise ใช้ร้อยกับ OpenAI, Anthropic, Google, และ open source models โดยไม่ต้อง commit vendor เดียว timing ตรงกับที่ Gartner บอก Fortune 500 ใช้ LLM vendor เฉลี่ย 2.7 ราย และ CFO เริ่มกังวล vendor lock-in สำหรับ builder ที่สร้าง agent framework ตอนนี้ capital bar สูงขึ้นแล้ว LangChain จะใช้เงินไป GTM และ eval infrastructure ซึ่ง open source maintain ยาก framework ตัวเล็กควรเลือก vertical เช่น coding agent หรือ sales agent แทนที่จะแข่งแบบ horizontal สำหรับ CTO ที่กำลัง evaluate agent stack ตอนนี้มี market signal แล้วว่า neutral middleware คือ valid bet valuation สามพันล้าน = commitment ว่า LangChain จะอยู่ต่ออีก 5 ถึง 10 ปี caveat คือตัวเลข 7,000 customers ไม่มี breakdown ระหว่าง freemium กับ paid และ Google ซึ่งลงเงินมี ADK ของตัวเอง ถ้า LangChain shift ให้ Gemini เป็น default จะโดน call bluff จาก OpenAI และ Anthropic ทันที.

เรื่องที่สอง.
วันที่ 12 พฤศจิกายน Anthropic ประกาศ private beta ของ self-hosted Claude Managed Agents ให้ลูกค้าเอา managed agents service ไป run ใน data center หรือ cloud ของตัวเอง ส่วนที่ย้ายคือ server, database, และ worker ที่ agent run shell กับ file tools ส่วนที่ไม่ได้ย้ายคือ model inference เอง — model call ยังออกไปข้างนอก แต่ลูกค้าเลือก endpoint ได้ว่าจะไป Anthropic, AWS Bedrock, Google Cloud, Microsoft Foundry, หรือ gateway ของตัวเอง ประเด็น gotcha ที่สำคัญคือ license clause — ถ้า Anthropic ตรวจพบ safety risk ใน software ของลูกค้า ลูกค้าต้อง act ภายใน 8 ชั่วโมง ซึ่งไม่ใช่ typical SLA ของ enterprise ที่ปกติให้ 24 ถึง 72 ชั่วโมง move นี้ตอบคำถามที่ CISO ถามมาทั้งปี — agent ของเรา handle PII และ internal code ทำไมต้อง run บน server ของคุณ เทียบกับ competitor OpenAI ยังไม่มี self-hosted path, Google มีแต่ tightly coupled กับ Google Cloud, Microsoft Copilot Studio ให้ run ใน tenant แต่ไม่ให้ offline — Anthropic เปิด box ที่สุดในกลุ่ม frontier lab ตอนนี้ สำหรับ builder ที่ขายเข้า regulated industry อย่างธนาคารหรือ healthcare การที่ Claude run self-hosted ได้ ทำให้มันเป็น option ที่ customer ที่ก่อนหน้านี้ reject SaaS only AI พิจารณาใหม่ได้ สำหรับ CIO ธนาคารไทยตอนนี้มี path ที่ชัด system integrator หรือ platform อย่าง Enabridge offer managed deployment ของ Claude Managed Agents บน private cloud ลูกค้า ไม่ต้องรอ Anthropic มีออฟฟิศ APAC สิ่งที่ต้องถามคือใครรับผิดชอบ safety monitoring และ 8 ชั่วโมงเริ่มนับจากตอนไหน.

เรื่องที่สาม.
วันที่ 10 พฤศจิกายน Mercor ประกาศ Series D เจ็ดร้อยห้าสิบล้านเหรียญ ที่ valuation สองหมื่นล้านเหรียญ มี NVIDIA และ Salesforce ร่วมลงทุน valuation สูงขึ้น 2 เท่าจากตุลาคมปีก่อนใน 13 เดือน business เดิมของ Mercor คือ staffing domain expert แพทย์ นักกฎหมาย นักฟิสิกส์ SWE senior มา label และ grade output ของ frontier model ให้ OpenAI, Anthropic, Google, Meta ที่เป็น 4 ลูกค้ารายใหญ่สุด CEO บอกว่า run rate ถึง 3 พันล้านเหรียญ ถ้าเป็นจริงจะเป็น labeling company ที่ scale เร็วที่สุดในประวัติศาสตร์ ส่วนที่น่าสนใจกว่าคือ pivot ไปที่ enterprise evaluations — service ที่ Fortune 500 ซื้อเพื่อ eval agent ของตัวเองก่อน deploy production Mercor จะส่ง domain expert เข้าไปใช้ agent grade output และสร้าง eval harness เฉพาะ workflow ลูกค้า round นี้ settle thesis ที่ debate กันทั้งปีว่า AI moat อยู่ที่ model หรือ data Mercor ตอบว่า judgment ของ expert คือ data ที่ unique ที่สุด และ enterprise จะจ่าย premium เพื่อ eval harness ที่สะท้อน business logic จริง ไม่ใช่ benchmark public สำหรับ builder ถ้า agent คุณ deploy ให้ enterprise ใน vertical ที่ต้อง expert judgment การมี eval harness ที่ validated โดย domain expert กลายเป็น table stake ไม่ใช่ premium NVIDIA ลงทุนเพราะกำลัง build full stack จาก GPU ไป agent platform Salesforce เข้าเพราะ Agentforce Coworker ที่ 185,000 users ต้อง eval infrastructure ของตัวเอง caveat คือ 3 พันล้าน run rate เป็น CEO claim ไม่ใช่ audited และ expert staffing margin บางกว่า SaaS.

เรื่องที่สี่.
วันที่ 10 พฤศจิกายน IBM และ Microsoft ประกาศ Imagine Enterprise — platform สำหรับ regulated industry ที่ financial services, insurance, และ retail เป็น 3 industry แรก ตัวเลข headline คือ 6,000 pre-built AI agents และ assets แต่ต้องระวัง framing คำว่า assets รวม templates, documented workflows, SOP extracts และ consulting artifacts ที่ IBM Consulting สะสมมาหลายปี ไม่ใช่ 6,000 agent ที่ deploy แยกกันได้ ตัวเลขจริงของ standalone agent ที่ production ready น่าจะอยู่ในหลักร้อย Microsoft contribute identity และ security layer ผ่าน Entra, Purview, Defender และ Azure AI Foundry IBM contribute consulting engagement model customer buy ผ่าน IBM Consulting หรือ self-service move นี้คือ IBM กลับเข้า AI platform game ด้วย positioning consulting plus compliance ไม่ใช่ model quality IBM รู้ว่า frontier model race ไม่ชนะ แต่ IBM Consulting มี 160,000 คน และสัญญากับ bank insurer government ทั่วโลก Imagine Enterprise คือ attempt monetize distribution ที่มีอยู่แล้ว เทียบกับ Agentforce Coworker ของ Salesforce ที่ขายตรง CFO เป็น seat subscription Imagine Enterprise ขายเป็น implementation engagement คิด 7 figure contract ต่อ customer ข้อสงสัยคือไม่มี independent evaluation และไม่มี customer production ที่ confirmed ชื่อ ณ วัน launch regulated industry ต้อง audit แต่ละ agent ตาม control framework 6,000 agents เท่ากับ 6,000 audit scope เป็น liability หนัก ไม่ใช่ feature move นี้บีบ competitor consulting อย่าง Accenture Deloitte ให้ต้อง build platform play ของตัวเอง Thai SI อย่าง Enabridge มี chance จับ mid market ที่ IBM ยัง enter ไม่ถึง.

เรื่องที่ห้า.
วันที่ 12 พฤศจิกายน Google ปล่อย Gemini 4 Hydrogen ใหม่ ราคาหนึ่งเหรียญห้าสิบเซนต์ต่อ input ล้าน token และเจ็ดเหรียญห้าสิบเซนต์ต่อ output ล้าน token context window หนึ่งล้าน positioning คือ fast model สำหรับ agent workload ใช้ standalone หรือเป็น worker ใต้ orchestrator model ที่ใหญ่กว่าอย่าง Argon เป็น pattern ที่ Anthropic ใช้กับ Haiku กับ Sonnet ตั้งแต่ 2024 และ OpenAI ใช้กับ 4.1 mini กับ 4.1 ตอน 2025 Google join มาตามหลัง benchmark ที่น่าสนใจคือ aitoolsrecap รายงานว่า Hydrogen ได้ Intelligence Index 51 เทียบ Argon ที่ 50 แต่ต้องตรวจเพราะเป็น third party aggregator ไม่ใช่ Google เอง ถ้าจริงแปลว่า worker tier ทำดีกว่า flagship ใน cluster coding plus agent ซึ่งสะท้อนว่า Google tune สำหรับ workload นี้โดยเฉพาะ pattern ที่ชัดขึ้นในปี 2026 คือ model tier for agent กลายเป็น standard product taxonomy ของ frontier lab flagship planner, standard coder analyst, worker tool use สำหรับ builder ที่ agent run บน Gemini อยู่แล้ว การ switch task ที่ repetitive ไป Hydrogen จะ cut cost 50 ถึง 75 เปอร์เซ็นต์ framework ที่ support multi model routing จะได้ประโยชน์ก่อน สำหรับ CFO ลูกค้าที่ใช้ Gemini Enterprise Agent Platform ควรถาม finance team ว่าเราใช้ Argon ทุก call ไหม ตอบ yes เท่ากับมี savings ที่ยังไม่ได้เอา move นี้บังคับ Anthropic กับ OpenAI ต้องตอบคาดว่าจะเห็น refresh ภายใน Q1 2027 ที่น่าสนใจคือ Alibaba Qwen และ DeepSeek กำลัง push open source agent worker model ที่ cost ต่ำกว่า Hydrogen มาก frontier lab อาจ race to bottom ด้าน price สำหรับ worker tier.
