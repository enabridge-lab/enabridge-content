เรื่องแรก.
ข่าว Salesforce ที่ออกเมื่อวันที่ 5 พฤศจิกายนเป็นตัวเลขที่ตลาด enterprise agent รอมาทั้งปี Agentforce Coworker ซึ่งเป็น AI teammate ของ Salesforce มี active users 185,000 คน โตขึ้น 21 เท่าในเวลาแค่สามเดือน แปลว่าต้นเดือนสิงหาคมตัวเลขยังอยู่ประมาณไม่ถึงหมื่น นี่เป็น curve ที่ไม่ค่อยเห็นในโปรดักต์ enterprise ที่ขายผ่าน sales rep ไม่ใช่ product-led growth Salesforce เพิ่มทางเลือก pricing ใหม่ที่ 50 เหรียญต่อ user ต่อเดือน flat rate แทนที่จะคิด per action แบบเดิม การ anchor ราคาแบบนี้บอกว่า Salesforce เชื่อว่า agent จะกลายเป็น SaaS seat รุ่นใหม่ ไม่ใช่ infrastructure cost ที่ต้องมี FinOps ดูแล และ Agentforce จะเข้าไปอยู่ใน Microsoft Teams, Microsoft 365, และ Google Workspace ซึ่งเป็น surface ที่พนักงานเปิดอยู่แล้ว สำหรับคนที่สร้าง agent platform signal นี้ชัดเจน distribution สำคัญกว่า model quality agent ที่อยู่ใน Teams จะชนะ agent ที่อยู่ในแอพของตัวเอง สำหรับ CFO ที่กำลังคิดจะซื้อ agent ตอนนี้มี market anchor แล้ว 30 เหรียญถึง 50 เหรียญต่อ user ต่อเดือน จะกลายเป็น default ปี 2027 แต่ caveat คือตัวเลข 185,000 เป็น user ที่ใช้งาน ไม่ใช่ paid seat และไม่มี breakdown ชัด รอดู Q4 earnings ว่า Salesforce จะ guide revenue impact อย่างไร.

เรื่องที่สอง.
CrowdStrike ประกาศเมื่อวันที่ 4 พฤศจิกายนว่าจะซื้อ Fiddler AI ที่ประมาณ 400 ล้านเหรียญ และ Dreadnode ที่ประมาณ 95 ล้าน รวมประมาณ 495 ล้าน ใช้เงินสดส่วนใหญ่และ stock บางส่วนที่ vest ตามเวลา สองดีลคาดว่าจะปิดภายในไตรมาสหน้าของ CrowdStrike Fiddler เป็น startup observability สำหรับ AI agent ตั้งมาตั้งแต่ปี 2018 ที่ย้าย focus มาที่ generative AI หลังปี 2023 มี platform ที่ track prompt, retrieval context, tool call และ response quality หลังดีลปิดจะถูก rebrand เป็น Falcon Observe Dreadnode เล็กกว่าแต่เป็น red team platform เฉพาะสำหรับ AI ที่จำลอง attack ต่อ agent ก่อน deploy ประกอบกับ kill switch ที่ CrowdStrike เพิ่งเปิดตัวเดือนก่อน บริษัทกำลัง build stack ครบ cycle คือ eval ก่อน deploy monitor ตอน run และ terminate ตอน anomaly โผล่ สิ่งที่น่าสนใจคือตลาด observability กับ security กำลังรวมกลายเป็นตลาดเดียว เพราะ data ที่ต้องเก็บมา debug กับ data ที่ต้องเก็บมา detect anomaly มันตัวเดียวกัน ภายในหกเดือน specialist observability ที่ไม่มี security angle อาจจะไม่เหลือเป็น independent company ทุกคนจะถูกดูดเข้า platform ใหญ่ สำหรับคนที่ใช้ CrowdStrike อยู่แล้ว stack ใหม่นี้ลด vendor ได้ แต่ต้องต่อรอง data portability เพราะ single pane of glass ปกติแปลว่า lock-in.

เรื่องที่สาม.
Nooks ซึ่งเป็น startup AI dialer สำหรับ cold calling ประกาศเมื่อวันที่ 4 พฤศจิกายนว่าได้เงินห้าร้อยล้านจาก General Catalyst Customer Value Fund โครงสร้างนี้ไม่ใช่ equity raise แบบปกติ เป็น non-dilutive growth capital ที่จ่ายคืนด้วย share ของ customer value ที่ Nooks สร้าง ผู้ก่อตั้งไม่โดน dilute แต่ General Catalyst ได้ return ตาม outcome ควบคู่กับเงิน Nooks เปิดตัว Node เป็น AI personal assistant สำหรับ sales rep นั่งข้างในแพลตฟอร์มเดิม ตัวเลขที่ justify ดีลคือมี 2,000 บริษัทใช้ platform ประมวลผล sales interaction ไปแล้วเกิน 1 พันล้านครั้ง โตปีละ 3 เท่า Net Revenue Retention 135% แปลว่าลูกค้าจ่ายเพิ่มมากกว่า churn การที่ General Catalyst ยอมใส่ห้าร้อยล้านแบบ non-dilutive บอกว่าเขามั่นใจว่า Nooks จะ scale revenue ได้คาดการณ์ได้พอ สำหรับ builder ที่คิดจะสร้าง agent platform signal ชัดเจน vertical ที่ลึกและ compound ได้ชนะ horizontal ที่ต้องแข่งกับ OpenAI หรือ Anthropic ส่วน enterprise buyer ที่กำลังคิดจะซื้อ Nooks ตัวเลข NRR 135% ดูดี แต่ควรขอ reference account ใน vertical เดียวกันของคุณก่อน และต้อง clear ว่า Node ซึ่งเป็น copilot layer ใหม่กับ product เดิมไม่ทับกัน.

เรื่องที่สี่.
The Information รายงานเมื่อวันที่ 4 พฤศจิกายนว่า Palo Alto Networks กำลังเจรจาซื้อ Clutch Security ที่ประมาณห้าร้อยล้านเหรียญ ดีลยังไม่ signed Palo Alto ไม่ comment ตามนโยบาย Clutch เป็น startup Israel ตั้งปี 2023 ทำ platform จัดการ non-human identity ครอบคลุม API key, service account, token, และที่สำคัญคือ credential ที่ AI agent ใช้ Platform ทำได้สี่อย่างคือ discovery ว่า credential อยู่ไหน governance ว่าใครมี permission อะไร protection ด้วย vault และ rotation และ detection ของ anomaly ระดมเงินมามากกว่า 20 ล้านจาก Lightspeed และ SignalFire ที่น่าสนใจคือ Palo Alto เพิ่งปิดดีล CyberArk ที่ 25 พันล้านซึ่งโฟกัส human privileged access ส่วน Clutch โฟกัสเครื่องและ agent — เป็น complementary ที่ Palo Alto ต้องการขายเป็น identity vendor ครบวงจร pattern ที่ชัดเจนคือ ปริมาณ non-human identity ใน enterprise เพิ่ม 10 ถึง 50 เท่าในสองปีที่ผ่านมา เพราะทุก agent ต้องมี credential สำหรับคนที่สร้าง agent framework คำถาม credential เก็บยังไง rotate ยังไง จะกลายเป็น hygiene requirement ใน 6 ถึง 12 เดือน เหมือน TLS ที่เคยเป็น premium แต่ตอนนี้เป็น default สำหรับ business ที่ deploy agent หลายตัว ลองนับก่อนว่า credential sprawl ของตัวเองใหญ่แค่ไหน แล้วเลือก platform ที่ discovery อัตโนมัติก่อน governance.

เรื่องที่ห้า.
SAP เปิดตัว Joule Studio 2.0 ที่งาน TechEd 2026 เป็น development environment สำหรับสร้างและ deploy AI agent ที่มีสองเส้นทางคือ no-code สำหรับ business user และ pro-code สำหรับ developer ที่ใช้ Visual Studio Code หรือ Cursor extension no-code path สามารถสร้าง agent หรือ workflow n8n จาก prompt เดียว ส่วน pro-code มี integration กับ framework ยอดนิยมอย่าง LangChain, Pydantic AI, LlamaIndex และ developer เลือก model ได้มากกว่า 70 ตัวรวม Claude, GPT, Gemini จุดที่ SAP เน้นคือ governance — agent แต่ละตัวรันใน sandbox แยกมี policy configurable, observability ของ token spend, และ audit log ทุก action ลักษณะเหมือน SAP ERP เดิมที่มี row-level security แต่ย้ายมาเป็น agent level ตลาด enterprise agent builder กำลังแบ่งออกเป็นสามค่ายคือ horizontal framework, hyperscaler platform, และ application vendor ที่ embed เข้าไปใน app ที่ลูกค้าใช้อยู่แล้ว SAP เดิมพันว่าค่ายที่สามจะชนะเพราะ enterprise ไม่ซื้อ framework แต่ซื้อ outcome ใน workflow ที่ตัวเอง run อยู่ สำหรับคนที่ใช้ SAP ERP Joule Studio ลด time to value แต่แลกกับ vendor lock-in ที่ลึกขึ้น ถ้าคิดจะย้าย ERP ภายหลัง agent ที่ build ใน Joule Studio ไม่ได้ย้ายตาม Enabridge ควรพิจารณาว่าจะ build ใน Joule เพื่อความเร็ว หรือ build ใน platform กลางที่เชื่อมผ่าน API เพื่อ portability.
