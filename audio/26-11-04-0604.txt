เรื่องแรก.
วันนี้มีข่าวใหญ่จาก Uber ครับ Uber เปิด deep dive เรื่อง MCP Gateway ที่รัน production อยู่จริง มี MCP server แปดร้อยตัวและ tool ห้าพันตัวอยู่หลังประตูเดียว นี่ไม่ใช่ pilot หรือ demo แต่คือ infrastructure ที่ coding agent ของวิศวกร Uber ใช้ทุกวัน จุดที่น่าทึ่งคือ AutoCrawler สแกน service registry ภายในที่มี service definition หนึ่งหมื่นตัว แล้ว auto generate MCP tool ออกมาโดยที่ทีม service ไม่ต้องเขียน MCP server เอง ตัดคอขวด onboarding ที่หลายบริษัทเจอตอนนี้ Architecture แยกเป็น control plane คือ MCP Registry ที่เก็บ metadata กับ policy ออกจาก Proxy Gateway ที่ handle runtime กับ authz authz เช็คสองชั้น ทั้งระดับ server และระดับ tool ผ่านระบบ internal access control ของ Uber เอง สิ่งที่ Uber สอนตลาด AI agent คือ gateway + registry pattern ไม่ใช่แค่ feature แต่เป็นคำตอบของ enterprise agent governance บริษัทที่คิดว่าจะ deploy agent หนึ่งร้อยตัวในองค์กรโดยไม่มี registry กลางควรหยุดและกลับไปทำ service catalog ก่อน Signal อีกข้อ InfoQ ZenML Forkast รายงานพร้อมกันในสัปดาห์เดียว หมายความว่าตลาด enterprise agent กำลังเปลี่ยนภาษาจาก framework เป็น gateway กับ registry ชั้นที่ชี้ชะตา vendor จะไม่ใช่ว่าใคร DSL สวยที่สุด แต่คือใครคุม distribution policy และ identity ของ tool call ใน enterprise ได้ครับ.

เรื่องที่สอง.
ข่าวที่สองวันนี้ครับ GitHub ประกาศ public preview ของ MCP connector ที่ verify โดย GitHub เอง รายการแรก 26 service ครอบคลุมทั้ง Slack, Figma, Notion, Sentry, Linear, Atlassian Rovo, Cloudflare, Vercel จุดสำคัญคือ connect once — developer authenticate เข้า Slack หรือ Figma แค่ครั้งเดียว แล้วใช้ได้ข้ามทุก Copilot surface ทั้ง IDE, PR review, chat ไม่ต้องตั้ง credential ใหม่ทุกเครื่องเหมือนที่ Claude Desktop หรือ Cursor ต้องทำ เงื่อนไข enterprise admin ต้องเปิด policy ให้ก่อนและถ้าใช้ allowlist ก็ต้อง explicit เพิ่ม server แต่ละตัว Partner list ไม่ใช่ random GitHub ตั้งใจเลือกคู่ที่ไม่ใช่ Microsoft stack เช่น Figma แข่ง Microsoft Designer, Linear แข่ง Azure DevOps, Notion แข่ง OneNote — แสดงว่า GitHub positioning ตัวเองเป็น neutral hub ไม่ใช่ Microsoft wing ที่สำคัญคือ GitHub มี developer identity ของคนร้อยล้านอยู่ในมือ ไม่มีคู่แข่งคนไหนมีขนาดนั้น ปีหน้าตัวเลข connector นี้น่าจะกลายเป็นหลักร้อย และทุกคนที่สร้าง MCP server จะเริ่มถามว่าต้อง verified บน GitHub ไหม เหมือนที่ developer ปี 2015 ถามว่าต้องอยู่บน npm หรือ PyPI ไหม สำหรับทีมไทยที่ใช้ Copilot Business อยู่แล้ว ควรให้ CISO review allowlist ภายในเดือนนี้ครับ ไม่งั้น connector 26 ตัวจะเริ่มถูก developer เปิดใช้โดยอัตโนมัติ.

เรื่องที่สาม.
ข่าวที่สามน่าสนใจมากครับ ที่ Android Dev Summit 2026 Google ประกาศว่า Android Studio Rabbit 2 เปิด Bring Your Own Agent หรือ BYOA แปลว่า developer เลือก coding agent ตัวใดก็ได้ใน list สี่สิบกว่าตัวมาเสียบเข้า IDE ผ่าน protocol ใหม่ชื่อ Agent Client Protocol หรือ ACP agent ที่ Google highlight คือ Claude Agent ของ Anthropic, Codex ของ OpenAI, Antigravity ของ Google เอง และ Junie ของ JetBrains ACP เป็น model mirror ของ Language Server Protocol ที่ VS Code ใช้สำหรับคุยกับ language server ก่อน ACP: Android Studio ต้อง custom build integration ต่อ agent หลัง ACP: agent ตัวใดก็ plug ได้ถ้า speak protocol Google ยัง claim ด้วยว่า agent ทำงาน UI task ได้ 77% เร็วขึ้นและใช้ token น้อยลง 3 เท่า ด้วยคำสั่ง Compose preview terminal ใหม่ ตัวเลขยังมาจาก Google ขอดู third party verify ก่อนเชื่อ จุดที่น่าคิดคือ Google ยอมเปิด IDE ให้คู่แข่งเข้า ซึ่งแปลว่า Google ยอมรับแล้วว่า IDE lock-in strategy แพ้ Copilot และ Cursor การ position Android Studio เป็น neutral runtime ก็เหมือนที่ Android เองเคย beat iOS ด้วย openness Pattern ที่ชัดในวันนี้ Uber เปิด internal MCP distribution, GitHub เปิด external MCP distribution, Google เปิด IDE distribution ทั้งสามชี้ไปทิศเดียวกัน ชั้นที่ profit ไม่ใช่ distribution แต่คือ agent-level capability ทีม Android ไทยควร experiment Rabbit 2 ใน sprint นี้ถ้ายังใช้ Claude Code หรือ Copilot อยู่ครับ.

เรื่องที่สี่.
ข่าวที่สี่ครับ 31 ตุลาคม ทีม Harness ของ DeepSeek post ใน WeChat เปิดตัว Super-Agent บน GitHub เป็น open source MIT license จุดต่างที่ DeepSeek เน้นคือ autonomy agent monitor group chat ของทีม developer เองแล้วเสนอ solution ก่อนโดยไม่รอให้ user summon ซึ่งเป็น step ที่ไกลจาก Copilot, Claude Code หรือ Cursor ที่ยังต้องรอ invoke Architecture แยกเป็น Router layer กับ Worker session หลายตัว Router รับ event แล้ว route ไปหา Worker ที่ specialize task ต่างกัน Bloomberg ตามข่าวนี้ในวันที่ 1 พ.ย. จุดที่น่าสังเกต launch ก่อน Anthropic IPO ที่คาดว่าจะเกิดในไม่กี่สัปดาห์ Attack ตรงที่ Claude Code ซึ่งเป็น flagship enterprise ของ Anthropic Caveat สำคัญ capability จริงยัง unproven ยังไม่มี benchmark เทียบกับ Claude Code หรือ Codex บน task จริง ยังเป็น architecture และ prototype ไม่ใช่ commercial product สิ่งที่น่าสนใจคือการเปลี่ยน default interaction model จาก request response เป็น always on monitoring ถ้า pattern นี้ scalable มันเปลี่ยน UX ของ coding assistance ทั้งอุตสาหกรรม Angle ภูมิรัฐศาสตร์ชัด DeepSeek open source + MIT license = กลยุทธ์จีน commoditize layer ที่ US frontier lab พยายาม monetize แบบเดียวกับที่ทำกับ v3 และ R1 ตอนนี้ apply กับ agent layer Anthropic กับ OpenAI ตอบด้วย open source ไม่ได้ ต้องตอบด้วย capability lead ที่กว้างพอ ถ้า Super-Agent benchmark ออกมาที่ 80% ของ Claude Code บนราคา 10% CFO enterprise จะเริ่มถามแน่ ๆ ครับ.

เรื่องที่ห้า.
ข่าวสุดท้ายวันนี้ครับ 27 ต.ค. Akamai เปิด beta Agent Sandbox และ Akamai Inference พร้อมกัน Agent Sandbox เป็น runtime isolated สำหรับโค้ดที่ AI agent สร้าง agent หลักรันบน Akamai Functions แต่โค้ดที่ agent เขียนรันแยกใน sandbox ที่ใช้ WebAssembly เป็นชั้น isolation ต่างจาก sandbox ที่ทีม dev ส่วนใหญ่รู้จักเช่น Firecracker หรือ gVisor ตรงที่ไม่ wrap container ใช้ WebAssembly isolation ตรงใน runtime ซึ่งเร็วและกินทรัพยากรน้อยกว่า Base คือ Spin framework ที่ Akamai เปิดเป็น open source Security model สำคัญ deny by default outbound โค้ดที่ agent เขียนจะรันด้วยไม่มี network access ต้อง explicit grant Cap ได้ครบทั้ง compute, memory, outbound connection, system privilege ปี 2025 agent sandbox เป็น feature ปี 2026 ครึ่งหลังมันกลายเป็น default requirement สาเหตุคือ incident สะสม coding agent รัน destructive command บน repo production LLM agent ที่ exfiltrate credential agent ที่ invoke endpoint ที่ไม่ควร CISO ที่ยอมให้ agent รัน shell เสี่ยง SOC2 fail Akamai เลือก Wasm แทน container เพราะ startup time ต่ำกว่ามาก attack surface น้อยกว่า และ deny by default กำหนดง่ายกว่าใน capability model ของ Wasm Trade off คือ โค้ด native ต้อง compile เป็น Wasm ก่อน Python ที่ใช้ numpy pandas ต้อง solve ที่ environment ก่อน ที่สำคัญคือ Spin open source Akamai ไม่ lock architecture — pattern เดียวกับ Firecracker ของ AWS หรือ gVisor ของ Google สำหรับทีมที่ deploy coding agent ใน CI CD pipeline ไทยควร audit outbound connection ของ agent ภายในเดือนนี้ครับ.
