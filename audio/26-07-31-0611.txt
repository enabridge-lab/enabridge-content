เรื่องแรก.
วันนี้เช้าที่ Enabridge อยากให้ทุกคนเห็น pattern ที่เกิดใน 24 ชั่วโมง. Hush Security กับ Encore AI สอง startup ที่ทำคนละเรื่องเลย ปิด Series A ขนาดเท่ากันเป๊ะ 30 ล้านเหรียญคนละราว. Hush นำโดย Akamai ในฐานะ strategic investor. Encore นำโดย Team8 กับธนาคาร insurance ที่เดิมเป็น customer.

Hush ทำ non-human identity สำหรับ AI agent. Registry กลาง JIT permission kill switch. Kyndryl ที่เป็น IT infrastructure services ใหญ่ที่สุดในโลก ไม่แค่ใช้เอง แต่เริ่ม resell ให้ enterprise. Encore ทำ Interaction Mining แยก action ของ top performer แล้ว encode เป็น revenue agent. Lending client รายใหญ่โชว์ 10x ROI ภายในไม่กี่เดือน.

วันเดียวกัน Gartner ออก press release. AI agent จะ outnumber seller 10 ต่อ 1 ภายในปี 2028. แต่ paradox คือ น้อยกว่า 40% ของ seller จะบอกว่า agent เพิ่ม productivity. Dan Gottlieb เรียกว่า value ceiling. Melissa Hilbert เสริม beyond a certain point more AI does not mean more productivity.

Signal ที่อยากให้เห็น. Agent workforce กำลังกลาย standard ในเวลาที่เร็วกว่า SaaS revolution รอบก่อน. แต่ 2 gap ใหญ่ open. Governance ที่ security team ยัง visibility ต่ำ. กับ outcome capture ที่ business ยังพิสูจน์ ROI ไม่ได้. Hush เข้ามุมแรก. Encore เข้ามุมสอง. คนละ arbitrage แต่ปัญหาเดียวกัน.

สำหรับ builders ที่ทำ agent framework. ต้อง treat identity กับ outcome เป็น first-class primitive ตั้งแต่ v1. ไม่ใช่ optional module. Framework ที่ไม่มี 2 hook นี้ในปี 2027 ขาย enterprise ไม่ได้.

สำหรับ enterprise ไทย SET50. Q4 นี้ต้องเริ่มถาม vendor สาม คำถาม. Agent enroll เข้า identity registry ได้ไหม. Outcome attribution instrumentation มีมั้ย. Standing credential หรือ JIT. คำถามพวกนี้ Q4 นี้ยังไม่ mandatory. Q4 ปีหน้าจะเป็น. คุยกันวันหน้าครับ.

เรื่องที่สอง.
ข่าวที่ dev ทุกคนที่ใช้ Visual Studio ต้องรู้เช้านี้. GitHub Copilot in Visual Studio ปล่อย July update วันที่ 30. Feature หลักคือ Agent Preview ตัวใหม่ที่ build บน Copilot SDK ตัวเดียวกับที่ powers Copilot CLI. แปลว่า Microsoft ย้าย AI layer ของ Visual Studio ทั้งหมดให้ run บน SDK เดียวกับ VS Code กับ CLI. ตัดการ maintain agent stack แยก 3 ตัวที่ fork กันมาปีที่ผ่านมา.

Feature ที่ตามมา. Built-in .NET กับ Azure skill ที่ team Microsoft author เอง. dotnet-trace-collect, dotnet-pinvoke, csharp-scripts, azure-validate, azure-upgrade. Organization-level custom instructions ให้ org owner set Copilot preference กลางแล้ว push ลงทุก repo. Copilot Actions Review Selection ให้เลือก code แล้ว invoke inline review.

Zoom out ให้เห็น pattern. 3 vendor ปิดเกม agent runtime สำเร็จภายในปี 2026. Anthropic Claude Code SDK powers Claude Code กับ Claude Desktop กับ Bedrock.
