เรื่องแรก.
วันจันทร์ที่แล้ว 26 ตุลาคม Anthropic ยื่น S-1 กับ SEC ขอ list หุ้น Class A บน Nasdaq ภายใต้ ticker ANT — เป็น frontier AI lab เจ้าแรกที่เข้าตลาดสาธารณะในขนาดนี้ ตัวเลขที่เขย่าตลาดคือ รายได้ครึ่งแรกของปี 2026 ที่ 16.3 พันล้านดอลลาร์ เทียบครึ่งแรกปี 2025 ที่ 1.2 พันล้าน โตราว 13.6 เท่าภายในปีเดียว ไตรมาสที่ 2 เดี่ยว 11.6 พันล้าน และ operating profit 974 ล้านดอลลาร์ margin 8 เปอร์เซ็นต์ นี่คือ frontier AI lab เจ้าแรกที่โชว์ quarterly operating profit ใน filing ระดับ IPO ตัวเลข net loss ที่ 80 พันล้านดอลลาร์ที่สื่อ panic จริงๆ แล้ว 72.4 พันล้านเป็น non-cash จากการ markup fair value ของหนี้ convertible เพราะมูลค่าบริษัทขึ้น ไม่ใช่ cash burn 22 ธนาคารนำโดย Goldman Sachs กับ Morgan Stanley ตลาด pre-IPO ตั้งราคาที่ 1.5 ถึง 2 ล้านล้านดอลลาร์ ถ้าถึงที่ 1.5 ล้านล้าน Anthropic จะเป็นบริษัทจดทะเบียน US ใหญ่ลำดับที่ 7 ของประเทศ ภายในอายุบริษัทจริงแค่ 4 ปี ประเด็นสำหรับคนทำ agent คือ หลังจาก IPO Anthropic จะมี corporate governance + fiduciary duty แบบ public ที่ทำให้ API deprecation หรือการเปลี่ยน terms ทำได้ยากขึ้น นี่คือ counterparty ที่เสถียรที่สุดสำหรับ enterprise contract ด้าน agent ปีหน้า.

เรื่องที่สอง.
วันจันทร์ที่แล้วที่ Oracle AI World ลาสเวกัส Oracle ประกาศ 2 ข่าวใหญ่พร้อมกัน หนึ่งคือ Google TPU จะมาบน Oracle Cloud Infrastructure ปี 2027 เป็นครั้งแรกที่ TPU เปิดใช้นอก Google Cloud ชิปที่มาคือ TPU Generation 8 สองรุ่น รุ่น 8t สำหรับ training และรุ่น 8i สำหรับ inference ที่ Thomas Kurian บอกว่า built for the iterative work of many specialized agents สองคือ Oracle จะฝัง ChatGPT กับ Codex เข้าแอป Oracle Fusion ทั้ง ERP HCM SCM และจะมี OpenAI Jalapeño ซึ่งเป็นชิป in-house ของ OpenAI กับ Cerebras WSE ลง OCI ด้วย กลายเป็น cloud แรกที่มี 4 ซิลิคอน frontier พร้อมในตลาดเดียว คือ Google TPU, OpenAI Jalapeño, NVIDIA Blackwell, และ Cerebras ที่สำคัญสำหรับ enterprise คือ บริษัท Fortune 500 70 เปอร์เซ็นต์ที่ใช้ Oracle ERP อยู่แล้ว ปี 2027 จะเรียก agent action ผ่าน UI เดิมของตัวเองได้เลย ไม่ต้องซื้อ seat ใหม่ ไม่ต้อง switch tool นี่คือ turn point ของ enterprise agent adoption ที่ bypass procurement cycle ยาวๆ สำหรับ Oracle backlog ตอนนี้มี 455 พันล้านดอลลาร์แล้ว หลังจาก OpenAI, Meta Superintelligence Labs, Microsoft overflow และตอนนี้ Google — เป็น signal ชัดว่า cloud platform wars เข้าสู่ยุค silicon diversity for agents ไม่ใช่ GPU count อีกต่อไป.

เรื่องที่สาม.
วันพุธที่ GitHub Universe 2026 ที่ San Francisco GitHub ประกาศ reposition Copilot ทั้ง product แบบที่ซีอีโอ Thomas Dohmke พูดบนเวทีว่า Copilot is no longer an autocomplete it now runs software delivery สิ่งที่เปิดคือ Copilot cloud sessions ที่รัน persistent บน cloud แล้ว follow dev ข้ามอุปกรณ์ ทั้ง web mobile CLI VS Code ปิด laptop ปุ๊บ session ยังเดินงานต่อ สอง Copilot Projects ที่จัดการ parallel agent หลายตัวข้าม repo จาก UI เดียว เป็น dashboard สำหรับคุม agent fleet สาม Copilot Automations ที่เป็น workflow ใน repo ที่ learn จากผลลัพธ์ past run แล้ว propose แก้ workflow เอง human approve หรือ reject เป็น gate เสมอ สี่ Copilot Fusion ที่ orchestrate model หลายตัวให้ dev task งานเดียว ใช้ Opus 5.5 planning, Sonnet หรือ GPT 5.5 mini generation, ได้ claim ว่า performance ใกล้ Opus 5.5 ที่ half per task cost ประเด็นสำคัญคือ GitHub เลิกเป็น IDE plugin อย่างเปิดเผย กลายเป็น cloud-first agent platform ที่ compete ตรงกับ Cursor, Replit, Codex Cloud ด้วย distribution advantage ที่ developer 150 ล้านคน และ seat Copilot ที่ organization ซื้ออยู่แล้ว 100 ล้าน ชั้น automation tool แบบ Zapier n8n กำลังโดน disrupt จากบนลงล่าง เพราะ repo คือ system of record ของ workflow และ Copilot เป็น agent engine ที่เรียกใช้ได้โดยตรง.

เรื่องที่สี่.
Snowflake ประกาศวันพุธ 28 ตุลาคม เพิ่ม 3 ตัวควบคุมใหม่ให้ Cortex Agents Coding Agent ผ่าน API ของตัวเอง หนึ่งคือ thinking_effort ที่ตั้ง reasoning budget ได้ 6 ระดับ ตั้งแต่ minimal ถึง max ถ้า model backend ไม่ support ระดับ max จะถูก downgrade อัตโนมัติแทนที่จะ error สองคือ instructions.system ที่ให้ enterprise ฝัง policy ระดับ system เช่น ห้าม PII leave warehouse หรือ ask for approval ก่อน DROP TABLE โดยไม่ต้องแก้ user prompt หลายที่ สามคือ stage_mounts ที่ mount Snowflake stage รวม versioned stage ของ notebook, Streamlit app, workspace, agent definition เข้า sandbox ของ agent ความสำคัญคือ ตอนนี้ agent สามารถเรียก notebook ที่ data team เขียนไว้แล้วเป็น tool ได้เลย ไม่ต้องเขียน MCP server แยก สิ่งที่ release note นี้สะท้อนคือ ชั้น agent primitive บน data warehouse กำลัง standardize ข้าม vendor ทั้ง Snowflake, Databricks, BigQuery, Microsoft Fabric วิ่งไปแนว API design เหมือนกัน คือ reasoning budget + system instruction + sandbox integration สำหรับ Thai enterprise ที่ใช้ Snowflake อยู่ ไม่ว่าจะเป็น SCB True PTT นี่คือ feature ที่ไม่ต้องรอ vendor ชิ้นที่ 11 เขียน SQL กับ agent ใน UI เดียว security policy เดียว audit layer เดียว compliance envelope เท่าเดิม.

เรื่องที่ห้า.
Akamai ประกาศวันอังคารที่ 27 ตุลาคม เปิด 2 ผลิตภัณฑ์ beta พร้อมกัน หนึ่งคือ Akamai Inference managed model serving ที่มี catalog เริ่มที่ 12 open-weight models ตั้งแต่ 8 พันล้าน parameter ถึง 2.8 ล้านล้าน parameter รวม NVIDIA Nemotron 3 Ultra, OpenAI gpt-oss-120b, Google Gemma 4 แล้วก็มี serverless deploy option ให้ dev deploy ครั้งเดียว scale ตาม request ฮาร์ดแวร์เริ่มที่ NVIDIA B300 cluster และ Vera Rubin support ปี 2027 สองคือ Akamai Agent Sandbox ที่เป็น isolated execution environment สำหรับ code ที่ agent generate รันบน WebAssembly ตาม Spin framework ซึ่งเป็น open source cap resource ทั้ง compute memory outbound connection system privilege ความต่างจาก sandbox แบบ Docker คือ WASM start ใน milliseconds overhead ต่ำกว่า 100 เท่า เหมาะกับ agent fleet ที่ 1 agent เรียก sub agent 50 ตัวต่อ workflow ประเด็นสำคัญคือ CDN รายใหญ่กำลังเปลี่ยนตัวเองเป็น edge agent runtime อย่างเปิดเผย ทั้ง Akamai, Cloudflare, Fastly การที่ latency ของ agent interaction เริ่ม bottleneck ที่ network ไม่ใช่ model แล้ว ทำให้ edge inference เป็น moat ที่ hyperscaler สู้ไม่ได้ สำหรับ Thai enterprise ที่สร้าง customer-facing agent — ธนาคาร telco retail — Akamai มี POP ใน Bangkok Singapore Jakarta แปลว่า respond time ต่ำกว่า 500 ms end to end data residency อยู่ที่ POP ไทยเอง เป็น default choice ปีหน้าแน่นอน.
