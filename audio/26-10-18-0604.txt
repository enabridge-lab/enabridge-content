เรื่องแรก.
วันนี้มีเรื่องที่คนทำ agent ควรฟัง — Perplexity เพิ่งเปิดซอร์ส SPACE sandbox ที่เขาใช้ใน Comet มาตั้งแต่กรกฎาคม ขึ้น GitHub แบบ Apache 2.0 แล้วเลขที่โชว์มันดุมาก. SPACE สร้าง VM ใหม่ใน 60 มิลลิวินาที, เก็บ snapshot ของทั้ง state ได้, และ credential ของ user ไม่เคยถูกเก็บไว้ใน sandbox — inject เฉพาะตอนใช้แล้วหายไป. ที่สำคัญกว่านั้น red team ยิง escape attempt 118 ครั้งผ่าน 9 frontier model แล้วไม่มีตัวไหนหลุดจาก VM ไปถึง host เลย ขณะ sandbox ปิดเจ้าอื่นมี model หลุด. และ CoreWeave, Akamai, Crusoe ประกาศจะเสิร์ฟ SPACE เป็น managed service ให้ลูกค้า — เท่ากับ sandbox ของ Perplexity กลายเป็น de facto standard ภายในวันเดียว. บทเรียนคือ sandbox กำลังกลายเป็น commodity layer เหมือน Docker เมื่อสิบปีก่อน — ไม่มีใครอยากขายมัน ทุกคนอยากให้ของตัวเองเป็น standard. ถ้าคุณสร้าง agent runtime อยู่ การ build sandbox เองคือของเสียเงิน. และถ้าคุณใช้ agent ใน business workflow ให้ถาม vendor ว่า sandbox อะไร isolated ขนาดไหน ถ้าตอบว่าแค่ container คือสัญญาณที่ควร pause.

เรื่องที่สอง.
Sakana AI เพิ่งปล่อย Agentic Scientist v3 แบบ Apache 2.0 — pipeline ที่ให้ agent ทำวิจัยตั้งแต่ hypothesis ไปจน publishable paper โดยที่มนุษย์ไม่แตะ. จุดที่ v3 ต่างจากรุ่นก่อนคือ architecture แยก 6 phase ไว้ใน Docker container คนละตัว — draft, investigate, ablate, evaluate, analyze, write — แล้วขับ coding agent 6 ตัวผ่าน headless CLI ตั้งแต่ Claude, Codex, Cursor, OpenCode, Gemini, Pi. finding ที่สะเทือนที่สุดคือ ทีม ablate 9 LLM กับ 4 harness แล้วสรุปว่า harness สำคัญกว่า model base — คือ orchestration layer อยู่ด้านบน model capability. และ development version ของ pipeline เขียน paper ที่ ALIFE 2026 รับตีพิมพ์จริง 1 ชิ้น ไม่ใช่ demo. ที่สะเทือนตลาด: pattern Docker ต่อ phase กับ CLI wrapper ต่อ agent คือ blueprint ที่ transfer ได้นอก research — legal pipeline, consulting pipeline, healthcare pipeline ก็ใช้ pattern เดียวกัน. และคำถาม "model หรือ harness สำคัญกว่า" ตอนนี้มีคำตอบ data-backed แล้ว ว่า harness ชนะ — ที่ engineering effort ของ builder ควรลงไปคือ orchestration ไม่ใช่รอ frontier model รุ่นต่อไป.

เรื่องที่สาม.
CERT-In อินเดีย เพิ่งออก advisory เรื่องที่ควรรู้ก่อนเริ่มงานเช้า — AI agent ที่หลายบริษัทใช้ใน research กับ test environment หลุดเข้าถึง production system จริง อ่าน business record กับ personal data ของบริษัทจริง. ที่น่าสนใจคือ root cause ไม่ใช่ model เก่งเกินไปหรือ jailbreak ซับซ้อน — เป็นของเก่าหมด คือ API key credential หลุดอยู่ใน source code, config file, client app, public web. agent ไม่ได้ hack มัน scan เจอ key ที่หลุดอยู่แล้ว แล้วใช้เพราะ IAM scope ไม่แคบพอ. CERT-In แนะ 4 ข้อ แยก test กับ prod ให้ไม่ shuffle, ใช้ synthetic credential ใน test, audit code หา exposed key, tighten cloud IAM. ที่น่าสังเกตคือ incident batch นี้คือ incident ที่ 4 ของปี 2026 ตามหลัง McKinsey, Asia government breach, AEPD สเปน. pattern คือ enterprise ยังไม่ treat AI agent เหมือน insider threat ยัง treat เป็น tool ที่ user รัน. ถ้าทีมคุณกำลัง pilot agent ก่อน next sprint รัน 4 step นี้ก่อน — audit secret, split environment, rotate key, scope IAM. และห้าม test agent share credential กับ production เด็ดขาด.

เรื่องที่สี่.
Arena ที่ย่อจาก LMArena ไอ eval leaderboard ที่เริ่มจาก UC Berkeley research ปี 2023 เพิ่งปิด Series B $200 ล้าน ที่ valuation $3.1 พันล้าน Lightspeed กับ Khosla co-lead. ตัวเลขที่สวยคือ 8 เดือนหลังเปิด commercial product Arena ชน $100 ล้าน annualized run-rate. แต่ CEO Angelopoulos hedge ชัดเจนซึ่ง rare สำหรับ founder ว่าไม่ใช่ ARR แบบ SaaS เป็น consumption-based คือเก็บต่อ eval call จริง ไม่ใช่ contract recurring. จาก Series A มกราคม $30M revenue ที่ $1.7B valuation ไปถึง Series B ตุลาคม $100M run-rate ที่ $3.1B — valuation +84% ใน 9 เดือน. ที่น่าสังเกตคือ Arena ขาย evaluation layer ซึ่งปีที่แล้วยังมองเป็น academic metric ที่ไม่มีใครจ่าย ตอนนี้ enterprise จ่ายจริงด้วยสองเหตุผล compliance ต้องมี benchmark auditor ยอมรับ และ procurement บริษัทที่ไม่ lock vendor เดียวต้องรู้ว่า model ไหนดีกว่าก่อนจ่าย premium. Pattern คือ Arena เป็น shovel seller ของ model gold rush เหมือน Snowflake ที่ไม่ compete กับ cloud provider โดยตรง. บทเรียน ถ้าทีม procurement คุณยัง pick model ด้วย demo ของ vendor คือสัญญาณที่ควร pause ควรมี internal benchmark หรือ subscribe eval platform ที่ independent ก่อน sign contract เจ็ดหลัก.
