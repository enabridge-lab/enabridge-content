เรื่องแรก.
OpenAI เปิดตัว Dots ซึ่งเป็น always-on agent ที่รันในคลาวด์ VM ของตัวเอง เก็บงานข้าม conversation ได้ — ที่น่าสนใจคือ pricing structure: Pro 100 ที่ 100 ดอลลาร์ต่อเดือน, Pro 200 ที่ 200, และ Pro 500 ที่ 500 ดอลลาร์ต่อเดือน ทุก tier ได้ dot หนึ่งตัว ชั้น 500 เพิ่ม headroom สูงสุด บวก Astra Ultra. 500 ดอลลาร์ต่อเดือนคือ floor ที่ consumer AI product ไม่เคยกล้าแตะมาก่อน — ก่อนหน้านี้เพดาน consumer อยู่ที่ 200. Rollout ไป US กับ 4,000 กว่าประเทศ ยกเว้น UK, EEA, Switzerland ที่รอ regulatory clearance ภายใต้ EU AI Act. Enterprise, Edu, Healthcare เป็น custom-priced กับ Dots off by default. ตัวเลขที่หนุน pricing นี้คือ scale: OpenAI รายงานเมื่อ 14 สิงหาคมว่า enterprise revenue overtake consumer เป็นครั้งแรก, enterprise run rate เกิน 40 พันล้านดอลลาร์ annualized, business customer โต 32 เปอร์เซ็นต์ในกรกฎาคมเดือนเดียว, agent features ชน 20 ล้าน weekly active user บน Aug 19, overall revenue run rate +35 เปอร์เซ็นต์ QTD, enterprise +50 เปอร์เซ็นต์. ประเด็นต่อจากนี้มีสาม หนึ่ง 500 ดอลลาร์ต่อเดือนคือ price anchor ใหม่ ถ้า validate ได้ Anthropic กับ Google จะตามเร็ว เปิดทางให้ agent-native tool ตั้งราคาสูงกว่า SaaS seat 20-50 ดอลลาร์ได้ครั้งแรก. สอง enterprise overtaking consumer เป็น structural shift — valuation ของ OpenAI กลายเป็น enterprise SaaS multiple ไม่ใช่ consumer internet อีกต่อไป ที่ 500 พันล้านดอลลาร์ ARR เป้า 2027 enterprise share น่าจะเกิน 60 เปอร์เซ็นต์. สาม Dots + Replit deal 100 ล้านต่อปี + agent WAU 20 ล้าน ต่อกันเป็น picture เดียวว่า OpenAI convert agent momentum เป็น long-dated enterprise commitment โดยใช้ discount เป็นเครื่องมือ Anthropic กำลัง catch up ด้วย Claude Duet กับ sandbox-runtime แต่ scale gap น่าจะโตขึ้นก่อน IPO กลางพฤศจิกายน. สำหรับทีมที่ซื้อ Dots มา deploy ควร note ว่ามันคือ hire non-human worker ที่ไม่มี 90-day review ต้องมี playbook การ assign งาน การ audit และการตั้ง spending cap ซึ่ง Dots enterprise edition ยังไม่มี equivalent กับ Google Universal Gemini for Work ที่ hard cap per project ได้ — ตลาด APAC รวมไทยที่มี AI Act lite จะเป็น testing ground จริงก่อน EU อีกหลายเดือน.

เรื่องที่สอง.
วันพุธที่ 15 ตุลาคมที่ Ship 2026 ซานฟรานซิสโก Vercel ประกาศ Drives เข้า GA — persistent storage layer ที่ mount เข้า Vercel Sandbox แล้วอยู่หลัง sandbox stop ค่า default 1 TiB บนทุก plan ขยายได้ถึง 16 TiB. ก่อนหน้านี้ Sandbox ของ Vercel เป็น ephemeral — agent run เสร็จ state หายทันที — pattern ที่คน CrewAI กับ LangGraph complaint มานาน ว่าทำ long-running workflow ไม่ได้. Drives แก้ได้แล้ว. ที่น่าสนใจคือ Forking ก็เข้า GA — fork คัดลอก state ปัจจุบันของ drive เป็น child ใช้ run parallel experiment ได้ แต่ไม่ merge กลับ parent — เป็น pattern ใหม่สำหรับ agent branching ที่ Devin กับ Codex กับ Replit Agent roll ของตัวเองก่อนหน้านี้. Vercel Daemons ก็เข้า public beta — long-running background worker ชั้นที่ Vercel เคย relentlessly ปฏิเสธ ตอนนี้ยอมรับว่า agent workflow ต้องการ compute pattern ที่ serverless ตอบไม่ครบ. Enterprise-Managed Authorization ผ่าน Vercel Connect เข้า beta พร้อมกัน — enterprise ที่ self-host หลัง Okta หรือ Entra จะได้ fine-grained access control ต่อ sandbox drive daemon. Vercel ประกาศคู่ว่า Meta Superintelligence Labs ใช้ Vercel และ enterprise AI Gateway token use โต 4 เท่าใน 3 เดือน. ประเด็นต่อจากนี้มีสาม หนึ่ง agent primitive stack กำลัง layer จริง — 6 เดือนก่อน Vercel เป็นแค่ frontend host ตอนนี้เกือบครบ stack สำหรับ build agent production ลด time to production จากเดือนเป็นสัปดาห์. สอง agent branching ด้วย drive fork คือ pattern ใหม่ที่ยังไม่เป็น vocabulary มาตรฐาน ถ้า Vercel bundle ชั้นนี้ลง primitive เท่ากับ commoditize — eval framework ที่วัด quality ของ fork แต่ละสายคือตลาดใหม่ที่ยังไม่มี leader. สาม Vercel กับ Anthropic sandbox-runtime pattern ต่างทาง topology — Anthropic OS-level sandbox บน machine ของ developer, Vercel managed cloud sandbox — สองโมเดลตอบคนละ workload การเลือก stack เริ่ม commit workload shape จริง. สำหรับ builder migrate long-running workload จาก function ไป Daemon ลด cost cold-start + ไม่ต้อง rehydrate state สำหรับ enterprise CTO Vercel ขยับจาก frontend of agent product ไป end to end agent platform cornerstone คู่แข่งกลายเป็น Modal กับ Replicate ไม่ใช่ Netlify อีกต่อไป.

เรื่องที่สาม.
วันอังคารที่ 6 ตุลาคมที่ Austin, SailPoint เปิดงาน Navigate 2026 ด้วย keynote ที่ CEO Mark McClain ยืนข้าง Horizons Report หน้าใหญ่ — 79 เปอร์เซ็นต์ของ enterprise รัน AI agent ใน production แล้ว แต่มีแค่ 2 เปอร์เซ็นต์ที่ deploy identity security tool ที่ purpose-built สำหรับ agent. gap นี้คือสิ่งที่ SailPoint ตั้งใจจะเติม ด้วย product line ใหม่ชื่อ Agentic Fabric ซึ่งมี 4 ชั้น: discovery ที่ scan endpoint browser SIEM XDR vault pipeline หา agent กับ MCP server กับ credential ที่คน spawn โดย IT ไม่รู้, autonomous agent 3 ประเภท — enforce policy, adjust privilege, protect system, A-ISPM หรือ Autonomous Identity Security Posture Management ที่ใช้ live context หา exposure และ remediate ทันที, และ conditional JIT provisioning ที่ default zero standing privilege ครอบ human service account กับ agent identity ในชั้นเดียว. SailPoint ยังมี kill switch สำหรับ rogue agent และ IdentityIQ 9.0 สำหรับ on-prem customer. ประเด็นต่อจากนี้มีสาม หนึ่ง 79 ต่อ 2 เปอร์เซ็นต์ gap คือตัวเลขที่ CISO ทุก Fortune 1000 จะชี้ให้ CEO ดู — 77 เปอร์เซ็นต์ของ enterprise มี non-human worker fleet แต่ไม่มีระบบ HR กับ security — shadow IT ที่ scale 100 เท่าของ 2017-2020. สอง IGA framework เดิมหมดอายุ — identity governance ปัจจุบัน assume identity เป็นตัวตนคงที่ แต่ agent คือ identity ที่ behavior random ตาม prompt scope ขยายและหดได้ทุก task spawn child ตัวเองได้ — ต้องมี framework ใหม่ที่ lifecycle per task, privilege conditional, audit เป็น trace of decision ไม่ใช่ snapshot of role. SailPoint วางหมาก A-ISPM ก่อน Microsoft Okta CyberArk. สาม เกิด non human HR category ใหม่ — enterprise ต้องมีอัตรากำลัง agent รายไตรมาส performance review termination process — SailPoint ยืน identity กับ lifecycle 60 เปอร์เซ็นต์ของ stack เหลือ performance eval กับ cost allocation กับ termination orchestration เป็นช่องสำหรับ startup. สำหรับ builder ที่สร้าง framework ยังไม่มี native identity binding ขาย enterprise ไม่ได้หลังปีนี้ — framework ที่ย้ายไป identity first by default จะชนะก่อน. สำหรับ enterprise ที่มี agent เกิน 50 ตัว ควร deploy agent identity governance ไม่ช้ากว่าสิ้นปี เริ่มด้วย discovery ตามด้วย inventory และ zero standing privilege. ไทย ETDA กับ สดช. ที่ร่าง AI Governance Act ควร reference identity first framework เป็นมาตรฐาน.

เรื่องที่สี่.
วันพุธที่ 8 ตุลาคมที่ Gemini at Work 2026 Google เปิด Universal Gemini agent — productized agent ที่ enterprise เรียกจาก prompt box เดียว ทำได้ทุกอย่าง ค้นหา สร้าง content เขียน code run workflow. ความต่างจาก Gemini แบบ embed ใน Google Docs คือ cross app ตั้งแต่ day one — connect Slack, Microsoft 365, Salesforce, ServiceNow, Snowflake, BigQuery, PayPal, Shopify. Google ชัดว่า private preview ยังไม่ใช่ GA. สิ่งที่ค่อนข้าง new คือ governance primitive ที่ bundle มากับ product — agent ได้ identity ของตัวเอง activity log access boundary ที่ admin กำหนด และ hard spending cap per project ซึ่งเป็น first ของ enterprise agent product. Vertical bundle: financial services กับ legal preview, government healthcare retail next. Early customer ที่ Constellation cite — Shopify, PayPal, On. Underneath Google เปิดเผยว่า Agent Compute Engine คือ substrate ของ Universal Gemini เป็น primitive layer ด้านล่าง product layer. ประเด็นต่อจากนี้มีสาม หนึ่ง Google position universal เทียบ Microsoft many Copilots เทียบ Salesforce Agentforce vertical — Google bet ว่า Gemini เก่ง routing พอที่ user ไม่ต้องเลือก agent เอง. สอง hard spending cap per project คือ feature ที่ CFO ขอมาก 2026 มี pattern เดียวกันหลายบริษัท — pilot agent 1 ตัว bill กระโดด 20 เท่าในไตรมาส — Google แก้ pain นี้ตรง. สาม Slack กับ Microsoft 365 integration คือ political statement — Google ยอมรับว่า enterprise hybrid ไม่ demand ย้าย 365 ไป Workspace แต่ให้ agent intelligence เลือกคนละ vendor จาก productivity suite. สำหรับ builder หา partnership กับ Google vertical bundle คือ opportunity — Universal Gemini จะ orchestrate specialized agent จาก startup ทำ task ที่ลึก. สำหรับ enterprise ไทยที่ใช้ Workspace เช่น SCG PTT True SCB Universal Gemini คือ default option — hard spending cap น่าใช้ประโยชน์ที่สุดในการ pilot agent ใน Thai SME ตั้ง cap 500 ดอลลาร์ต่อ project ทดลอง 10 project 3 เดือน แล้ววัด ROI ก่อน scale. ส่วน ecosystem Google เตรียมเป็น AWS of agent compute — host agent ของทุก vendor บน Compute Engine ขณะ compete ที่ product layer — strategy ที่ shadow AWS 2010-2015.

เรื่องที่ห้า.
AI funding tracker เผยว่า 1 ถึง 21 ตุลาคม 2026 มี AI round รวม 59 รอบ 25.7 พันล้านดอลลาร์ ตัวเลขดูมหาศาลเพราะ 20 พันล้านกว่ามาจาก OpenAI tranche เดียว ตัดออก excluding OpenAI เหลือ 5.68 พันล้านดอลลาร์ใน 58 รอบ median 15.5 ล้านดอลลาร์ ซึ่งสูงกว่า 2024 Q4 ประมาณ 2 เท่า Series A กับ B ของ agent category กำลัง command premium. รอบเด่นตุลาคม 2026 ที่ยังไม่เคย cover: Hone 60 ล้านดอลลาร์ seed สำหรับ agent ที่ own business goals หลายเดือน rhetoric แปลกเพราะ seed stage ไม่ค่อย claim long horizon, Vitalize 31 ล้านดอลลาร์ Series A สำหรับ nurse scheduling optimization — US nursing shortage คือ pain real hospital จ่าย travel nurse 7-15k ต่อสัปดาห์, Mistlabs หรือ Ambi 26 ล้านดอลลาร์ pre-Series A สำหรับ ambient agent cross device Apple ecosystem first, TrueFoundry 19 ล้านดอลลาร์ Series A สำหรับ agent LLMOps gateway enterprise control plane multi agent multi model routing, Ghost AI 11 ล้านดอลลาร์สำหรับ agent hardware. Earlier Q4: Armadin 255.5 ล้านดอลลาร์ Series B สำหรับ offensive cybersecurity ตัวเลขใหญ่สุด ex-OpenAI, Instinct 1 พันล้านดอลลาร์ Series C ที่ 10 พันล้าน valuation จาก Sequoia Benchmark Coatue personal agent, Rein Security 25 ล้าน Series A defensive sidecar. ประเด็นต่อจากนี้มีสาม หนึ่ง capital แยก 4 ชั้นชัด primitive gateway vertical ลึก consumer ambient adversarial pair ชั้นที่ขาดหายคือ horizontal glue — CrewAI LangChain AutoGen ไม่มี growth round ใหญ่ตั้งแต่กลางปี VC thesis emerge horizontal glue มี small moat high churn. สอง 60 ล้านดอลลาร์ seed สำหรับ agent ที่ own goal หลายเดือนคือ outlier ที่ควร note normally seed 3-10 ล้าน 60 ล้านสะท้อน founder reputation plus specific contract — pattern คล้าย Harvey 2023 ถ้า Hone deliver scale จะเป็น category แยกจาก task level agent ปัจจุบัน. สาม Armadin กับ Rein คือ adversarial pair ที่ VC fund ทั้งสองข้าง offensive agent plus defensive agent คือ arms race ภายใน enterprise ที่ CISO ต้อง deploy ทั้งคู่ security agent น่าจะ separate category จาก generic agent exit path ชัดกว่า. สำหรับ builder หลีก horizontal workflow glue positioning วางเองใน 4 ชั้น primitive หรือ vertical regulated หรือ consumer ambient หรือ adversarial. สำหรับ enterprise ที่เลือก agent vendor ต้องพิจารณา round stage บวก runway — Hone seed 60 ล้าน runway 3 ปี, Series A 19-31 ล้าน runway 2 ปี, Series B 100 ล้านบวก safe สำหรับ enterprise contract 3-5 ปี. Thai VC ยังไม่มี agent focus thesis ถ้า Thai founder สร้าง agent startup ที่ fit 4 ชั้นข้างต้น ต้อง tap global หรือ corporate strategic.
