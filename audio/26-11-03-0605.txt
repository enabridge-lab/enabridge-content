เรื่องแรก.
วันนี้มีข่าวจาก Dayforce ที่น่าจับตานะครับ Dayforce คือเจ้าของ HCM platform ที่คนไทยอาจไม่คุ้น แต่ประมวล form กว่า 60 ล้าน form ต่อปี บริษัทจัดงาน Dayforce Discover วันที่ 27 ตุลาคม แล้วเปิดสามของใหม่พร้อมกัน หนึ่ง Agentic HCM Platform บน data model เดียว มี Ask Dayforce เป็น natural language interface สอง Dayforce Build ที่ให้ user เขียน prompt แล้วได้ app หรือ bot ออกมา สาม Dayforce Marketplace ที่คนสามารถ publish ของที่สร้างให้คนอื่นใช้ และ monetize ได้ถ้าผ่าน Build Academy certification แต่ส่วนที่ชอบที่สุดคือ MCP connector เข้า Claude ของ Anthropic ตัว beta ให้ Claude อ่านและเขียน HR กับ payroll data ได้ ทุก write operation ต้อง human confirm ก่อน execute เริ่มจาก action set พื้นฐานเช่น approve shift submit time off engage candidate แม้ Build กับ Marketplace จะยังไม่ GA จนถึงปี 2027 แต่ตัว MCP connector นี่คือสัญญาณชัดครับว่า ERP กับ HCM vendor ทุกราย ภายใน 6 ถึง 12 เดือนต่อจากนี้ จะต้องเลือกข้างว่า default agent runtime ของพนักงาน HR คือ Claude หรือ ChatGPT ที่น่าสังเกตคือ Dayforce เลือก Claude ก่อน Copilot ทั้งที่ Microsoft เป็น partner มานานแล้ว นี่คือสัญญาณที่สามในสัปดาห์เดียวหลังจาก Cresta Conductor และ UBS ว่า Anthropic กำลังชนะศึก enterprise agent runtime มาตรฐาน ผ่าน MCP เป็น protocol-level moat สำหรับ CIO ที่ไทย คำแนะนำสั้น ๆ ครับ ตอนนี้คือจังหวะที่ต้องแยก MCP integration budget ออกจาก seat license ก่อนปี 2027 ไม่งั้นโดนเก็บ metered action charge โดยไม่มีงบ.

เรื่องที่สอง.
วันนี้มีข่าว governance ที่ตามเรื่อง UBS เมื่อสองวันก่อนครับ BetterCloud ซึ่งเป็นบริษัทลูกของ CoreStack หลังโดน acquire เมื่อ 31 มีนาคม 2026 เปิดสองความสามารถใหม่พร้อมกันเมื่อ 29 ตุลาคม หนึ่งคือ AI spend tracking ที่รวม token กับ credit consumption ของ provider ทั้งหมด เช่น OpenAI Anthropic Google เข้า view เดียว แล้วลิงก์เข้า spend module เดิมที่ลูกค้าใช้ reclaim SaaS license ที่ไม่ได้ใช้อยู่แล้ว logic เดียวกันเลยแต่ย้ายมาคุม AI subscription สองคือ agent lifecycle management ที่ให้ admin create update retire agent, scope ว่า agent ตัวไหนใช้ tool ใดได้บ้าง, grant กับ revoke user access, และ manage AI data store ของทุก project ที่น่าสนใจคือ workflow library ใหม่มี AI governance action สำหรับทุก provider ที่ cover แปลว่า admin เขียน rule ครั้งเดียวแล้วรันข้าม provider ได้ เช่นเมื่อพนักงาน offboard ให้ revoke access ของเขาจาก agent ทุกตัวบน OpenAI Anthropic Google ภายใน 15 นาที retire personal agent ของเขา และโอน data store ให้ team lead ตัวนี้ถ้าทำได้จริงจะเป็น lifecycle template มาตรฐานของ enterprise agent governance ร่วมกับ Microsoft Agent 365 และ Zendesk Employee Service Suite สิ่งที่ยังไม่เปิดคือราคาและจำนวน agent ที่จัดการได้ต่อ tenant และยังไม่มี third party validation ยังเป็น vendor claim ล้วน แต่สัญญาณชัดครับ เลเยอร์ที่ enterprise agent stack ปี 2027 ต้องมีสามชั้น identity runtime และ cost plus lifecycle governance ชั้นที่สามคือ CFO facing layer ที่ตอบคำถามว่าเงิน $ ที่จ่าย AI vendor เดือนนี้คุ้มไหม คำถามที่ UBS ยังไม่เปิด ROI เพราะไม่มีคำตอบ สำหรับ CIO ไทย ถ้ากำลัง deploy AI tool หลายตัวพร้อมกัน shortlist governance OS หนึ่งตัวที่ครอบ 4-5 provider ไว้ตั้งแต่ตอนนี้ CoreStack Microsoft Agent 365 และ Zluri เป็นสามตัวหลักให้ไปดู.

เรื่องที่สาม.
Island ซึ่งเป็น unicorn enterprise browser ที่เพิ่ง ระดมทุน Series F 400 ล้านดอลลาร์ที่ valuation 6.4 พันล้าน เปิด Enterprise Browser for Agents เมื่อ 29 ตุลาคม 2026 ครับ idea หลักคือให้ AI agent เข้า SaaS กับ internal app และเว็บ โดยใช้ browser session ของ user คนภายใต้ policy เดียวกัน แทนที่จะเรียก API ตรงไปหา service agent เข้ามาผ่าน Island MCP server ที่ build in อยู่ใน browser ไม่ใช่ MCP extension ที่ติดตั้งจาก provider อื่น admin กำหนดได้ตรง Island console ว่า agent ตัวไหนเข้าได้ เงื่อนไขอะไร tool ไหนเรียกได้ จุดที่ sharp ที่สุดคือ Island claim ว่า credential ที่ agent ใช้ ไม่ไหลผ่าน model context window agent เห็น result แต่ไม่เห็น secret ตอบ attack pattern ที่ Oasis Threat Research กับ Zenity แฉมาตลอดปีว่า MCP server รุ่นแรกส่ง credential ผ่าน context ให้ model ประมวลแล้วหลุดง่าย ส่วน browser MCP server รุ่นอื่น เช่น Comet หรือ ChatGPT Atlas Island บอกว่าใช้ screenshot เป็นหลัก ซึ่งช้ากว่าและไม่เสถียร การเลือก frame แบบนี้คือการวาง Island เป็น anti vendor browser สำหรับ enterprise ที่ไม่อยากพึ่ง browser agent ของ model vendor ที่ชอบคือ Island deploy ได้สอง mode on device กับ cloud ไม่ pin เข้า Google หรือ Perplexity cloud ที่ยังไม่เปิดคือตัวเลข early customer ราคาใหม่ และ benchmark ที่น่า takeaway ที่สุด ชัดเจนขึ้นเรื่อย ๆ ว่า enterprise agent stack ปี 2027 มีหลายชั้นไม่ใช่ one layer Island กำลัง pitch ว่า browser คือชั้นที่ enterprise ควบคุมได้โดยไม่ต้อง re plumb SaaS vendor ทีละตัว ซึ่งเป็นคำตอบที่ sharp เพราะ MCP endpoint ของแต่ละ SaaS vendor จะใช้เวลา 2 ถึง 3 ปีกว่าจะพร้อม ระหว่างที่รอ agent ที่ล็อกอิน SaaS ผ่าน browser ของ user คือทางลัดที่ไม่ต้องรอ vendor สำหรับ CIO ไทย ก่อนลงทุน AI browser ต้อง audit ทันทีว่าพนักงานกี่ เปอร์เซ็นต์ ใช้ consumer AI browser อยู่.

เรื่องที่สี่.
วันนี้มาดูเรื่อง infrastructure ที่สำคัญครับ Uber เปิด blog Designing MCP Gateway ลงวันที่ 1 ตุลาคม แล้วเพิ่งนำเสนออีกครั้งใน AAIF MCP Dev Summit ปลายเดือนตุลาคม ตัวเลขที่โดดคือ 800 กว่า MCP server และ 5,000 กว่า tool ที่รันอยู่หลัง single control surface ของ Uber ที่สำคัญเพราะ Uber ตอบคำถาม architecture ของ enterprise MCP ที่ยังไม่มี reference ชัดก่อนหน้านี้ สี่ชั้นหลัก หนึ่ง AutoCrawler ที่เป็น Cadence based workflow scan IDL registry ของ Uber หา service ใหม่กับ schema change อัตโนมัติ แล้ว register เป็น MCP tool แต่ default ปิดจนกว่า owning team จะ enable เอง สอง Omni MCP Proxy ที่แก้ปัญหาใหญ่ของ enterprise MCP ถ้า agent ต้อง list tool แล้วได้ 5,000 tool schema คืนมาจะกิน context window ของ Claude หมด Omni เปิดแค่ 4 meta tool คือ discover server, discover tools, get tool schema, และ invoke tool agent ค้นก่อนแล้วค่อย load schema ของ tool ที่จะใช้จริง สาม auth ใช้ short lived JWT ที่ carry chain of actor ว่าใครเรียก agent ตัวไหน service ไหน ถ้า agent compromised blast radius จำกัดอยู่ที่ scope ของ JWT สี่ aifx เป็น internal CLI ที่ Claude Code Cursor Codex เรียกได้ agent ไม่ต้องรัน local MCP server และ Uber มี background coding agent ของตัวเองชื่อ Minion บน stack เดียวกัน สิ่งที่ Uber ยังไม่เปิดคือจำนวน agent user จำนวน tool call ต่อวัน และ cost per call Blog เน้น architecture ไม่ใช่ operation metric ที่ takeaway สำคัญ MCP มี reference architecture ของ enterprise scale แล้ว JPMorgan Walmart Delta BP จะ copy template นี้แทบจะทันที สำหรับ enterprise ไทยที่มี microservice 100 ถึง 500 ตัวและกำลังจะเปิด MCP endpoint สำหรับ agent copy Uber blueprint ก่อนลองออกเองดีกว่าครับ สี่สิ่งต้องตั้งก่อน rollout Registry กับ ownership metadata, auto discovery pipeline, meta tool proxy, และ JWT chain plus per tool policy.
