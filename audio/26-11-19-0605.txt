เรื่องแรก.
วันนี้ขอเริ่มจากข่าวที่น่าจะเปลี่ยน default ของ enterprise agent ทั้งอุตสาหกรรม Microsoft เปิดตัว Copilot Autopilot ใน Ignite 2026 เมื่อวันที่ 18 พฤศจิกายน Autopilot เป็น autonomous agent ตัวแรกที่มี Entra identity ของตัวเอง แปลว่าเวลามันทำอะไร action ถูก log ภายใต้ account แยกจากคน ซึ่ง CISO ทั่วโลกรอฟีเจอร์นี้มานานเพราะ pattern เดิมที่ agent ทำงานในนาม user account เป็น audit nightmare เบื้องหลัง Autopilot คือ WorkIQ ซึ่งเป็น reasoning layer ที่ Microsoft อ้างว่าดึง context ข้าม 19.5 exabytes ของ Microsoft 365 data ทำให้ agent หลายตัวทำงานประสานกันได้ Autopilot ยังอยู่ใน early access แต่ Copilot Home, Office in Copilot และ Managed Runtime ถึง general availability ในวันเดียวกัน พร้อม Dynamics 365 skills 100 กว่าตัว และ CRM skills จาก Salesforce 38 ตัวในชื่อ Copilotforce วันเดียวกัน Satya Nadella ประกาศ AI Transparency Initiative กับ 40 กว่าองค์กร มี Accenture, Adobe, KPMG, Mastercard, Volvo ร่วมด้วย เป้าหมายคือพัฒนา industrywide standard ให้ agent activity verify ได้อย่างอิสระ สำหรับคนที่สร้าง agent platform signal คือต้องคิดเรื่อง identity ตั้งแต่วันแรก เพราะ Entra จะกลายเป็น default ของ regulated industry สำหรับ Thai enterprise ที่ใช้ Microsoft 365 อยู่แล้ว ควร benchmark ว่า Autopilot จะ cover use case ไหนก่อนจะไปสร้าง custom agent แข่งกับของที่ Microsoft กำลังจะ ship ฟรี.

เรื่องที่สอง.
ข่าวที่สองวันนี้ Cognition เปิดตัว Devin Bots เมื่อ 17 พฤศจิกายน Fortune ได้ exclusive Devin Bots เป็น persistent coding agent ที่อยู่ในทีม software ได้ระยะ days or weeks เข้าไปอยู่ใน Slack channel ของทีมเป็นสมาชิก เก็บ context ข้ามสัปดาห์ และติดต่อคนเมื่อติด decision ไม่ใช่แค่ chat ตอบ Bot แบ่งโปรเจกต์เป็น task แล้ว assign ให้ Devin agent หลายตัว เช่น update Android version เมื่อ iPhone version เปลี่ยน แต่ละ Bot เลือก model เอง ใช้ frontier model สำหรับ planning และ computer use และใช้ model ถูกกว่าสำหรับ routine code แต่ละ Bot มี budget ของตัวเองที่ measure กับ result ไม่ใช่ token เป็นครั้งแรกที่ product agent พูดเรื่อง unit economics ใน UI ตรง ๆ ตัวเลขของ Cognition น่าทึ่ง valuation 48 พันล้านเหรียญ annualized revenue run rate ทะลุ 1 พันล้านเหรียญ ตั้งแต่กันยายน ลูกค้า early-access มี Decagon Fireworks AI Reducto ใช้ Bot โต 10 เท่าใน 2 สัปดาห์ และที่หนักที่สุด Citigroup มี 14,000 engineers ใช้ Devin อยู่แล้ว Citi บอกว่าตัด tech vendor spend ลง 30% year-over-year สิ่งที่ Devin Bots pre-empt คือ OpenAI Dots และ Anthropic Duet ซึ่งเป็น always-on agent ของสอง lab Devin เลือก position ตรงข้าม model-agnostic routing เป็น bet ว่า enterprise ไม่อยาก lock-in กับ lab เดียว สำหรับ CTO ไทยที่มี team 50 ถึง 500 คน pattern ที่ Citi ทำได้คือตัด SaaS license ซ้ำซ้อน และรวม budget ไว้ที่ coding agent ซึ่งเป็น template ที่ realistic กว่าตัวเลข 30 เปอร์เซ็นต์โดยตรง.

เรื่องที่สาม.
ข่าวที่สามวันนี้ Model ML ที่ลอนดอน ปิด Series B 250 ล้านเหรียญที่ valuation 1.5 พันล้าน co-lead โดย General Atlantic และ QED Investors รวม total funding 350 ล้าน บริษัทผ่านจาก seed ถึงยูนิคอร์นใน 1 ปี 9 เดือน Model ML เป็น personal AI agent สำหรับ banker consultant และ investment professional ไม่ใช่ chatbot หรือ task tool แต่เป็น agent ส่วนตัวที่อยู่ใน infra ของบริษัท รันตลอด 24 ชั่วโมง และ personalize มากขึ้นเมื่อใช้ไปเรื่อย ตัวอย่าง use case คือ research ข่าวบริษัทลูกค้าแล้วเตรียม output ใน format ที่ firm ใช้ประจำ ซึ่งเป็น workflow ของ junior analyst ตัวเลข Q3 น่าสนใจ ARR โต 12 เท่า DAU โต 26 เท่า แต่ไม่เปิดเผยตัวเลข absolute บริษัทบอกว่า product อยู่ใน bank ขนาดใหญ่ของโลก แต่ไม่ยอมบอกชื่อ และถือ certification ISO 27001 และ SOC 2 Type II ซึ่งเป็น table stakes ของ buyer regulated จุดที่น่าทึ่งที่สุดคือ Model ML สร้าง own fine-tuned open-source model ที่ cost ประมาณ 2 เปอร์เซ็นต์ของ frontier model และวิ่งเร็วกว่า 5 เท่า แปลว่าบริษัทกำลัง decouple จาก price ของ OpenAI หรือ Anthropic ซึ่งเป็น risk ที่ founder vertical agent หลายคนกังวล สำหรับธนาคารไทยที่มี banker 500 ถึง 5,000 คน Model ML เป็น proof ว่า personal agent per professional ทำได้จริง Enabridge ที่ลูกค้าในกลุ่มการเงินไทยควร pitch ว่าจุดต่างคือ ภาษาไทย กฎ regulator ไทย และ integration กับ core banking ไทย ซึ่งเป็น 3 moat ที่ global vendor สร้างยาก.

เรื่องที่สี่.
ข่าวที่สี่วันนี้เป็น infrastructure story ที่ enterprise architect ไทยต้องฟัง Uber publish engineering blog เรื่อง MCP Gateway บอกว่า MCP Gateway ของ Uber เป็น foundational microservice ที่ powers MCP interaction ทุกตัวในบริษัท ตอนนี้ host 800 MCP servers กับ 5,000 tools ภายใต้ control surface เดียว problem ที่ gateway แก้มี 4 อย่าง duplicate infra ที่ทีมสร้างซ้ำ tool discovery ที่ไม่มี control plane protocol fragmentation ระหว่าง HTTP gRPC TChannel และ security risk จาก permission กระจัดกระจาย Uber แยกเป็น control plane คือ MCP Registry กับ data plane คือ Proxy Gateway ที่ translate MCP เป็น HTTP gRPC TChannel แล้วกลับ มี AutoCrawler ที่ scan IDL registry แล้วสร้าง MCP server tool อัตโนมัติ และที่สำคัญคือ Omni MCP pattern ที่ agent ไม่ต้องโหลด schema ของ tool ทุกตัวเข้า context รวมกัน แต่ discover แบบ incremental ผ่าน 4 primitive ผลลัพธ์คือ per-session tool schema overhead ที่เคยอยู่ 50 ถึง 70 พัน tokens ต่อ session ลดลงเหลือ near-zero ตามที่ Uber claim สิ่งที่สำคัญคือ MCP กลายเป็น service mesh for agents ของ Uber จริง ไม่ใช่ experiment เล็ก ๆ อีกต่อไป เป็น signal ที่ enterprise ไทยที่มี microservice architecture ซับซ้อน ควรวาง MCP Gateway กลางเป็น investment ที่ payoff ชัดกว่าให้แต่ละทีมสร้าง integration เอง Enabridge ควรเสนอ managed MCP Gateway เป็น service เพื่อลด cost ของ central IT ไม่ต้อง maintain gateway เอง.

เรื่องที่ห้า.
ข่าวที่ห้าวันนี้ Chargebee เปิดตัว Arc เมื่อ 18 พฤศจิกายน Arc เป็น agentic finance platform ที่ ship 3 agent ทำงานใน back-office ของทีม finance อันแรกคือ contract ingestion อ่าน signed contract แล้ว propose billing setup กลับไปให้ team อันที่สองคือ receivables เตรียม collection work เช่น draft reply ตอน customer promise to pay อันที่สามคือ revenue recognition trace ว่า contract amendment แต่ละครั้งเปลี่ยน revenue อย่างไร ทุก action ของ agent แสดง reasoning cite source และต้อง review ก่อน commit Chargebee launch Agent Studio พร้อมกัน เป็น workspace ที่ customer สร้าง custom agent เอง เป็น hedge strategy ที่ Snowflake กับ Databricks ทำอยู่ 3 task ที่ Arc เลือกไม่ใช่สุ่ม เป็น 3 pain point ที่ CFO ใน subscription business ถามหาทุกไตรมาส contract ingestion ใช้เวลาของ junior analyst 40 ถึง 60 เปอร์เซ็นต์ receivables ตัดสิน DSO ของบริษัท revenue recognition ภายใต้ ASC 606 เป็น compliance pain ที่ auditor ชี้ error บ่อยสุด Context จาก PYMNTS Intelligence บอกว่า 12 เปอร์เซ็นต์ของ US CFO ที่บริษัท revenue 1 พันล้านขึ้น ใช้ AI agent อยู่แล้ว อีก 23 เปอร์เซ็นต์ explore สำหรับทีม finance ของ Thai enterprise ไม่ต้องรอ Chargebee มา Enabridge ที่ลูกค้ามี pain point ซ้ำ ๆ ใน 3 task นี้ควร pitch pattern เดียวกัน ship 3 agent เฉพาะทางพร้อม Agent Studio และ integrate กับ ERP ไทย เช่น SAP Business One Microsoft Dynamics Business Central หรือ PEAK.
