เรื่องแรก.
วันนี้มีข่าวใหญ่จาก UBS ที่น่าสนใจมากครับ UBS รายงานผลประกอบการ Q3 แล้วใส่ตัวเลข AI agent ลงใน earnings slide เลยนะ ไม่ใช่ marketing deck พนักงาน UBS รัน personal AI agent มากกว่าหนึ่งหมื่นสองพันเจ็ดร้อยตัวในงานประจำวัน มี production use case 608 ตัวที่เพิ่มขึ้นแปดสิบเอ็ดเปอร์เซ็นต์จากปีก่อน และกำลังสร้างอีกพันเก้าสิบตัว tool ที่ชื่อ STAAT สำหรับ financial advisor สร้าง insight ไปแล้วสามสิบล้านครั้ง และนักพัฒนาหนึ่งหมื่นแปดพันคนใช้ AI tooling ประจำวัน จุดสำคัญไม่ใช่ตัวเลข แต่คือการที่ bank tier หนึ่งเลือกเปิดตัวเลข agent ใน earnings call ซึ่งแปลว่า auditor กับ IR team ตรวจแล้วและคิดว่าตัวเลขนี้ต้อง benchmark กับคู่แข่ง ปีหน้า JPMorgan Morgan Stanley Deutsche Bank น่าจะต้องเปิดตัวเลขเดียวกัน อีกจุดที่น่าสังเกต UBS มี personal agent หนึ่งหมื่นสองพันเจ็ดร้อยตัวแต่มี production use case แค่ 608 ตัว แปลว่าพนักงานสร้าง agent ของตัวเองเยอะกว่า central team หลายเท่า นี่คือ employee-driven agent sprawl ที่ Mintive เรียกว่าปัญหา governance อันดับหนึ่งของปีหน้า CFO ที่ไทยและ SEA ควรเริ่มคิดเรื่อง per-employee agent budget ไม่ใช่ per-use-case budget ตั้งแต่ตอนนี้ครับ สิ่งที่ UBS ไม่พูดก็สำคัญ ไม่มีตัวเลข cost saving ไม่มี time to decision reduction ยังเป็น activity metric ไม่ใช่ outcome metric — ต้องรอดูอีกสองไตรมาสว่า cost income ratio จะขยับยังไงต่อ.

เรื่องที่สอง.
Sema4.ai ปล่อย platform 3.0 เมื่อวันที่ 30 ตุลาคม จุดเปลี่ยนใหญ่คือย้ายจาก personal agent ไปเป็น team workspace หลายคนในทีมแชร์ agent skill memory data ร่วมกันใน governed workspace เดียว แต่สิ่งที่น่าสนใจกว่าชื่อ feature คือตัวเลขที่บริษัทกล้าเปิด Verified Queries ที่ reuse pattern การ access data ที่ approve แล้วแทนที่จะให้ model generate SQL ใหม่ทุกครั้ง ตัด token ลง 80% และเร็วขึ้น 4 เท่า Verified Logic reuse calculation ที่ check แล้วลด token อีก 50% เร็วขึ้น 30% พูดอีกแบบ Sema4 กำลังเดิมพันกับ thesis ที่ค่า token ไม่ลดเร็วพอถ้า agent รัน query เดิมซ้ำร้อยครั้งต่อวัน การ cache + verify pattern คือ anti pattern ของยุคถาม LLM ทุกอย่าง และเป็นสิ่งที่ CFO ต้องการเห็นในปีหน้า integration day one กับ Claude Cowork Microsoft Copilot Microsoft Fabric ส่งสัญญาณชัดว่า Sema4 ไม่พยายามแทน hyperscaler แต่เป็น agent layer เหนือ stack เหล่านั้น สิ่งที่บริษัทยังไม่เปิด customer name pricing baseline เทียบของตัวเลข 80 เปอร์เซ็นต์ ยังขาด credibility ถ้าคุณกำลัง scale agent ใน enterprise ให้ประเมิน Sema4 ก่อนไปสร้าง framework เอง การย้าย query 80 เปอร์เซ็นต์ไป verified cache คือ ROI ที่พิสูจน์ได้ที่ bill เดือนถัดไปครับ.

เรื่องที่สาม.
Cresta ประกาศวันที่ 29 ตุลาคมว่า Conductor ซึ่งเป็น agent builder ที่สร้างบน Claude Agent SDK เปิดให้ enterprise developer self service ไม่ต้องรอ professional service team ของ Cresta แล้ว นั่นหมายความว่า developer เขียน Python เอง deploy ผ่าน CLI ใช้ Git และ CI CD เดิม แล้ว Cresta provide infra layer คือ A B test routing rollback access management cost tracking บริษัท quote ว่าใช้เวลา 1 สัปดาห์จาก requirement แรกไป production เร็วกว่าเดิม 5 เท่า ยืนยันด้วย deal 8 หลักกับ Atento ที่เป็น BPO ใหญ่ที่สุดใน LatAm และมีสาขาที่ไทย compliance ของ Cresta ครบ SOC 2 ISO 27001 PCI DSS HIPAA และที่น่าสังเกต ISO 42001 ซึ่งเป็นมาตรฐาน AI management system ของ ISO ที่พึ่งปล่อยปี 2024 vendor ส่วนใหญ่ยังไม่คุย Cresta เป็นหนึ่งใน CX vendor แรกที่ claim จะกลายเป็น table stakes ของ RFP ปีหน้าเมื่อ EU AI Act bind ตัวจริง ที่น่าสนใจที่สุด Cresta เลือก Claude Agent SDK แทนที่จะสร้าง runtime เอง — ปีนี้ Anthropic สะสม big name adopter เร็ว Honeycomb Replit Vercel Cresta pattern คือบริษัทที่มี vertical expertise ไม่อยากสร้าง agent harness เองจาก scratch เลือก Claude Agent SDK เพราะ tool use context management sandbox มาพร้อม ปีหน้าสงคราม agent runtime มาตรฐานน่าจะเห็น Claude Agent SDK vs OpenAI Agents SDK ชนกันตรงๆ ครับ.

เรื่องที่สี่.
วันที่ 30 ตุลาคม OpenAI ประกาศ 5 update ของ Agents API ผ่าน X ตัวแรก Auto Review นำกลไกจาก Codex มาเป็น API primitive ตรวจ command ก่อนรันเพื่อหา behavior ที่น่าเป็นห่วง เช่นลบไฟล์ส่งคำขอ network destructive op ตอบ pattern agent ลบไฟล์ตัวเอง หรือ push code เสียลง main ที่เราเห็นในข่าว security ตลอดปี 2026 ตัวที่สอง async compaction compact context รัน background session ยาวไม่ค้าง ตัวที่สาม time awareness ให้ model track elapsed time เพื่อ timebox งาน บริษัทบอกว่ายัง experimental แนะให้มี hard timeout คู่ ตัวที่สี่ mid session tool update เปลี่ยน tool list ระหว่าง session ได้ ตัวที่ห้า automatic system prompt caching ข้าม session ตัว cost สำคัญสำหรับ multi session app ที่น่าสังเกต update นี้มาพร้อม AgentKit wind down 30 พฤศจิกายน Agent Builder visual จะถูกปิด OpenAI ยอมรับว่า low code visual builder ไม่ scale กับ enterprise CTO ที่ลงทุน Agent Builder มี 1 เดือนย้ายไป Agents SDK pattern ใหญ่ที่เห็นปีนี้คือ low code agent builder ถดถอยทั่วตลาด Microsoft Google Salesforce ขยับไปทางเดียวกัน ชนะคือ code first strong primitive และ Anthropic กับ OpenAI กำลังชิงเลเยอร์ agent runtime ไม่ใช่ model layer อีกต่อไปครับ.

เรื่องที่ห้า.
Persona บริษัท identity verification ที่ valuation ล่าสุด 2 พันล้านเหรียญ เปิดตัว Persona AI เมื่อ 30 ตุลาคม สาม layer คือ Persona Assistant Persona Agents และ Persona Extend ตัว Agents ทำ case review อัตโนมัติ รวบรวม evidence เทียบ policy ของ customer แล้ว recommend decision พร้อม visible reasoning แต่ human ยังต้อง approve consequential decision ส่วน Extend เป็น MCP server ที่ expose Persona data ให้ agent ของ customer เอง เรียกใช้ ตัวเลขที่เปิด 30 กว่า early access customer หลายแสน identity decision ใน production บริษัทไม่เปิด customer name ไม่เปิด accuracy rate ไม่เปิดตัว time reduction thesis ของ Rick Song ซีอีโอ บอกว่าโลก agent ทำให้คำถาม who is behind the bot กลายเป็นคำถาม infrastructure identity verification จะต้องเริ่ม verify agent ไม่ใช่แค่คน pattern ใหญ่ที่กำลังชัดคือ enterprise AI stack ปี 2027 จะมี 3 เลเยอร์ identity หนึ่ง user identity สอง agent identity สาม agent to service verification ที่ Persona กำลังเล่น ถ้าคุณทำ fintech healthcare crypto marketplace agent ของ customer อาจเริ่มเรียก API คุณ ถ้าระบบยัง authenticate แค่ password 2FA ภายใน 12 ถึง 18 เดือน จะ break ควรออกแบบ agent credential flow ตั้งแต่ตอนนี้ครับ.
