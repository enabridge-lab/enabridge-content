เรื่องแรก.
วันนี้มีข่าวใหญ่จาก Anthropic ที่น่าจะเปลี่ยน procurement question ของ enterprise agent ไปเลยครับ 12 พฤศจิกายน 2026 Anthropic เปิด private beta ของ self hosted Claude Managed Agents ลูกค้ารัน agent harness รัน sandbox รัน credentials และ session history บน cloud หรือ on prem ของตัวเองได้ทั้งหมด แต่ model call ยังออกไปข้างนอกเลือกได้ว่าจะไป Anthropic AWS Bedrock Google Cloud หรือ Microsoft Foundry มีคนบอกว่านี่คือการย้าย address ของ agent service ไม่ใช่ย้าย address ของ model จุดสำคัญคือหลัง UBS เปิดตัวเลข 12,700 personal agent ใน earnings call แล้ว Mintive เตือนว่า credential sprawl คือ governance crisis อันดับหนึ่งของปี 2027 Anthropic เป็นเจ้าใหญ่รายแรกที่ยอมให้ control plane ออกจาก cloud ตัวเอง OpenAI ยังไม่ปล่อย self hosted Agents API ครับ pattern นี้คล้ายกับ GitHub Enterprise Server ที่ชนะใจ bank กับ defense contractor ในยุค DevOps ให้ compute อยู่ในบ้าน ให้ model เช่า นี่คือ compromise ที่ regulator ยอม สำหรับ CISO ไทย SEA ที่กำลังโดน BOT โดน SEC โดน OIC ถามเรื่อง AI governance ต้องเปลี่ยน procurement question จาก vendor มี SOC 2 มั้ย เป็น vendor ให้ harness รันใน VPC ของเราได้มั้ย ถ้าไม่ได้ให้ add clause ใน RFP รอบถัดไปเลยครับ สำหรับ LangChain Cresta Sema4.ai ที่ขายเป็น SaaS ตอนนี้โดน pressure ต้องมี on prem edition เร็วๆนี้ ส่วนคนที่ได้ประโยชน์ทันทีคือ AWS GCP Azure เพราะ compute instance เพิ่มขึ้น Postgres managed service ก็ได้ด้วย ส่วนคนที่เสียคือ pure SaaS agent vendor ที่ไม่มี on prem play ครับ.

เรื่องที่สอง.
วันนี้ข่าวใหญ่ของวงการ AI Agent คือ LangChain ปิด Series C ที่ 300 ล้านดอลลาร์ นำโดย CapitalG ของ Alphabet ร่วมด้วย GIC จากสิงคโปร์ DFJ Growth และนักลงทุนเก่า IVP กับ Sapphire Ventures valuation ขึ้นไปที่ 3 พันล้านดอลลาร์ step up 2.4 เท่าจากรอบ Series B ที่พึ่งปิดเมื่อปีที่แล้ว บริษัทเปิดตัวเลขว่า LangSmith ซึ่งเป็น observability และ evaluation platform สำหรับ agent มี customer มากกว่า 7,000 ราย thesis ของ CapitalG คือ enterprise ไม่อยากซื้อ agent stack จาก OpenAI หรือ Anthropic หรือ Google โดยตรงเพราะไม่อยาก lock in กับ vendor เดียว LangChain position ตัวเองเป็น Switzerland of AI agents ใช้กับ model ไหน provider ไหนก็ได้ pattern นี้คล้ายกับ Datadog ยุคแรกที่ขึ้นมาอยู่เหนือ AWS Azure GCP แม้ทุก cloud มี monitoring ของตัวเองแล้ว enterprise ก็ยังเลือก Datadog เพราะ one pane across clouds สำหรับคนสร้าง agent app ในไทย ถ้าคุณ build stack ให้ลูกค้าที่ต้องการ vendor agnostic LangGraph บวก LangSmith ยังเป็น default ที่ procurement team ของแบงก์ยอมรับ ถ้าคุณผูกกับ Claude หรือ GPT อย่างเดียวอย่าเติม LangChain แค่เพื่อให้ดูน่าเชื่อถือ overhead จริง สำหรับ CFO ไทยที่เบื่อ BOM ของ Datadog OpenTelemetry Grafana กับ tracing แยกแต่ละ model ปีหน้าเป็นเวลาที่ดีที่จะ consolidate ไปที่ LangSmith จุดที่ต้องจับตา คือ Databricks ที่ขาย Agent Bricks กำลังเป็น competitor ใหญ่ที่สุดของ LangChain ไม่ใช่ model lab ครับ.

เรื่องที่สาม.
วันนี้มีข่าว round ใหญ่มากของ Mirendil บริษัท AI ที่ก่อตั้งโดยอดีตนักวิจัยจาก Anthropic กับ Google DeepMind ปิด Series A ที่ 1 พันล้านดอลลาร์ นำโดย Kleiner Perkins กับ Clearlake Capital ร่วมด้วย Battery Google M13 Pear VC S32 Bloomberg เคยรายงานก่อนหน้านี้ว่า valuation อยู่ที่ประมาณ 5 พันล้านดอลลาร์ แต่บริษัทไม่ยืนยันเอง เพียงครึ่งปีก่อนเพิ่งปิด seed ที่ 200 ล้านดอลลาร์ แปลว่า valuation ขึ้นอาจ 10 เท่าในเวลา 5 เดือน Product หลักของบริษัทชื่อ Lor ยังอยู่ใน private beta coordinate agent หลายร้อยตัวให้เขียน code และรัน experiment หลายวัน model ของบริษัทเองชื่อ Fern context 10 ล้าน token ประมาณ 5 แสนบรรทัด code บริษัทอ้างว่า agent เขียน code ของ Mirendil-Base มากกว่า 99 เปอร์เซ็นต์ ส่วนที่น่าสังเกตคือทุก frontier lab อย่าง Anthropic OpenAI Google DeepMind มี internal tooling ประมาณนี้แต่เก็บเงียบ Mirendil คือเจ้าแรกที่ยอมเปิดเป็น product นี่เป็น bet ว่า AI lab operation เองก็ถูก disrupt ได้ด้วย agent ที่ต้อง skeptical คือ 99 เปอร์เซ็นต์ของ code อาจหมายถึง autocomplete บวก boilerplate ไม่ใช่ research contribution จริง และ 10 ล้าน token context ยังไม่มี benchmark independent สำหรับคน build agent app ในไทย บทเรียนคือ orchestration ของ agent หลายร้อยตัวคือ frontier challenge ของปีหน้า ไม่ใช่แค่ chain prompt ธรรมดา สำหรับ CTO ไทย ที่ยังมี agent หนึ่งตัวต่อ workflow ควรเริ่มคิด architecture สำหรับ agent fleet 100 ถึง 1000 ตัว UBS บอกเรา 12,700 personal agent Mirendil กำลังบอกว่าลืม personal agent ไปเถอะ agent fleet 100 ถึง 1000 ทำงานคู่กันต่างหากคือ future ครับ.

เรื่องที่สี่.
วันนี้มีข่าวใหญ่จากฝั่ง big tech enterprise ที่ IBM กับ Microsoft ประกาศเมื่อ 10 พฤศจิกายน เปิดตัวแพลตฟอร์มชื่อ Imagine Enterprise ที่ co-built co-sold co-delivered ร่วมกัน สำหรับ build run และ govern AI agent เฉพาะอุตสาหกรรม จะเริ่มที่ banking insurance retail ก่อน แล้วค่อยขยายไป manufacturing energy public sector mobility จุดเด่นคือ seed ด้วย prebuilt agent และ asset ที่ IBM Consulting สร้างไว้แล้วกว่า 6,000 ชิ้น PYMNTS เป็นแหล่งเดียวที่ย้ำว่าเป็น agent บวก asset ไม่ใช่ deployable agent 6,000 ตัวเฉพาะ Stack ใช้ IBM Consulting Advantage คู่กับ Microsoft Foundry Copilot Studio GitHub Copilot Fabric Entra Purview Defender แปลว่า IBM ส่งคน Microsoft ส่งโครงสร้าง ลูกค้าเลือกได้สามแบบ ให้ IBM Consulting ทำให้ทั้งหมด ร่วมมือกับ IBM Consulting หรือ self-manage เอง ตัวเลือกแรกจะทำเงินให้ IBM สูงสุดเพราะ consulting hours คือ revenue หลัก ที่ยังไม่เปิดคือราคา ไม่มี named customer ใน production ไม่มี benchmark outcome ครับ สำหรับ builder ที่กำลัง sign IBM หรือ Microsoft เป็น partner อาจ wrap product เข้า marketplace ได้แต่ margin split จะเน่า IBM เอา 40 ถึง 60 เปอร์เซ็นต์ สำหรับ CTO ไทยของแบงก์ ประกันภัย retail chain ที่เป็นลูกค้า IBM หรือ Microsoft อยู่แล้ว ให้เรียก sales มา demo 6,000 asset ถ้าชี้ asset ภาษาไทยหรือ SEA ได้ชัดคือจริง ถ้าได้แต่ English US template แปลว่าใช้ไม่ได้จริง consulting hours จะ localize เยอะเกิน สำหรับ Accenture Deloitte PwC นี่คือ pressure ต้องสร้าง own asset catalog แข่งไม่งั้นจะโดน IBM กินดีล Fortune 500 ไปเงียบๆ ครับ.
