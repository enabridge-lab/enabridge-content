3 พฤศจิกายน Menlo Ventures ปล่อย State of Enterprise AI รอบปี 2026 ตัวเลขที่ออกมาสะเทือน ecosystem อยู่สองสาม จุด แรก enterprise จ่ายเงินลง AI deployment 176 พันล้าน usd ภายใน 9 เดือน เพิ่ม 5.4 เท่าจาก 33 พันล้านปีที่แล้ว ส่วนที่น่าตกใจกว่าคือ บริษัทที่ตอบ survey ใช้จริง 4.7 เท่า ของปีก่อน ทั้งที่วางแผนแค่ 1.9 เท่า นั่นคือเกินแผนไปแล้ว 2.5 เท่า สอง 55 เปอร์เซ็นต์ ของ budget ที่เพิ่มขึ้น มาจาก new budget ไม่ใช่ย้ายจาก software line เดิม แปลว่า CFO ยอมเปิดกระเป๋าให้ AI เป็นหมวดใหม่ ไม่แตะงบ SaaS. สาม ตัวเลขที่พลิกเกม 80 เปอร์เซ็นต์ของ token usage ตกอยู่กับ agent ไม่ใช่ chat กับคนอีกต่อไป ปีเดียว chat กลายเป็น agent. สี่ Anthropic OpenAI Google รวมกัน 69 เปอร์เซ็นต์ ของ deployment spend frontier lab 3 เจ้า lock ตลาด enterprise แล้ว. Takeaway สำหรับทุกคน ถ้าเราตั้ง AI budget ไว้ Q4 นี้ ตามแผนต้นปี มีโอกาสสูงมากว่าจะเกิน — ต้องเริ่มวาง per agent cap และ observability ตั้งแต่สัปดาห์นี้ ไม่ใช่รอข้ามปี.

4 พฤศจิกายน Adobe ประกาศว่า CX Enterprise Coworker — agent ที่ Adobe เปิดตัวเมื่อ Summit เดือนเมษา และ GA เมื่อ มิถุนา ตอนนี้วิ่งอยู่ใน Claude Enterprise ChatGPT Enterprise Gemini Enterprise Microsoft 365 Copilot และ Databricks แล้ว ส่วน AWS IBM Snowflake จะตามเร็วๆนี้. ท่านี้สำคัญ เพราะ Adobe เป็น SaaS incumbent ที่หุ้นลง 30 เปอร์เซ็นต์ปีนี้ กลัวโดน AI กดราคา — แทนที่จะปกป้องผู้ใช้ให้ลงมาใน Adobe app Adobe เลือกส่ง agent ของตัวเองไปอยู่ทุก surface ที่ user เปิด pattern นี้สวนกับ playbook SaaS เดิม. Salesforce เลือกรัน Agentforce ของตัวเอง ServiceNow เลือก MCP marketplace Adobe เลือกกระจาย — คนที่ชนะเร็วที่สุด คือ Anthropic เพราะ Claude Enterprise ถูก Adobe ชื่อขึ้นก่อน และเดือนก่อน SAP ก็เลือก Claude เป็น reasoning layer ของ Autonomous Enterprise. ปี 2027 จะเกิด marketplace ของ enterprise agent ข้ามหลาย LLM ประเด็นคือใครเก็บ revenue ใคร own customer. Takeaway สำหรับ CMO ไทย ถ้าใช้ Adobe Experience Cloud อยู่แล้ว ไม่ต้องย้าย tool แต่ต้อง audit data egress และ DPA กับ LLM provider ที่จะเข้าถึง campaign data ของเรา ก่อนเปิด Coworker ในงาน real.

เรื่องที่สาม.
3 พฤศจิกายน ที่งาน Fal.Con Europe ที่ Amsterdam CrowdStrike ประกาศว่า Falcon Guardian AI Detection and Response — tool EDR ของบริษัท — เข้าไปวางคู่กับ Anthropic Claude Cowork แล้ว. Cowork คือ VM ที่ Anthropic ให้ enterprise รัน Claude Agent พร้อม filesystem browser terminal. ของใหม่ที่ Falcon เข้ามาทำคือ monitor behavior ของ agent ระดับ process syscall network ตรวจ prompt injection ตรวจ data exfiltration และมี AI kill switch — ถ้า detect พฤติกรรมน่าสงสัย admin หยุดได้ทันที. Status ตอนนี้ยังเป็น beta Linux sensor รันใน VM บน Mac และ Windows — ไม่ monitor host ของ dev — scope ดีสำหรับ privacy. ภาพใหญ่คือ เลเยอร์ security รอบ agent runtime ก่อตัวเร็วมาก ไม่กี่สัปดาห์มานี้มี Mintive จับ agent identity, Persona จับ user ต่อ agent, Sentra เพิ่งปิด 150 ล้าน เหรียญ จับ agent data access — รอบเดียวกับที่ CrowdStrike วิ่งเข้าจับ agent behavioral. คนที่จับได้ 2 ใน 4 จุดคือ win enterprise contract ปี 2027. Takeaway สำหรับไทย ถ้าแบงก์หรือ FSI ใช้ Falcon อยู่แล้ว การขยับไปลอง Cowork ง่ายขึ้นเพราะ security policy ย้ายต่อได้ ไม่ต้องสร้าง runbook ใหม่ ต้องเช็ค licensing และ DPA ก่อน enable ในงาน production.

4 พฤศจิกายน Sentra บริษัทอิสราเอล ที่ทำ data security สำหรับยุค agent ปิด 150 ล้าน เหรียญ นำโดย Capital One Ventures. Bessemer Zeev Standard Munich Re Key1 ร่วมด้วย Capital One ส่งตัวแทนขึ้นบอร์ด แปลว่าไม่ใช่แค่เขียน check แต่ bank tier 1 เลือก sit at the table. Sentra อ้าง 300 เปอร์เซ็นต์ YoY total funding ผ่าน 250 ล้าน. Product ของ Sentra จะ scan data ใน tenant ลูกค้า S3 Snowflake Databricks SharePoint 300 กว่า source แล้ว map ว่า user service account และ agent ตัวไหนเข้าถึงอะไรได้ enforce least privilege ตัด permission ที่เยอะเกินออก. จุดที่ต้องสังเกต Sentra เป็น data-at-rest policy layer ไม่ใช่ inline firewall ระหว่าง agent กับ data real-time — scale ง่ายกว่าแต่ยังต้องพึ่ง IAM downstream. ภาพใหญ่ เลเยอร์ security รอบ agent ก่อตัว 4 ล้อ CrowdStrike จับ runtime behavior Mintive agent identity Persona user ต่อ agent Sentra และ Cyera data access. คนที่ประสาน 2 ใน 4 ได้คือ win contract bank ปี 2027. Takeaway สำหรับ SME ไทย ก่อนเปิดให้ agent ยิง query เข้า data store ทำ access review ของ service account รายไตรมาส — baseline ที่ auditor ขอแน่นอน.

2 พฤศจิกายน Anthropic ปล่อย Message Threads ขึ้น public beta บน Messages API. กลไกคือ แทนที่ agent จะส่ง conversation เต็ม 800 กิโลไบต์ทุก turn เราส่งเต็มครั้งเดียว รอบต่อไปส่งแค่ new message กับ thread ID เท่านั้น ประมาณ 1.8 กิโลไบต์ ที่เซิร์ฟเวอร์ Anthropic เก็บ state ไว้ encrypted in memory 5 นาที ผลที่ได้ TTFT ลด 35 เปอร์เซ็นต์ สำหรับ request ขนาด 500 K ถึง 1M token Claude Code เปิด default แล้ว available ทั้ง native Claude Bedrock Azure Foundry และ Vertex. Caveats สำคัญ สาม ข้อ. หนึ่ง token usage ไม่เปลี่ยน ประหยัดแค่ network และ input processing. สอง TTL แค่ 5 นาที agent ที่รันยาวต้อง reconstruct เอง. สาม ไม่ compatible กับ zero data retention และ HIPAA — regulated industry รอ compliant variant ต้นปี 2027. ภาพใหญ่ OpenAI มี Responses API อยู่แล้ว Anthropic เลือก path แตก ต่าง — Framework layer แต่ละเจ้าต้อง detect header แล้ว route request ให้ถูก Vercel AI SDK LangGraph น่าจะ ship เร็วสุด. Takeaway สำหรับ builder enable วันนี้ได้ทันทีถ้า use case ไม่ต้อง ZDR coding agent research customer support benefit หนักสุด เก็บ canonical history ของตัวเองไว้เสมอ กัน thread หมดอายุ.
