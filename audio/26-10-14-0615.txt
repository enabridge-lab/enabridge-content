เรื่องแรก.
วันที่แปดตุลาคม Google Cloud ปล่อย Gemini Agent ที่งาน Gemini at Work สองหกเป็น universal agent ตัวแรกที่กล้ายอมเอา Claude ของ Anthropic ซึ่งเป็นคู่แข่งโดยตรงมาใส่ใน prompt box ของตัวเอง แล้วให้ Smart Routing เลือกให้ว่างานไหนจะวิ่งผ่าน Gemini หรือ Claude โดยคิดจาก quality กับ cost เป็นหลัก ที่น่าทึ่งกว่านั้นคือ agent ตัวนี้ได้ identity ของตัวเองเป็น email คนหนึ่งในบริษัท มี inbox มี calendar มี Drive storage ของตัวเอง สามารถ accept meeting ได้ ส่ง email ได้ เก็บ artifact ไว้แล้ว resume งานได้อีกสามวันข้างหน้า นี่คือครั้งแรกที่ hyperscaler ยอม collapse workflow ของ human in the loop ไปสู่ human adjacent agent ใน Workspace Business กับ Enterprise โดยไม่คิดค่า add on แยก แต่ pricing กับ GA date ยังไม่เปิด admin คุมได้ด้วยการตั้ง spending threshold ระดับ project ถ้าถึง limit agent จะ pause ตัวเอง สิ่งที่ชัดคือ Anthropic ได้ distribution ที่ต่อสายไปถึง Workspace user สามพันล้านคนในชั่วข้ามคืน OpenAI จะต้องตอบ Microsoft จะต้องตัดสินใจว่าจะเปิด Copilot ให้ route ไปที่ model คู่แข่งเหมือน Google ไหม สำหรับ CIO ไทยที่กำลัง sign Copilot หรือ ChatGPT Enterprise ขอ POC Gemini Agent คู่กัน ดู long running task retention กับ audit trail quality เป็นหลัก คนที่สร้าง agent framework ต้องเริ่มคิดว่า vertical workflow หรือ specialized routing คือ moat ที่เหลือเพราะ universal agent กำลังเป็น commodity ที่ hyperscaler แจกฟรี.

เรื่องที่สอง.

เรื่องที่สาม.
วันที่ 8 ตุลาคม Rein Security ปิด Series A ที่ 25 ล้านเหรียญ co-lead โดย Glilot Capital กับ Sienna Venture Capital รวม total funding เป็น 35 ล้านเหรียญ จุดต่างจาก Lasso Prompt Security Noma คือ patent pending sidecar architecture ที่ไม่ sit ที่ gateway หรือ proxy แต่ติดข้าง process ของ agent เอง มองเห็นทุก line of code ที่รัน ทุก resource ที่ถูก access แล้ว block action ที่ไม่ปลอดภัยก่อน execute ตัวเลขที่น่าสนใจ นับจาก launch มกราคม 2026 revenue โต 8 เท่า customer base โต 5 เท่า Dun and Bradstreet กับ Lemonade เป็น named customer อ้างว่าใช้ Rein ปกป้อง agent หลักพันตัว pattern ที่ชัด 90 วันผ่านมา มี 3 ดีลสำคัญในชั้น agent trust layer Cyera ซื้อ Oasis หนึ่งพันล้าน Baselayer Series A 35 ล้าน Rein 25 ล้าน รวมกับ Cisco ซื้อ Astrix Palo Alto ซื้อ CyberArk 25 พันล้าน ตลาด non human identity กับ agent runtime security กำลัง consolidate เร็วกว่า Gartner คาด sidecar กำลังชนะ gateway ด้วยเหตุผลเดียวกับที่ service mesh ชนะ API gateway บน microservice 7 ปีก่อน gateway เป็น bottleneck + ownership ของ auth flow sidecar decentralized ติดกับ workload สำหรับ CISO ไทยที่ยัง approve agent deployment case by case ต้องมี runtime guardrail primitive ภายในไตรมาสหนึ่ง 2027 เลือก sidecar สำหรับ multi step complex gateway สำหรับ simple RAG ที่สำคัญ check support ของ framework ที่ใช้อยู่ก่อนซื้อ สำหรับ builder ที่สร้าง vertical agent ภายใน 12 เดือน enterprise จะ require integrate กับ runtime guardrail vendor อย่างน้อยหนึ่งค่าย ไม่ build in day one จะหลุด RFP ที่ regulated industry ทันที.

เรื่องที่สี่.
วันที่ 7 ตุลาคม Nous Research ปิด Series B 90 ล้านเหรียญที่ valuation ที่ Wall Street Journal รายงาน 1.5 พันล้านเหรียญ รวม total funding 158 ล้านเหรียญ Lead investor ยังไม่ชัด บาง source อ้าง Robot Ventures บางเจ้าบอกยังไม่ name เงินรอบนี้จะไปที่ Hermes for Businesses enterprise version ของ open source agent ที่ Nous ปล่อย open ปี 2023 ตัวเลข traction ที่น่าทึ่งที่สุดคือ Hermes agent ถูก clone 24 ล้านครั้ง คิดเป็นประมาณ 2.5 เปอร์เซ็นต์ของ global AI token usage ตามการประเมินของบริษัทเอง และ WSJ รายงาน annualized revenue 36 ล้านเหรียญ ซึ่งถ้าตัวเลขจริง Nous กลายเป็น open source agent company ที่โตเร็วที่สุด Hermes for Businesses จะ model agnostic ลูกค้าเลือก backbone เอง data ownership stay with customer run on prem ได้ pricing กับ launch date ยังไม่เปิด pattern ที่สำคัญคือครั้งแรกที่ open source agent มี ARR เกินแปด digit แล้ว valuation ขึ้น billion plus Hugging Face มี developer มากกว่าแต่ enterprise ARR เล็กกว่า Mistral valuation สูงกว่าแต่คู่แข่งคือ foundation model vendor Nous คือ first proof ว่า open source agent business viable ที่ scale enterprise สำหรับ CTO ไทยที่ sign ChatGPT Enterprise กับ Claude Enterprise ภายใน 6 เดือน ขอ POC Hermes for Businesses คู่กัน check workflow coverage total cost of ownership กับ data residency ถ้าทำได้ 70 เปอร์เซ็นต์ขึ้นไปของ workflow เริ่ม negotiate lower pricing กับ incumbent ได้ สำหรับ builder ของ agent framework ที่ assume closed source backbone รีบ rebuild ให้ model agnostic ด้วย 1 click swap backbone ภายใน 6 เดือน หรือเสีย enterprise customer ที่กำลังหา hedge.
