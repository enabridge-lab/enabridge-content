รอบนี้มี 4 เรื่อง เน้น Agentic AI, business use case, และ trend ที่เอามาใช้กับ OpenBridge ได้.

เรื่องแรก.
วันนี้ข่าวใหญ่ของวงการ agent IBM กับ Microsoft จับมือเปิดตัวแพลตฟอร์มชื่อว่า Imagine Enterprise เมื่อวันที่สิบพฤศจิกายน. จุดขายคือมีไลบรารี agent สำเร็จรูปมากกว่าหกพันตัว ที่ IBM Consulting เก็บสะสมมาจากงานจริงใน industry โดยเฉพาะ financial services, insurance กับ retail ที่เปิดก่อน. ฝั่ง Microsoft เอา Foundry, Copilot Studio, Fabric กับ security stack อย่าง Entra, Purview, Defender มาเป็น runtime. ลูกค้าแรกคือ SEI Investments ที่บริหารเงินสองล้านล้านดอลลาร์ แต่ยังอยู่ขั้น exploring ไม่ใช่ production. ที่น่าสนใจคือมี forward-deployed engineering ให้ลูกค้า qualifying ด้วย — คือวิศวกรของทั้งสองฝั่งจะเข้าไปอยู่ที่ไซต์ลูกค้าเพื่อผลักจาก pilot ไป production. มุมมองคือเกม agent platform กำลังเปลี่ยนจากแข่ง framework ไปแข่ง domain-specific library กับ system integrator channel. Builder ที่ทำ framework ล้วน ๆ ต้องคิดใหม่ว่าจะไปเป็น OSS layer หรือสร้าง managed offering เอง. ส่วนธุรกิจที่กำลัง deploy agent มีทางเลือกใหม่ — ซื้อสำเร็จกับ SI ช่วย customize แทนสร้างเอง แลกกับ lock-in กับ Microsoft/IBM stack. SI อื่นอย่าง Accenture, Deloitte, Cognizant น่าจะต้องเร่งสร้าง library ของตัวเองตอบ ไม่งั้นเสียเค้ก enterprise AI ให้ IBM.

เรื่องที่สอง.
Google ส่งตัวจริงลงสนาม agent runtime. สัปดาห์นี้ Google donate โปรเจกต์ชื่อ Agent Substrate กับ gVisor เข้า Cloud Native Computing Foundation หรือ CNCF ก่อน KubeCon ที่กำลังจะมีถึง. Agent Substrate เป็น runtime สำหรับรัน agent แบบ stateful บน Kubernetes. Google บอกว่ารันได้ล้าน sandbox พร้อมกัน ที่ความหนาแน่นประมาณสิบเท่าของ container runtime มาตรฐาน. ปลุก actor ที่หลับอยู่ให้กลับมาทำงานได้ในเวลาไม่ถึงหนึ่งวินาที. เปิดเป็น Apache 2.0 รันบน Kubernetes cluster ไหนก็ได้ แต่ GA บน GKE ยังเป็น allowlist. ส่วน gVisor เป็น user space kernel ที่ Google ใช้ sandbox code ที่ไม่ไว้ใจ. ถ้าดูภาพใหญ่นี่คือ playbook เดียวกับที่ Google เคยทำกับ Kubernetes — ยกให้ CNCF แล้วกลายเป็นมาตรฐาน de facto. ตอนนี้กำลังพยายามทำกับ agent runtime ก่อน AWS Bedrock AgentCore กับ Azure stack จะปิดตลาด. มุมกับ builder — ถ้าทำ agent framework อยู่ควรเริ่มทดสอบบน Substrate แล้ว. มุมกับธุรกิจที่ deploy — ก่อน lock กับ cloud runtime ใดคลาวด์หนึ่ง ลอง evaluate stack ที่อยู่บน Kubernetes + CNCF ก่อน เพราะ portable กว่า. AWS กับ Azure ต้องตัดสินใจเร็ว ๆ ว่าจะ adopt หรือสร้างเอง.

เรื่องที่สาม.
Bay AI สตาร์ทอัพความมั่นคงจาก Tel Aviv เปิดตัวพร้อมกันกับเงินห้าสิบล้านดอลลาร์. Battery Ventures นำสามสิบเจ็ดล้านใน Series A บวก seed อีกสิบสามล้านจาก YL Ventures กับ Striker ซึ่งมี CEO ของ Wiz ร่วมลงด้วย. ผู้ก่อตั้งสามคนเคยอยู่หน่วยไซเบอร์แปดสองศูนย์ของกองทัพอิสราเอล. ผลิตภัณฑ์ติดตั้งบนเครื่องพนักงานกับ cloud กับ SaaS ผ่าน MDM หรือ EDR ที่มีอยู่แล้ว ใช้เวลาไม่ถึงห้านาที. วิธีทำงานคือ Bay Enforcer จะ hook เข้าระบบ แล้วตรวจทุก action ที่ agent ขอรันก่อน — verdict ภายในมิลลิวินาที, false positive rate ต่ำกว่าหนึ่งเปอร์เซ็นต์. Lighthouse สร้าง policy ให้เฉพาะทีม จาก activity ของเดือนก่อน. ลูกค้าเริ่มต้นได้แก่ Micron, Wix, ClickUp, Peloton. ตัวเลขที่น่าสนใจที่สุด — ลูกค้า Fortune 100 ที่ใช้ Bay รายงานว่าขยายการใช้ autonomous agent เพิ่มสามเท่าภายในสามสิบวัน. ข้อความคือ security layer ไม่ใช่ cost center — มันคือ enabler ของ agent ROI เพราะปลดล็อคให้องค์กรกล้าให้ agent รันจริง. ตลาดนี้กำลังหวานเพราะเพิ่งมีดีล CrowdStrike ซื้อ Fiddler และ Palo Alto คุย Clutch. ถ้ากำลัง deploy agent ใน workflow ควรรีวิว control plane ก่อน scale.

เรื่องที่สี่.
ตลาด agent security consolidate เร็วมาก. CrowdStrike ประกาศซื้อสองบริษัทพร้อมกัน Fiddler AI กับ Dreadnode. Wall Street Journal รายงานว่าราคารวมประมาณสี่ร้อยเก้าสิบห้าล้านดอลลาร์ โดย Fiddler ที่สี่ร้อยล้าน Dreadnode ที่เก้าสิบห้าล้าน แต่ CrowdStrike ยังไม่ confirm ราคาอย่างเป็นทางการ. Fiddler เป็น agent observability รู้ว่า agent ตัดสินใจอย่างไรและพฤติกรรมเปลี่ยนไหมเมื่อเวลาผ่าน จะถูกรีแบรนด์เป็น Falcon Observe เปิด GA ไตรมาสสี่ของปีงบประมาณ 27. ส่วน Dreadnode ตรงข้าม — ทำ red teaming ก่อน deploy, map ปัญหาเข้า standard ที่ใช้กันเช่น OWASP, MITRE. ก่อนหน้านี้ไม่กี่วัน CrowdStrike เพิ่งเพิ่ม AI Kill Switch ใน Falcon Guardian — admin กดเพื่อฆ่า agent ที่ misbehave ตัด network และห้าม relaunch — ชัดว่าเตรียมพื้นให้ดีลนี้. ภาพใหญ่คือ security incumbent ทุกรายเลือก team แล้ว. Palo Alto กำลังคุย Clutch ประมาณห้าร้อยล้าน. Bay AI เพิ่งเปิดตัวห้าสิบล้าน. ตลาด point solution agent observability กำลังถูก compress. มุมกับ builder — framework ที่ emit observability data แบบ structured จะได้ distribution. มุมกับธุรกิจที่ใช้ Fiddler อยู่ ตอนนี้ควร re-negotiate contract หรือ evaluate alternative อย่าง Arize WhyLabs Patronus ไว้เผื่อ.
