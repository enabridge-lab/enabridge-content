เรื่องแรก.
Casap บริษัทที่ทำ AI agent สำหรับ financial services ปิด Series B $56 ล้านดอลล่าร์ นำโดย Base10 Partners เมื่อวาน รวม total funding ขึ้นเป็น $90 ล้าน จาก Series A ที่ $25 ล้านปีที่แล้ว ที่น่าสนใจคือตัวเลข — revenue โต 10 เท่าใน 1 ปี ลูกค้า 100 กว่าธนาคาร credit union กับ fintech, chargeback win rate 96 เปอร์เซ็นต์ เทียบ industry average 60 เปอร์เซ็นต์, dispute resolution จาก 90 วันเหลือ 8 วัน, human processing time จาก 45 นาที เหลือ 1-2 นาที, first-party fraud loss ลด 51 เปอร์เซ็นต์. ประเด็นที่น่าคิดคือ Experian กับ Synchrony เข้ามาเป็น strategic investor — สองบริษัท Fortune 500 ที่มี customer base มหาศาล นี่คือ distribution channel เป็นของแถม Casap พูดชัดว่า agents ไม่ได้แค่ตอบคำถาม แต่ investigate case ตัดสินใจ และ action ตาม policy ของแต่ละสถาบัน ปิด dispute 73 เปอร์เซ็นต์ด้วย agentic automation human-in-the-loop ยังอยู่สำหรับ edge case Signal ที่สำคัญคือ vertical agent ที่โฟกัส operations ลึกเฉพาะอุตสาหกรรม จะได้ pricing power สูงกว่า horizontal framework และกำลังเติมช่องว่างที่ CrewAI กับ LangChain เคยหวังจะชนะ สำหรับธนาคารไทย โจทย์ชัด ดูแผน dispute card, debt collection, fraud investigation — ตลาดนี้มี proof production แล้ว blocker หลักคือ BoT regulatory sandbox ยังไม่มี category สำหรับ autonomous agent.

เรื่องที่สอง.
Infisical บริษัท open-source secrets management ปิด Series B 40 ล้านดอลลาร์ ที่ valuation 600 ล้าน Elad Gil นำ round เป็นรอบที่สองติด ตัวเลขที่สะท้อน scale ปัจจุบัน ลูกค้า 1,300 ราย developer ใช้ platform 300,000 คน secrets ที่ encrypt กับ rotate วันละ 10,000 ล้านชิ้น customer ที่เปิดชื่อรวม Airbus, Volkswagen, Hugging Face, OpenRouter, Wise ประเด็นที่สำคัญคือผลิตภัณฑ์ใหม่ที่เรียกว่า Agent Vault — ให้ AI agent เข้า database กับ API ได้โดยไม่เห็น credential จริง ที่ Infisical ชี้คือ credential ที่ agent ต้องใช้มีมูลค่าสูงเกินกว่าจะส่งเป็น plain text ให้ LLM เห็น ถ้า agent รันบน OpenAI หรือ Anthropic API ส่ง DB password เข้า prompt provider เห็นหมด prompt injection เห็นหมด model fine-tune เห็นหมด Agent Vault ทำหน้าที่เป็น proxy layer agent request action Infisical execute operation แล้วส่ง result กลับ credential ไม่เคยออกจาก vault Signal ที่น่าสังเกตคือ valuation โต 6-7 เท่าภายใน 16 เดือน สำหรับ secrets management ที่ pivot เข้า agent HashiCorp Vault ใช้ 11 ปีถึง 500 ล้าน run rate Infisical ทำ 3 ปีถึง 600 ล้าน valuation ความต่างคือ non-human identity scale สำหรับทีมที่กำลัง deploy agent ใน production คุยกับ CISO ให้ list credential path ของ agent วันนี้ก่อน audit หน้างาน บริษัทไทยที่พูด AI agent in production น่าจะมี vulnerability ที่ credential รั่ว audit urgent.

เรื่องที่สาม.
Sierra ประกาศ integration กับ Stripe ที่ให้ AI voice agent รับการชำระด้วยบัตรเครดิตบนสายโทรศัพท์ภายใน call เดียว เมื่อ 20 ตุลาคม ที่ Sierra Summit ลูกค้าโทรเข้า คุยกับ voice agent บอกยอดเงิน พิมพ์เลขบัตรบนปุ่มโทรศัพท์ Stripe รับข้อมูลตรงไม่ผ่าน agent transaction ประมวลผล agent ส่ง digital receipt กลับก่อนจบ call ทุกอย่างใน call เดียว ไม่มี SMS link ไม่มี transfer ไปหาคน จุด sell หลักคือ compliance Sierra ได้ PCI Level 1 ตั้งแต่เมษายน เป็น AI agent platform แรกที่ได้ Level 1 คือ tier สูงสุดของ PCI DSS สำหรับ merchant ที่ประมวลผลเกิน 6 ล้าน transaction ต่อปี customer ที่ launch ด้วยคือ Cedar บริษัท healthcare payment ที่ครอบ 65 health system ใช้รับการชำระ medical bill ค้าง ประเด็นที่สำคัญคือ voice agent เปลี่ยนจาก cost reduction tool เป็น revenue surface direct ลูกค้าจ่ายเงินใน call agent ปิด transaction healthcare collection subscription renewal utility bill ทุก category ที่คนไม่อยากตั้ง autopay แต่พร้อมจ่ายเมื่อโทรเตือน Stripe กำลัง build agent commerce stack ที่ครอบมากกว่า API Visa Mastercard PayPal เข้า Poppy design partner พร้อมกัน payment network กำลังกำหนด agent transaction standard สำหรับไทย call center ของธนาคาร เทลโก้ ประกัน รพ.เอกชน ควร pilot voice agent payment ใน Q1 2027 blocker หลักคือ Thai language voice LLM กับ PCI acquiring compliance.

เรื่องที่สี่.
Omnichat บริษัท agentic CX ของ APAC HQ ที่ฮ่องกง เปิดตัว Omni AI Agents platform เมื่อ 27 ตุลาคม พร้อมตั้งเป้าปิด Series A+ 10 ล้านดอลล่าร์เพื่อขยายไปญี่ปุ่น เกาหลี ออสเตรเลีย traction ปัจจุบัน revenue โต 8 เท่าใน 3 ปี ARR เกิน 10 ล้าน backer ที่ลงมารวม AppWorks ของไต้หวัน 91APP Palm Drive กับ Cornerstone Ventures Product ครอบ 3 agent class ที่สำคัญ AI Customer Service Agent ตอบลูกค้า 24 ชั่วโมง AI Copilot Agent ช่วย marketer ลอง campaign AI Sales Agent คุณสมบัติเจาะ lead ปิดดีลผ่าน conversational channel ครอบ WhatsApp LINE Messenger Instagram WeChat SMS email voice ในแพลตฟอร์มเดียว ประเด็นที่น่าสังเกตคือ agentic CX สำหรับ APAC ยังไม่มี category leader ชัด Decagon กับ Sierra เป็น US enterprise ไม่ได้ optimize สำหรับ LINE WeChat WhatsApp ที่เป็น primary channel ของผู้บริโภค APAC Omnichat ที่สร้างจากฝั่ง APAC มา 9 ปี ย่อมมี channel optimization ที่ US copy ยาก Thai VC ปัจจุบันยังไม่มี agentic CX thesis SCB10X เน้น web3 Krungsri Finnovate เน้น fintech True Digital Fund เน้น media ไม่มีใครถือ agentic CX startup ขนาด regional เป็นช่องว่าง opportunity ใหญ่ Thai founder ที่กำลัง build conversational AI startup ควรดู Omnichat trajectory และ go-regional ตั้งแต่ seed stage ไม่ใช่ Thailand first then expand TAM ไทยเดี่ยวไม่พอ build company ขนาด 100 ล้าน.
