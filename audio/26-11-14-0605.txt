เรื่องแรก.
วันที่ 13 พฤศจิกายน LangChain ซึ่งเป็น framework ที่ developer ใช้สร้าง AI agent ทั่วโลก ประกาศปิดรอบ Series C มูลค่า 300 ล้านเหรียญ ที่ valuation 3 พันล้านเหรียญ นำโดย CapitalG ซึ่งเป็น growth fund ของ Alphabet GIC จากสิงคโปร์กับ DFJ Growth เข้าเป็นนักลงทุนใหม่ ส่วน IVP กับ Sapphire Ventures ที่เคยลงอยู่แล้วลงเพิ่ม เทียบกับรอบที่แล้ว valuation โตขึ้นกว่าสองเท่าในเวลาแค่ 13 เดือน ตัวเลขที่สำคัญกว่า valuation คือ customer count ของ LangSmith ซึ่งเป็นผลิตภัณฑ์ observability และ evaluation ของ LangChain ปัจจุบันมีองค์กรใช้งาน 7,000 ราย รวม NVIDIA, Toyota, Salesforce, Harvey, Rippling, LinkedIn, Workday และ Bridgewater สิ่งที่น่าสนใจคือ Salesforce เองก็ขาย Agentforce ที่แข่งในตลาดใกล้เคียง แต่ยังใช้ LangSmith สร้าง agent ของตัวเอง สัญญาณคือ agent observability กำลังกลายเป็น infrastructure layer ที่ enterprise ทุกรายต้องมี เหมือน Datadog ของยุค microservice หรือ Snowflake ของยุค data warehouse สำหรับทีมที่สร้าง agent platform แปลว่า observability กับ evaluation ไม่ใช่ feature ที่ bundle ได้ ต้องเป็น standalone product สำหรับองค์กรที่ deploy agent ใน production ควรแยกชั้นให้ชัดระหว่าง model, runtime และ control plane ชั้นที่สามเป็นชั้นที่มักถูกลืมใน POC แต่พอ scale จะกลายเป็น bottleneck LangChain จะมี release event วันที่ 20 พฤศจิกายน เปิดตัว LangSmith capability ใหม่ น่าจะเป็น runtime หรือ orchestration pricing ที่ชาร์จต่อ run.

เรื่องที่สอง.
วันที่ 12 พฤศจิกายน Anthropic เปิด private beta ของ Claude Managed Agents แบบ self-hosted หลังจากที่ก่อนหน้านี้เปิดแค่ self-hosted sandboxes แบบ public beta ครั้งนี้ย้าย control plane ทั้งหมดเข้าไปในของลูกค้า server ของ Managed Agents, PostgreSQL ที่เก็บ agent state และ workers ที่รัน shell กับ file tools ทั้งหมดอยู่บน VPC ของลูกค้าเอง Anthropic เป็นคนติดตั้งและดูแล security ของ release แต่ไม่เข้าถึง data model inference ยัง default ไปที่ Anthropic API แต่ลูกค้าสามารถสลับไปใช้ Amazon Bedrock, Google Vertex, Microsoft Foundry หรือ gateway ของตัวเองได้ สิ่งที่สำคัญคือ ตลาด enterprise agent มี bottleneck ที่พูดกันน้อย ไม่ใช่ model quality หรือราคาต่อ token แต่เป็นคำถามว่า agent state ควรอยู่ที่ไหน ธนาคารใหญ่กับบริษัทประกันที่เจอ GDPR, EU AI Act หรือ regulation ของแต่ละประเทศเข้าใจความเจ็บปวดนี้ดี Anthropic ยอมเปิด self-hosted control plane คือการยอมรับว่า Anthropic เป็นเจ้าของ model แต่ customer เป็นเจ้าของ agent เทียบกับคู่แข่ง OpenAI ยังไม่ให้ self-host Managed Agents, Google ให้ build agent บน Vertex แต่ไม่ให้รัน on-prem, AWS Bedrock ให้ model แต่ไม่มี managed agent service แปลว่าสำหรับ regulated industry ตอนนี้ Anthropic เป็นรายเดียวที่ให้ control plane อยู่ในมือลูกค้า สำหรับทีมที่สร้าง agent platform ควรแยก control plane กับ model inference ตั้งแต่ต้น สำหรับลูกค้าไทยกลุ่มธนาคาร ประกัน โรงพยาบาลเอกชน นี่คือโอกาสเปิด conversation ใหม่.

เรื่องที่สาม.
วันที่ 10 พฤศจิกายน IBM กับ Microsoft ประกาศ joint platform ชื่อ Imagine Enterprise ที่ทั้งสองบริษัทร่วมกันออกแบบ IBM เอา 6,000 prebuilt agent และ asset จาก IBM Consulting ซึ่งเป็นผลงานที่เก็บสะสมจาก client engagement ปีที่ผ่านมา ผสมเข้ากับ Microsoft Azure AI, Foundry, Entra identity และ security stack ทั้งสองบริษัทส่ง forward-deployed engineer เข้าไปทำงานกับลูกค้า Industry focus ชุดแรกคือ financial services, insurance, retail ถัดไปคือ manufacturing, energy, public sector, mobility ตัวอย่าง use case รวม agent ที่ช่วย underwriter ประกันตรวจ claim, agent สำหรับ KYC AML ของธนาคาร, agent ที่ optimize assortment ใน retail ทั้งหมดเป็น industry-specific workflow ที่ Copilot Studio หรือ generic agent framework ทำไม่ได้ตรง ๆ จุดขายคือ governance ออกแบบสำหรับ regulated industry โดยเฉพาะ รองรับ EU AI Act และ data sovereignty สิ่งสำคัญคือ ต้องซื้อผ่าน IBM Consulting engagement เท่านั้น ไม่ใช่ self-serve สองปีที่ผ่านมา enterprise agent story ส่วนใหญ่เป็นแบบ ซื้อ platform แล้ว build เอง แต่ reality ของ regulated industry ไม่ได้เป็นแบบนั้น ธนาคาร ประกัน retail ขนาดใหญ่ไม่มี AI team ที่ build agent ได้โดยไม่ต้อง consulting support ที่เข้าใจ workflow เฉพาะทาง Imagine Enterprise คือการยอมรับว่าโมเดล self-serve platform ไม่พอ ต้อง bundle consulting เข้าไปด้วย สำหรับลูกค้าไทยที่คุยกับ Enabridge นี่คือ benchmark ที่ควรใช้ ไม่ใช่ default SI ไทยที่เข้าใจ workflow local สามารถ compete ได้ ถ้า focus ที่ last-mile customization.

เรื่องที่สี่.
วันที่ 12 พฤศจิกายน Decagon ซึ่งเป็น customer service agent startup ประกาศ Missions ซึ่งเป็น feature ใหม่ที่ขยับ paradigm จากตอบคำถามเดี่ยว ๆ ไปเป็น agent ที่รับผิดชอบผลลัพธ์ข้ามหลายวันหรือสัปดาห์ Missions coordinate agent ข้าม system, monitor status update และ engage คนในหลายขั้นตอนตามจำเป็น ตัวอย่างคือลูกค้าธนาคารร้องเรียน fraud charge ที่ต้องรอ investigation 7 ถึง 14 วัน ปกติ chat agent ตอบได้แค่เราจะติดต่อกลับภายใน 7 วันแล้วจบ session Missions จะจัดการเอง ส่งต่อ case ให้ investigator ติดตาม status จาก backend update ลูกค้าเป็นระยะ แจ้ง resolution และเก็บ feedback ทั้งหมดในฐานะ agent เดียวที่เป็นเจ้าของ mission Named customer ประกอบด้วย Chime ที่ containment rate 70 เปอร์เซ็นต์ operating cost ลด 60 เปอร์เซ็นต์ voice agent รับสายมากกว่าหนึ่งล้านสายต่อเดือน Duolingo ที่ deflection 80 เปอร์เซ็นต์ Hertz ที่ใช้ทำ outbound proactive และ Deutsche Telekom สัญญาณชัดเจนว่าตลาดต้องการ agent ที่ take ownership of outcome ไม่ใช่แค่ตอบ FAQ แล้ว transfer ให้คน สำหรับ enterprise ที่คิดจะ deploy customer-service agent ควร re-scope project จากลด ticket เป็นเป็นเจ้าของ outcome บาง category ลูกค้าไทยกลุ่ม telco retail bank ประกัน airline e-commerce ควรจัด workshop map case lifecycle ของแต่ละ issue type แล้วเลือก category ที่ยาวที่สุด เช่น fraud dispute, claim, refund เป็น pilot ของ long-horizon agent แทน FAQ.

เรื่องที่ห้า.
วันที่ 11 พฤศจิกายน Rox ซึ่งเป็น AI agent สำหรับ sales rep ปิด Series B มูลค่า 100 ล้านเหรียญที่ valuation 1.3 พันล้านเหรียญ นำโดย General Catalyst และ March Capital Databricks Ventures กับ Prosperity7 Ventures เข้าเป็นนักลงทุนใหม่ Sequoia, Factory และ GV ที่ลงรอบ seed กับ Series A ไว้ลงเพิ่ม ตัวเลขที่ Rox เปิดเผยพร้อมรอบนี้คือ ARR โตมากกว่า 10 เท่าใน year แรกที่ออก market ถ้าดูข่าวก่อนหน้า Rox คาดจะปิด 2025 ที่ ARR ประมาณ 8 ล้านเหรียญ แปลว่า valuation 1.3 พันล้านเหรียญเท่ากับ 160 เท่าของ ARR ซึ่ง investor ลงจาก growth curve ไม่ใช่ current revenue Product ของ Rox ทำงานใน Salesforce, HubSpot, LinkedIn Sales Navigator และ Gmail Outlook ที่ลูกค้าใช้อยู่แล้ว ไม่ใช่ standalone UI pitch คือ replace sales ops overhead แทนที่จะ add workflow ซึ่งเป็น framing ที่ CFO ของบริษัท enterprise ซื้อง่าย Rox อยู่ในคลื่น AI รุก seat ของ sales rep ที่สัปดาห์ก่อนมี Nooks ได้ 500 ล้านแบบ non-dilutive และก่อนหน้านี้มี Clay 11x Regie.ai ออกตัวเลข traction สัญญาณร่วมคือ sales ops function กำลังถูกตีแผ่ และ seat ของ BDR SDR junior AE ที่ค่าใช้จ่าย 100,000 ถึง 150,000 เหรียญต่อคนต่อปี กลายเป็น prime target ของ agent replacement สำหรับ enterprise ที่กำลัง scale sales team ปี 2027 ควรถามว่า ถ้า agent ทำ pipeline generation meeting booking และ deal expansion แทน BDR ได้ 70 ถึง 80 เปอร์เซ็นต์ของ workload headcount ที่ plan ไว้ปีหน้าควรเป็นเท่าไหร่.
