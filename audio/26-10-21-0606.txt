รอบนี้มี 4 เรื่อง เน้น Agentic AI, business use case, และ trend ที่เอามาใช้กับ OpenBridge ได้.

เรื่องแรก.
วันนี้มีข่าวใหญ่ที่คนทำ agent ควรรู้ — Daytona บริษัท sandbox สำหรับ AI agent ปิดรอบ Series B หกสิบล้านดอลลาร์ที่ valuation พันล้าน แปลว่าเป็น unicorn แล้วภายในแปดเดือนจาก Series A ที่ยี่สิบสี่ล้าน. FirstMark เป็น lead แต่ที่น่าสนใจกว่าคือ list ของ angel — Patrick Collison แห่ง Stripe, Tobi Lütke แห่ง Shopify, Aravind Srinivas แห่ง Perplexity, Olivier Pomel แห่ง Datadog, Eric Yuan แห่ง Zoom. ไม่ใช่คนทั่วไป คือ CEO ที่ขาย product ให้ลูกค้าเอง และกำลัง bet ว่า agent runtime คือ infrastructure layer ถัดไป. revenue run rate ของ Daytona โตยี่สิบห้าเท่าใน 8 เดือน ลูกค้ามี Anthropic, OpenAI, NVIDIA, Cursor, Cognition, Meta, Cohere, Postman. CEO บอกว่า "บริษัทกำลังจะต้อง manage digital employee เป็นพัน ๆ ตัว และแต่ละตัวต้องมีที่ให้มันล้มเหลวได้อย่างปลอดภัย" — คือ positioning ว่า Daytona ไม่ใช่ sandbox แต่คือ agent cloud. บทเรียนคือ ถ้าสร้าง agent อยู่ อย่าสร้าง sandbox เอง — layer นี้มี unicorn เสิร์ฟแล้ว เวลาที่เคยใช้กับ ops เอาไปใช้กับ tool catalog, policy, observability จะคุ้มกว่า.

เรื่องที่สอง.
วันนี้มีข่าวที่คน build agent ควรรู้ — Neural Concept บริษัทจาก Lausanne ที่เพิ่งปิด Series C ร้อยล้านดอลลาร์เมื่อธันวาคมปีก่อน นำโดย Goldman Sachs ประกาศปล่อย MCP Bridge — เป็น Model Context Protocol server ตัวแรกที่ให้ AI agent ขับซอฟต์แวร์ CAD กับ simulation ตัวจริงของ enterprise. Connector รุ่นแรกครอบคลุม CATIA, NX สำหรับ design, ANSA, HyperMesh สำหรับ prep model, และ Abaqus สำหรับ simulation. ลูกค้าแรกคือ Traton บริษัท heavy truck ของกลุ่ม Volkswagen — engineer ของเขาบอกว่าทำ geometry cleanup ของ wheel rim ลดจากหนึ่งวันเหลือสามนาที, การ setup simulation draft จากสัปดาห์เหลือชั่วโมง, และเขียน script simulation จาก research paper ลดเหลือสองสามวัน. ที่สำคัญกว่าตัวเลขคือ signal ว่า MCP กำลังข้ามจาก developer tool ไปถึง enterprise software เก่า 30 ปี. ถัดจาก CAD จะเป็น PLM, EDA, medical imaging, legal doc. ถ้าใครสร้าง agent framework อยู่ MCP connector สำหรับซอฟต์แวร์แพง ๆ ที่ไม่มี API สวย ๆ คือ opportunity ขนาด unicorn เพราะ barrier สูงแต่ตลาดใหญ่. ถ้าใช้ CAD อยู่ให้ถาม vendor ตัวเองว่าแผน MCP เป็นยังไง.

เรื่องที่สาม.
วันนี้มีสองข่าวที่ชี้ไปทิศเดียวกัน — Sumsub บริษัท KYC ที่คนไทย fintech รู้จักเพราะทำ identity verification ให้ Bitkub, Line BK, StashAway ประกาศปล่อย KYA Module คือ Know Your Agent — proxy ที่สอดอยู่ระหว่าง AI agent กับ data store ของบริษัท strip PII ออกก่อน agent เห็น และถ้า agent approve invoice เกิน threshold จะเรียก liveness check ของคนอนุมัติแบบ real time. วันเดียวกัน Opsin ที่ San Jose ปิดรอบยี่สิบเอ็ดล้านดอลลาร์ นำโดย SYN Ventures กับ Race Capital เพื่อขยาย platform ที่ตามรอย agent ที่พนักงานสร้างใน Copilot, Claude, ChatGPT Enterprise. Stat ที่ CISO ได้ยินแล้วเขียนเช็คคือ 93% ของ misaligned agent มี full access ไปยัง system ตัวเอง และมีแค่ 1 ใน 200 action ที่ต้องการมนุษย์อนุมัติ. และ Sumsub cite research ว่า 65% ของ organization เคยมี agent security incident ใน 12 เดือนที่ผ่าน. บทเรียนคือ Know Your Agent กำลังจะเป็น category เหมือน Know Your Customer ที่ Sumsub, Jumio, Onfido เป็น business พันล้าน. ถ้าสร้าง agent อยู่อย่า reuse user token — scope แยก permission ให้ชัดและ emit audit event. ถ้าใช้ agent ใน business ก่อน deploy ให้ security team ตอบว่า agent มี identity แยกจาก user ไหม scope อะไร revoke ยังไง.

เรื่องที่สี่.
วันนี้มีข่าวที่สะท้อนว่า personal AI assistant กำลังเข้าสู่สงครามจริง — Town บริษัท AI assistant สำหรับ knowledge worker ที่ connect กับ inbox, calendar, Slack, docs ของคุณ ใกล้ปิด Series B ขนาดเก้าสิบล้านดอลลาร์ที่ valuation พันล้าน ภายในสี่เดือนหลัง Series A ห้าสิบห้าล้านของ a16z. Co-lead คือ Forerunner ของ Kirsten Green กับ Menlo ของ Shawn Carolan. ที่ drama กว่าตัวเลขคือ Index Ventures เซ็น term sheet แล้วจะเป็น lead แต่ถอนหลัง Instinct คู่แข่งโดยตรง complain ว่า conflict of interest. Conviction ก็ถอยด้วย. Instinct คือ context สำคัญ — บริษัทของ Noah Shinn ปิด Series C พันล้านดอลลาร์ที่ valuation หมื่นล้าน เมื่อ 28 กันยา โดย Sequoia Benchmark Coatue. บทเรียนคือ personal AI assistant กำลังเข้าสู่เฟส pick side ของ investor — Index Conviction เลือก Instinct, Forerunner Menlo เลือก Town. Deeper reading คือ ใครชนะชั้นนี้จะมี context window ของทั้งชีวิต user ซึ่งคือ moat ที่ Google Microsoft Apple มีมา 20 ปี. ถ้าสร้าง personal agent อยู่ context layer คือ moat ไม่ใช่ model ไม่ใช่ UI. ถ้าจะ deploy ให้ทีม knowledge worker ถาม vendor ตรง ๆ ว่า context user อยู่ที่ไหน encrypted ยังไง revoke ยังไง.
