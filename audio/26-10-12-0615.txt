เรื่องแรก.
สัปดาห์แรกของเดือนตุลาคมปีนี้มีสองโปรโตคอลใหม่สำหรับเอเจนต์เคาะประตูธุรกิจ โผล่พร้อมกัน. วันที่ 1 ตุลาคม Decagon เปิด PACT ที่ event ของตัวเอง ย่อมาจาก Personal Agent Consent and Trust. วันที่ 6 ตุลาคม Meta และ Sierra เปิด Personal Agent Protocol หรือ PAP. ทั้งคู่สร้างบน OAuth เหมือน Sign in with Google. ทั้งคู่ตั้งใจตัด payments ออกจาก version แรก. ทั้งคู่เลือกเลเยอร์ identity เป็นเลเยอร์แรกที่จะปิด. จุดที่น่าสังเกตคือ merchant ยอม commit ก่อน spec จะออก. Walmart Shopify Stripe Genesys Rocket Instinct เซ็นเข้า PAP ก่อน spec v0.1 จะ ship ด้วยซ้ำ. ขณะที่ PACT open-source spec พร้อม reference implementation ไปแล้วที่ openpactprotocol.org. จุดสับสนที่สุดคือ Instinct อยู่ทั้งสองค่าย. ส่วน Google Gemini Agent GA, PAP v0.1, และ A2A Agent Registry formal spec — สามเสาแห่ง roadmap ตุลาคมพลาด deadline ทั้งหมด ตามการตีข่าวของ Forkast. เรื่องนี้สำคัญเพราะมันบอกว่า bottleneck ของ agentic commerce ปี 2027 ไม่ใช่ เอเจนต์จ่ายเงินยังไง. แต่คือ ธุรกิจรู้ได้ไงว่าตัวที่กำลังคุยอยู่คือเอเจนต์ของลูกค้า ไม่ใช่ bot ปลอม. Amazon บล็อก Muse ของ Meta เพราะเหตุผลเดียวกัน. ตั้งแต่ Walmart ล็อก scraping ของ ChatGPT ถึง Reddit สู้ bots — pattern ชัดว่าธุรกิจไม่ไว้ใจ traffic จาก agent ที่ไม่ identify ตัวเอง. การมีสอง spec แข่งกันตั้งแต่ day 1 คือ bad news สำหรับทุกคน. ประวัติศาสตร์เตือนว่า WAP กับ i-mode, OpenID กับ SAML — สอง spec ขัดกันตั้งแต่แรกยืด adoption 3 ถึง 5 ปี. CIO retail hospitality SaaS ไทยควรเริ่มคุยกับ security team ตอนนี้ ว่าจะ expose Agent Card format ไหน เพราะเลเยอร์นี้คือสิ่งที่ปิด gap ระหว่าง agent demo สวย กับ agent production ที่ใช้งานจริง.

เรื่องที่สอง.
วันอังคารที่ 7 ตุลาคม Automation Anywhere ประกาศเข้าซื้อ Boost.ai จาก Nordic Capital. ไม่เปิดเผย financial terms แต่คาด close ไตรมาสสุดท้ายของปีนี้. Boost.ai เป็น conversational AI สัญชาตินอร์เวย์ ที่สร้างมาตั้งแต่ก่อนยุค LLM แข็งที่ regulated industry — ธนาคาร insurance telco ยุโรป มีลูกค้าหลายร้อยราย และอ้าง production resolution rate เกิน 90 เปอร์เซ็นต์. สำหรับ Automation Anywhere นี่คือดีลที่สอง ตามหลัง Aisera ปลายปี 2025. Aisera แข็งที่ employee service ส่วน Boost.ai แข็งที่ customer-facing. สองดีลรวมกันคือ full coverage ทั้งเอมพลอยและลูกค้าของการ automate dialog ในองค์กร. CEO Mihir Shukla เลือกใช้คำว่า autonomous enterprise ที่ทำงาน 80 เปอร์เซ็นต์ได้โดยอัตโนมัติ ซึ่งเป็น framing ที่ UiPath Blue Prism Workato พูดเหมือนกัน. ความต่างที่ Automation Anywhere พยายามสร้างคือ voice. Boost.ai มี voice stack ที่ผ่าน production ในธนาคารจริง ซึ่งถ้า integrate กับ Automation 360 บวก Aisera ก็ได้ pattern end-to-end: ลูกค้าโทรเข้า voice agent เข้าใจ trigger RPA workflow เขียน record กลับ ERP. ความสำคัญคือ ดีลนี้คือ playbook ของ RPA 2.0 ที่เราจะเห็นซ้ำอีก 3 ถึง 4 รอบในปี 2027. UiPath Blue Prism Workato n8n เจอ pressure เดียวกัน — RPA แบบ click-based script ตายเพราะ LLM ทำงานเดียวกันได้โดยไม่ต้อง record macro. ทางออกคือรีแบรนด์เป็น agent orchestration platform บวกซื้อ conversational AI. ลูกค้า Boost.ai เดิมควรเริ่ม plan B ตั้งแต่ตอนนี้ เพราะไม่มีการประกาศ pricing continuity. CTO ธนาคารไทยที่กำลังจะเลือก voice AI ควรเจรจา change of control clause เป็นข้อหนึ่งใน procurement contract.

เรื่องที่สาม.
วันจันทร์ที่ 6 ตุลาคม Ampersand ปิด Series A 15 ล้านดอลลาร์ นำโดย Bessemer Venture Partners. ก่อตั้งโดย Ayan Barua และ Lauren Long จาก San Francisco. Total funding หลังรอบนี้ 20 ล้าน. Lauri Moore partner ของ Bessemer เข้า board. ลูกค้าที่เปิดเผยคือ Square, 11x, และ Orb. ผลิตภัณฑ์คือ integration platform ให้ AI app อ่านและเขียน Salesforce, NetSuite, SAP, Workday ของลูกค้าได้โดยจัดการ custom fields และ permission ให้. ความสำคัญคือ: builder ที่สร้าง agent ขายเข้า enterprise เจอ last mile problem ซ้ำ ๆ — เอเจนต์เก่งแค่ไหนก็ไม่มีประโยชน์ถ้าเขียนกลับ CRM ของลูกค้าแต่ละรายไม่ได้. OpenAI Anthropic Google แก้ด้วย MCP แต่ MCP เป็น protocol layer ยังต้องมี implementation สำหรับทุก schema ของ Salesforce หรือ SAP. Ampersand กินตรงจุดนี้ — ขาย infrastructure ที่ compress N-by-M ให้เป็น 1-to-N. Thesis ของ Bessemer สะท้อน shift ของ unit of value: จาก model ไป distribution บวก integration. ปี 2024 VC ลง foundation model lab. ปี 2025 ลง horizontal agent framework. ปี 2026 ลง integration layer บวก vertical runtime. 11x เป็นลูกค้าของ Ampersand คือ validation ที่น่าสนใจ. 11x เป็น AI SDR agent ที่ยังอยู่และยัง scale ได้ส่วนหนึ่งเพราะต่อ Salesforce ของลูกค้าได้ลึก. บทเรียนสำหรับ builder ไทย — อย่าสร้าง integration เอง ซื้อ. CIO ไทยที่ซื้อ AI product ควรถาม vendor ว่าใช้ integration platform อะไร ถ้าตอบไม่ได้หรือตอบว่าสร้างเอง ให้ระวัง onboarding time 2 ถึง 4 สัปดาห์ต่อ workflow. ขอดู reference customer ที่ onboard สำเร็จในเวลา 1 ถึง 2 สัปดาห์.

เรื่องที่สี่.
วันที่ 1 ตุลาคม doxx.net ปิด Series A 38 ล้านดอลลาร์ นำโดย Andreessen Horowitz. Joel De La Garza partner ของ a16z เข้า board. บริษัทก่อตั้งโดย Barrett Lyon คนเดียวกันที่สร้าง BitGravity, Xbot, และ Netography — คนที่ shipped network infra มา 20 ปี 3 รอบ. ผลิตภัณฑ์คือ Agentic Defined Networking ให้ agent สร้าง config operate private network ของตัวเอง. SDK พร้อมใช้บน iOS macOS Android. Windows กับ Linux กำลังมา. บริษัทอ้าง block threat 38 ล้านครั้งใน closed beta ตั้งแต่ธันวาคม 2025 แต่ยังไม่มี third party verify. ความสำคัญไม่ใช่ตัวเลข 38 ล้าน แต่คือ network layer คือ gap ที่ยังว่าง. ยุค MCP A2A PAP PACT ทำให้ protocol layer เริ่มตกผลึก. Application layer มี player เยอะแล้ว. Model layer ก็ชัด. แต่ชั้น network ที่ determine ว่า agent ของคุณไปเคาะประตูธุรกิจอื่นได้จริงไหมยังว่าง. Cloudflare Fastly Akamai พยายามเติมด้วย product line ตัวเอง แต่ยังไม่มี pure play startup. doxx.net ชิง positioning ก่อน. Signal อีกชั้น a16z เลือกลงใน security adjacent agent startup. ก่อนหน้านี้ลง Reco Prompt Security Protect AI. doxx.net เป็น second security bet ที่โฟกัสขา network ไม่ใช่ขา model. บอก thesis ชัดว่า threat surface ของ agent ปี 2027 ไม่ใช่ prompt injection เท่านั้น แต่คือ network traffic กับ identity ที่ merchant กับ enterprise ไม่ไว้ใจ. Builder ไทยที่สร้าง agent product วิ่ง autonomously ข้าม internet ควรรู้ว่า IP reputation TLS fingerprint session continuity เป็น silent killer ที่ demo ไม่เจอ. การวิ่งจาก datacenter IP ของไทยเจอ merchant block ซ้ำ ๆ. doxx.net หรือ equivalent เริ่มน่าทดสอบตอน scaling.

เรื่องที่ห้า.
30 กันยายน Microsoft เปิด public preview ของ Work IQ สำหรับ Dynamics 365 Sales และ Customer Service บวก Power Apps บวก third party line of business apps. ประกาศโดย James Oleinik ที่เป็น product lead สำหรับ Dataverse และ Work IQ. Finance and Operations ซึ่งคือ ERP core ของ Microsoft จะเพิ่มปลายตุลาคม. Work IQ สร้างบน 3 primitive. หนึ่ง semantic model ที่แปล raw data ใน Dynamics เป็น business concept ที่ agent เข้าใจ. สอง reusable business skills ที่ encode business logic เช่น create lead escalate case approve invoice. สาม governed actions — จุดแตกต่างสำคัญ. Agent ไม่ commit write operation โดยตรง แต่ propose change route ให้ user หรือ manager approve แล้ว platform commit under permission ของ user ที่ approve. Flow นี้แก้ปัญหา agent ทำเสียโดยไม่มีคนรู้ ที่ CISO กลัวที่สุด. ความสำคัญ: Work IQ คือคำตอบของ Microsoft ต่อ Google Gemini Agent ที่ประกาศ 8 ตุลาคม. ทั้งสองค่ายเดินทางเดียวกัน — ขยับ layer value จาก copilot ภายใน app ไป agent ข้าม app. ความต่าง Google focus productivity suite Gmail Drive Docs. Microsoft focus business application CRM ERP LOB. ลูกค้า enterprise ที่ใช้ทั้งคู่ได้ coverage กว้างสุด ซึ่งเป็น default ของ Fortune 500 US. Governed actions จะกลายเป็น table stakes ภายใน Q1 2027. ปัญหา agent write operation โดยไม่ควบคุม คือเหตุที่ CFO Fortune 500 บล็อก agent rollout ตั้งแต่ปี 2024. Microsoft แก้ด้วย propose then approve flow บวก permission under user scope ไม่ใช่ agent principal แยก. นี่ตรงข้ามกับ Google Gemini Agent ที่ให้ agent มี Workspace account ของตัวเอง. CIO ไทยที่ใช้ Dynamics 365 ควรเตรียม semantic model mapping และ governed action policies ตั้งแต่ตอนนี้ ก่อน ERP เพิ่มเข้ามาปลายตุลาคม.
