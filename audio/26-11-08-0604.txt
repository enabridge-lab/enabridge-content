เรื่องแรก.
Google ประกาศที่ KubeCon North America วันที่ 5 พฤศจิกายน บริจาคโครงการโครงสร้างพื้นฐาน agent สามตัวให้ CNCF ซึ่งเป็นมูลนิธิเดียวกับที่ดูแล Kubernetes สามตัวนี้คือ Agent Substrate, gVisor และ OpenRL ทั้งหมดเข้า sandbox tier ของ CNCF Agent Substrate คือ runtime ที่ snapshot state ของ agent ลง storage ได้ แล้ว restore กลับใน 500 มิลลิวินาที จุดสำคัญคือ agent ส่วนใหญ่รอ ไม่ได้ compute ดังนั้นถ้า pause ลง disk ได้ระหว่างรอ จะวาง agent ต่อ node ได้เยอะกว่า container ปกติเป็น 10 เท่า ซึ่งเปลี่ยน unit economics ของ agent platform ได้เลย ข่าวควบคู่คือ Agent Compute Engine ให้แต่ละ agent รันใน microVM ของตัวเอง มี governance stack ครบ ประกอบด้วย Agent Gateway Agent Registry และ Agent Identity ทำไมมันสำคัญ Google กำลังเล่นสคริปต์เดิมกับที่ชนะ Kubernetes ปล่อยของให้เป็น neutral standard ให้ ecosystem ลงทุนรอบมัน แล้วตัวเองขาย GKE เป็น managed version ที่ดีที่สุด AWS กับ Azure ต้องเลือกว่าจะ adopt หรือ fork แรงดึงดูด economic ของ 10x density จะดึงทุก hyperscaler ให้ compat ในที่สุด สำหรับคนที่สร้าง agent platform ต้อง bake Agent Substrate compat ลง roadmap เพราะมันจะเป็น cost of goods ไม่ใช่ feature ต่างหาก สำหรับ Anthropic ที่ดูแล MCP อาจต้องคิดเรื่อง foundation donation เร็วกว่าเดิมเพื่อไม่ให้ Google control ทั้ง stack.

เรื่องที่สอง.
Ocient ซึ่งเป็น data warehouse ที่ก่อตั้งใน Chicago ประกาศปิด Series C ที่ 100 ล้านเหรียญเมื่อวันที่ 5 พฤศจิกายน co-lead โดย BOKA Capital และ OCA Ventures ทำให้ยอดระดมสะสมแตะ 260 ล้านเหรียญ CEO บอกว่าปี 2026 revenue จะมากกว่า 3 เท่าของปีก่อน Dealroom จัดอันดับว่า round นี้ติด top 10 เปอร์เซ็นต์ของ Series C enterprise software ใน US pitch ของ Ocient รอบนี้ไม่ใช่ faster SQL แบบเดิม แต่คือ OcientAIQ ที่รวม ingestion analytics governance และ agent orchestration ไว้ในเอนจินเดียวสำหรับ dataset ระดับ petabyte argument หลักคือการที่ agent รัน workload in-place บน data โดยไม่ต้อง copy ไปที่ feature store เป็น edge เชิง architecture ที่คู่แข่งทำไม่ได้ เพราะ Ocient build engine ของตัวเองตั้งแต่ต้นไม่ได้ fork postgres หรือ layer บน object storage ตลาดที่แตกเร็วคือ cybersecurity เพราะ log cardinality สูงจน copy แบบเดิมไม่ work สำหรับคนที่สร้าง agent ที่ต้อง query data หลาย domain บ่อยๆ pattern ที่ควรพิจารณาคือ agent orchestrator ภายใน data engine ไม่ใช่ agent service ข้างนอก สำหรับองค์กรไทยที่มี cardinality สูง เช่น ธนาคาร telco retail chain ประกัน การ evaluate architecture ใหม่ควรขึ้นโต๊ะ CTO ภายในปี 2027 ประวัติบอกว่า Snowflake กับ Databricks มักจะ acquire มากกว่า rewrite ราคา Ocient จึงน่าจะขึ้นเร็วในปี 2027 ถ้า revenue 3x ผ่าน audit ได้.

เรื่องที่สาม.
Shackleton AI เปิดตัวจาก stealth เมื่อวันที่ 4 พฤศจิกายน พร้อม seed round 5 ล้านเหรียญนำโดย Battery Ventures ร่วมด้วย Brick and Mortar กับ Trust Ventures เรื่องที่น่าสนใจกว่าตัวเลข funding คือ origin story สาม founder ไม่ได้มาจาก big tech แล้วเดา workflow ของอุตสาหกรรมก่อสร้าง แต่ build platform ตัวนี้ขึ้นมาในธุรกิจรับเหมาของตัวเองชื่อ Ernest ซึ่งโต 35 ล้านเหรียญ revenue และบริหาร project value รวมกว่า 1 พันล้านเหรียญใน 15 รัฐ หลังจาก run เอง 2 ถึง 3 ปีเห็นว่า agent ที่ handle RFI change order submittal daily log ช่วยประหยัดเวลา PM 15 ถึง 20 ชั่วโมงต่อสัปดาห์ จึง spin off เป็น product company product รวม 3 ชั้น development management construction management และ agent ที่ do ไม่ใช่แค่ track ซึ่งกินทั้ง Procore PlanGrid และ CoConstruct pattern ที่ repeat ชัดในปี 2026 คือ vertical agent startup ที่ founder มาจาก industry เอง และ build product ภายในธุรกิจตัวเองก่อน spin off กำลัง raise ที่ valuation สูงกว่า pure tech startup ที่มองอยู่ข้างนอก ของจริงคือ operator moat ก่อน code moat สำหรับผู้รับเหมาไทยและ developer ควรเริ่ม evaluate agent layer บน workflow เพราะ overhead ต่อ project 5 ถึง 8 เปอร์เซ็นต์ของต้นทุนรวมเป็น admin overhead ที่ agent แก้ตรงๆ สำหรับ Procore Autodesk Oracle Textura 12 ถึง 18 เดือนข้างหน้าน่าจะเห็น M and A activity ในวงการนี้เยอะขึ้น.

เรื่องที่สี่.
firmly ซึ่งเป็น startup agentic commerce ประกาศปิด Series A 15 ล้านเหรียญเมื่อวันที่ 5 พฤศจิกายน ทำให้ยอดสะสม 20 ล้านเหรียญ ตัวที่น่าสนใจคือ cap table Squarepoint Capital เป็น lead J.P. Morgan Payments Mastercard และ Samsung NEXT เข้าร่วม การที่ payment infrastructure giant สองรายเข้ามา signal ชัดว่า agentic commerce ไม่ใช่ fringe play แล้ว firmly launch product ชื่อ Ask Agent ซึ่ง merchant เอา JavaScript บรรทัดเดียววางบนเว็บ แล้ว shopper พิมพ์ความต้องการแบบธรรมชาติ agent ตอบ recommendation จาก catalog pricing และ inventory จริงเวลาของ merchant เอง จุดสำคัญคือ merchant ควบคุม catalog เอง ไม่มี marketplace commission ไม่มี agent คนกลาง และ integration แค่บรรทัดเดียว ตัวเลข early deployment conversion rate เพิ่ม 18 เปอร์เซ็นต์ AOV เพิ่ม 23 เปอร์เซ็นต์ ถ้าจริงเป็น proof point ที่หมวด agentic commerce รอมาทั้งปี caveat คือตัวเลขเป็น company-reported sample เล็ก selection bias เยอะ ต้องรอ independent case study 6 ถึง 12 เดือนข้างหน้า สำหรับ retailer ไทยที่มีเว็บ D2C ควร trial agentic conversational layer ภายในปีหน้า ไม่ใช่เพราะต้องรีบ แต่เพราะ customer habit กำลังเปลี่ยน shopper Gen Z คุ้นกับการถาม ChatGPT ก่อนตัดสินใจซื้อ ถ้าร้านไม่มี agent ของตัวเอง customer จะเดินผ่าน generic agent แล้วร้านเสีย personalization สำหรับ Shopify BigCommerce Salesforce Commerce Cloud ทุกคนจะปล่อย feature คล้ายๆกันใน Q1-Q2 2027.

เรื่องที่ห้า.
Agiloft ซึ่งเป็น contract lifecycle management vendor ระดับ enterprise ประกาศวันที่ 5 พฤศจิกายน เปิดตัว agent 3 ตัวใหม่ ทุกตัวถูกออกแบบให้ execute ไม่ใช่แค่ analyze ตัวแรก Bulk Update Agent รับคำสั่งแล้วไปอัปเดต contract หลายฉบับพร้อมกัน ตัวที่สอง Contract Request Agent ให้ business user พิมพ์ความต้องการแบบธรรมชาติ แล้ว agent หา request form ที่ถูกให้ ตัวที่สาม eSignature Agent for Adobe Acrobat Sign จัดการ flow ของการ sign ตั้งแต่ส่ง follow up log ไปจนถึง activate contract ข่าวที่ซ่อนใต้ 3 agent คือ MCP preview Agiloft เปิดให้ Claude และ external agent อื่นเข้ามา invoke action ใน CLM ผ่าน MCP server โดย respect permission เดิม นี่คือ pattern ที่ enterprise software vendor เริ่มทำแทบทุกราย เปิด agent surface ให้ customer เอา agent ของตัวเองมา drive ทำไมสำคัญ execution gap เป็น narrative หลักของ enterprise agent ปี 2026 AI ที่แค่ analyze ขายได้มา 2 ปีแล้วแต่ ROI วัดยาก การย้ายไป execute เป็น direction ที่ทั้งวงการต้องไปเพราะ CFO วัดได้ตรง MCP preview เป็น move ที่สะท้อนว่า vendor ที่ชนะปี 2027 คือคนที่ยอม distribute agent surface ให้ customer เลือก runtime เอง สำหรับคนที่สร้าง vertical agent บน enterprise SaaS ควร expose MCP เป็น default ไม่ใช่ feature premium สำหรับองค์กรที่ใช้ enterprise app ตอนนี้ต้อง audit ว่า vendor expose MCP ไหม การตั้งคำถามใน vendor review ปี 2027 ควรรวม MCP roadmap ถ้าไม่มี คุณกำลังอยู่ใน walled garden ที่ constrain agent strategy ของตัวเอง.
