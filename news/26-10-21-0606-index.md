## 🧭 Signal สำหรับ builder

- **ปลายปี 2026 investor pick layer แล้ว** — runtime (Daytona), protocol-to-vertical-SaaS (Neural Concept), identity (Sumsub + Opsin), context (Town / Instinct). 4 เลเยอร์, 5+ unicorn-level deal ในสัปดาห์เดียว. ถ้าสร้าง agent product อยู่ ให้คิดก่อนว่า **คุณขายของในเลเยอร์ไหน** — ไม่ใช่ generic "agent for X"
- **Sandbox / runtime กำลัง consolidate เร็ว** — Daytona + E2B + Modal + SPACE (open-source) + hyperscaler managed (AWS Bedrock AgentCore, Azure, GCP) — window ของ independent sandbox vendor เหลือ 12–18 เดือนก่อน hyperscaler bundle. ถ้าใช้ agent ใน production เลือก runtime เพื่อ future portability (MCP + Firecracker standard)
- **"Know Your Agent" ควรอยู่ใน security checklist ของทุก deployment** — ก่อน deploy agent ใน production ให้ security team ตอบ 4 คำถาม: (1) agent identity แยกจาก user ไหม (2) permission scope-down แล้วหรือ (3) action log ตรวจย้อนหลังได้ไหม (4) revoke access ยังไงเมื่อ compromise. Sumsub + Opsin + Microsoft Entra Agent ID คลุม 4 ข้อนี้ — vendor eval ไม่ต้อง build เอง
- **MCP connector สำหรับ enterprise software ที่ไม่มี API** คือ opportunity ขนาด unicorn — Neural Concept proof-point ของ CAD, ยังมีอีก 300+ vertical (PLM, EDA, legal, medical imaging, construction, logistics) ที่ยัง virgin market
- **Personal AI assistant = context moat ไม่ใช่ model** — ถ้าคิด build productivity agent ให้ focus deep integration กับ 10 app ที่ user ใช้จริง ไม่ใช่ chat UX ที่สวยสุด. User lock-in ของ Google / Microsoft ตอน Gmail / Outlook ครองโลกคือ playbook เดียวกัน
