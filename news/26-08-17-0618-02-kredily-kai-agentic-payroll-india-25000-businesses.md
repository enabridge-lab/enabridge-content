# Kredily 3.0 เปิด "KAI" agentic AI ทำ payroll + HR ทั้งกระบวนการ — ครั้งแรกใน India, 25,000 SMB, 1M employee, 110 skill = vertical agent moat ที่ SaaS ทั่วไปแย่งไม่ได้

## TL;DR
- **14 ส.ค. 2026** — Kredily ปล่อย **Kredily 3.0** พร้อมเปิดตัว **KAI (Kredily AI)** — agentic AI ตัวแรกใน India ที่ built-in ใน HRMS ไม่ใช่ plug-in
- **110+ skill** ครอบ payroll, attendance, leave, employee info, compliance workflow — ไม่ใช่แค่ตอบคำถาม แต่ **execute + validate + escalate exception** ให้ human approve
- **Install base 25,000 บริษัท, 1M+ พนักงาน** = ทันทีมี distribution ที่ agent startup ใน India ไม่มี
- **Independence Day promo** — DPIIT-recognised startup + Udyam-registered MSME ได้ **Bharat Payroll OS Plan ฟรี 1 ปี** — GTM push ครั้งใหญ่
- ประกาศเปิด **AI-powered Managed Payroll Services** เป็น business line ใหม่ — จาก software vendor → managed service provider

## เกิดอะไรขึ้น
วันที่ 14 สิงหาคม 2026 (ก่อน Independence Day India 1 วัน) **Kredily** — HRMS สัญชาติอินเดียที่เปิดมา 10+ ปี เจ้าของ install base ที่ใหญ่ที่สุดรายหนึ่งใน SMB segment — ปล่อยเวอร์ชั่นใหม่ **Kredily 3.0** พร้อมเปิดตัว **KAI (Kredily AI)** เป็น "**India's first agentic AI payroll agent built directly into an HRMS**" ไม่ใช่ chatbot plug-in ที่แปะเพิ่ม แต่ **built-in native** ตั้งแต่ core

จุดที่ Kredily วางกลยุทธ์ต่างจาก HR SaaS ทั่วไป: **KAI ไม่ใช่ Q&A assistant** — แต่รับ instruction ภาษาธรรมชาติ, **perform action ที่ได้รับ permission**, **validate outcome**, และ **surface exception ให้ human approve** ครบ loop ตัวอย่างที่ CEO วางไว้: user บอก "pull today's attendance, identify absences, process any leave request pending, generate payroll report, run payroll for the month" — KAI ทำครบชุด 4–5 step โดยที่ manager ดูแค่ exception list ท้ายกระบวนการ. Skill library เปิดตัวมา **110+ skill** ครอบทั้ง payroll cycle, attendance tracking, leave workflow, employee master data, และ compliance filing (PF, ESI, PT — critical สำหรับ India regulatory)

ตัวเลขที่ทำให้ทั้ง vertical เข้าใจ moat: **install base 25,000+ businesses ที่ serve พนักงาน 1M+ คน** = KAI มี distribution ทันทีที่ agent-native startup อย่าง **Sikha, Peoplebox, Zimyo** ไม่มี — plus ข้อมูล historical payroll transaction 10 ปีที่ใช้ fine-tune skill ให้เข้ากับ **India-specific rule set** (PF slab, TDS calculation ตาม budget ล่าสุด, state-wise PT variance) ที่ generic model อย่าง GPT/Gemini ตอบผิดเยอะ

Kredily ประกาศคู่กันว่าเปิด **AI-Powered Managed Payroll Services** — ก้าวจาก software vendor เข้าสู่ managed service (BPO) — เป้าคือ SMB ที่ไม่อยากรัน payroll เองเลย, จ่ายเป็น package: Kredily ทำทั้งหมด, KAI ทำงาน, มี human ops ดูแล exception เท่านั้น ราคาน่าจะต่ำกว่า traditional payroll processor (ADP India, Ramco, Excelity) 40–60% เพราะ headcount ต่อ 1000 employee client ต่ำมาก

**Independence Day promo** (Aug 15): **DPIIT-recognised startup** และ **Udyam-registered MSME** ได้ **Bharat Payroll OS Plan ฟรี 1 ปี** — GTM push ที่จะเพิ่ม install base อีก 5,000–10,000 บริษัทในไตรมาส Q3–Q4 ตามที่ Kredily ประกาศ

## ทำไมสำคัญ
เรื่องนี้เป็น **playbook สำคัญ** สำหรับ vertical SaaS ทั่วโลกที่มี install base ใหญ่แต่ยังไม่ได้ ship agent: **retrofit agent เข้า core product** ก่อนที่ agent-native competitor จะกัด market share Kredily รู้ตัวว่าถ้าปล่อยให้ Zimyo หรือ startup ใหม่ ship agentic HRMS ก่อน, install base จะกร่อนภายใน 18–24 เดือน — เลยเลือก push agent มา be first-mover ในช่อง **SMB India + regional compliance moat** ที่ global player (Workday, SAP SuccessFactors) เอื้อมไม่ถึงเพราะไม่มี India tax nuance

Pattern ที่ pattern-match ตรงกับหลายบริษัท: **install base × India-specific data moat = agentic advantage** — ไม่ใช่แค่ software feature อีกต่อไป **Kredily 3.0 model** = install base ให้ scale + regulatory nuance ที่ generic LLM ตอบผิด = agent ที่ trust ได้ในบริบท India ที่ Anthropic/OpenAI Enterprise ไม่ได้ตอบตรง

Signal ต่อจากนี้ 3 อย่าง: หนึ่ง — **HR SaaS ทั่วโลกจะรีบ ship agentic layer ในไตรมาสถัดไป** — Zoho People, greytHR, sumHR (คู่แข่งตรงใน India) จะประกาศตอบก่อนสิ้นปี. สอง — **Managed AI service = business model ใหม่** ที่ SaaS vendor เก็บ revenue เพิ่ม 3–5× ต่อ client จาก pure software subscription. สาม — **compliance-heavy vertical** (payroll, tax filing, health record, insurance) จะเป็น first battleground ที่ agent-native startup ล้ม Incumbent ที่ deploy agent ช้า

## มุม AI Agent Platform
**Builders** ที่สร้าง agent framework: ตัวอย่าง Kredily บอกว่า **skill library architecture** ที่ Anthropic push (Claude Skills) กำลังเป็น pattern ที่ enterprise ใช้จริง — **110 skill = 110 verified action** ที่ agent เรียก, ไม่ใช่ prompt template. Framework ที่รองรับ "skill as first-class primitive" (Claude Managed Agents, OpenAI Agent SDK v2) จะได้ tailwind; framework ที่พึ่ง generic tool-call ต้องเพิ่ม abstraction layer

**Users / business** ที่ deploy agent ใน workflow: บทเรียนจาก Kredily = **อย่ารอ agent-native startup มากิน แล้วค่อยขยับ** — บริษัทที่มี install base ใน vertical ตัวเอง (ERP, CRM, procurement) ต้อง **ship agent layer ใน 6–9 เดือน** ไม่งั้นเสี่ยง churn ตอน renewal cycle ปีถัดไป. บริษัทที่ compliance-heavy (accounting, healthcare admin, insurance claim) ควรมอง Kredily model — ใช้ agent + managed service เป็น bundled offering กินตลาด SMB ที่ปัจจุบันจ้าง BPO ราคาแพง

**Ecosystem**: คนได้ประโยชน์ (1) **vertical LLM/model tuning vendor** (Sarvam AI สำหรับ India, Krutrim, Ola AI) — ที่มี India-specific fine-tuned model จะเป็น backbone ของ agentic HRMS/ERP ในระลอกถัดไป, (2) **agent observability + audit vendor** — compliance workflow ต้อง log ทุก action ที่ agent take → market จะโตเร็ว, (3) **managed service provider ที่ pivot จาก manual → AI-augmented** จะได้ margin สูงขึ้น. คนเสีย = **traditional payroll BPO** (ADP India, Excelity, Ramco) ที่ยังจ่ายค่าคนทำ manual ต่อ transaction
