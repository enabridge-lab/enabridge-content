# Instinct ปิด $1B Series C ที่ valuation $10B ภายในเดือนเดียว — personal AI agent moment มาถึงจริงแล้วรึยัง

## TL;DR
- **Instinct** (San Francisco) ปิด Series C **$1 พันล้าน** ที่ valuation **$10 พันล้าน** 28 ก.ย. 2026 — Sequoia, Benchmark, Coatue ร่วม; **~4x valuation ภายใน 30 วัน** จากรอบ $250M ที่ $2.5B เดือน ส.ค.
- สินค้าคือ **personal agent** ที่คุยทาง **text + voice call** ทำงานแทนผู้ใช้: จอง trip, สั่งของ, ยกเลิก subscription, จอง reservation — ตัว agent ใช้ **computer/phone capabilities ของตัวเอง** act บน browser/app จริง
- Founder คือ **Noah Shinn** co-creator ของ **Reflexion** framework (LLM self-critique + iterative improvement). Service invite-only ตั้งแต่ ส.ค. 2026 — ยังไม่เปิดเลข revenue หรือ active users

## เกิดอะไรขึ้น

**Instinct** startup จาก San Francisco ประกาศ Series C มูลค่า **$1 พันล้าน** ที่ valuation **$10 พันล้าน** วันที่ 28 ก.ย. 2026. Sequoia Capital, Benchmark และ Coatue อยู่ในรอบ (สำนักข่าวต่างกันบอก lead ต่างกัน; Reuters ไม่ระบุ lead). ก่อนหน้านี้ 1 เดือน บริษัทเพิ่งปิด $250M ที่ $2.5B — **valuation โตเกือบ 4 เท่าภายใน 30 วัน** โดยไม่เปิดเผย revenue, active users หรือ unit economics อะไร

สินค้าคือ **personal AI agent** ที่ **"เข้าใจชีวิต digital ของคุณในระดับที่ละเอียด"** — ผู้ใช้คุยกับมันทาง **ข้อความ หรือ โทรศัพท์** (ไม่ใช่แอป chat ปกติ). มันใช้ **computer-use + phone-use capabilities ของตัวเอง** กดปุ่มในแอป, คลิกเว็บ, โทรร้าน — ตามโฆษณาของบริษัท agent สามารถวางแผน trip, สั่ง grocery, cancel subscription, จอง reservation ให้. บริการเปิด invite-only ตั้งแต่สิงหาคม 2026

Founder คือ **Noah Shinn** นักวิจัยอดีต Northeastern ที่ co-พัฒนา **Reflexion** — framework ที่ให้ LLM วิจารณ์ output ตัวเองแล้วปรับ next attempt. งาน Reflexion ปี 2023 กลายเป็น building block ของ agent loop เกือบทุกตัวในวงการ. ตอนนี้ Shinn เอา pattern เดียวกันมาสร้างบริษัท — personal agent ที่ **retry + reflect** ตัวเองได้เมื่อ task fail ครั้งแรก

ยังไม่ชัดเจนว่า Instinct รัน model ของตัวเองหรือเป็น application layer บน frontier model เจ้าใด; sources ไม่ confirm. บริษัทบอก fund ใหม่จะใช้ **ขยาย reach ของ agent** — ไม่พูดถึง research spend หรือ infrastructure build-out ชัดเจน

## ทำไมสำคัญ

Valuation 4x ภายใน 30 วันโดยไม่เปิด metric ใด ๆ ส่งสัญญาณ 2 เรื่อง: (1) **personal AI agent market กลายเป็น meta narrative** ที่ VC มองว่าใหญ่พอให้จ่ายล่วงหน้าเพื่อจองสิทธิ์, และ (2) **ของจริงยังหายาก** — ไม่งั้นบริษัทที่ปล่อย metric จะปิด round ที่ valuation สูงกว่าแน่. การไม่เปิด DAU/MAU/retention แสดงว่าตัวเลขเหล่านั้นอาจยังไม่โชว์ได้ (หรือยังเล็กเกินไป) และ VC จ่ายให้ **team + bet on category** มากกว่า business metric

**Instinct vs. frontier labs:** OpenAI เปิดตัว **Dots** (always-on personal agent) ที่ DevDay 29 ก.ย. — วันถัดจาก Instinct ปิด round. Meta มี **Muse**. Google เปิดตัว Gemini agent 8 ต.ค. (ซึ่งโฟกัส work ไม่ใช่ consumer). Instinct แข่งตรง ๆ กับทั้งหมดในฐานะ **standalone personal agent startup** — pricing model, retention curve, และ action trust จะเป็นสนามจริง. ที่ Shinn เลือก **text + phone call** เป็น primary interface ไม่ใช่แอป เป็นการตัดสินใจน่าสนใจ — เพราะมันทำให้ agent "available" ตลอดเวลาผ่าน channel ที่ทุก smartphone มีอยู่แล้ว ไม่ต้อง onboard app ใหม่

Pattern ลึกกว่าคือ **personal agent = frontend ใหม่ของ internet**. ถ้า agent คือคนที่ book flight, สั่งของ, จอง restaurant ให้คุณ — browser และ app ของ airline/Amazon/restaurant กลายเป็น **tool layer** ของ agent ไม่ใช่ destination ของ user. revenue chain ทั้ง e-commerce + travel + consumer SaaS ที่สร้างบน "user เปิดแอปแล้ว click" จะเริ่มถูก disrupt. Reflexion ที่ Shinn เขียนไว้ตั้งแต่ปี 2023 เป็นเหมือน blueprint ที่สุก — ตอนนี้ตลาดเพิ่งพร้อม

## มุม AI Agent Platform

**Builders** ที่สร้าง personal agent (Rabbit, Humane legacy, Persona, Friend, Pin) ต้องตอบ: distribution ของคุณคืออะไร? Instinct ใช้ **phone number** เป็น entry — ไม่มี device ไม่มี app ที่ต้องซื้อ. framework ที่สร้าง agent-powered consumer app (Vercel AI SDK, Mastra, Vapi for voice) ยังได้ประโยชน์เพราะ wave ของ personal agent app จะวิ่งผ่าน stack เหล่านี้. **Users:** คนทั่วไปที่ invite ยังไม่มา จะมี option เพิ่ม 3-4 ตัวในไตรมาสถัดไป — ควรเริ่มสังเกต **retention + action trust** ของแต่ละตัวว่าใครทำได้จริง. **Ecosystem:** Twilio, Vonage, และ voice-infra startup ได้ประโยชน์เพราะ phone-first personal agent ต้อง voice stack ที่ scale; **travel + e-commerce vertical** จะเริ่มเจอ pressure เรื่อง **agent-friendly API** (เร็ว, cheap, auth ที่รับ delegated authority) — ที่ยังไม่พร้อม ให้รีบ. ถ้า Instinct ที่ยังไม่เปิด metric เลยได้ $10B — คาดว่าหลัง DevDay + Gemini at Work, consumer agent valuation ที่เหลือจะขยับขึ้นทั้งหมด
