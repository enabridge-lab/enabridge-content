# วันเดียวเห็นสองบล็อค — Oracle backlog พุ่ง $664B / +26 พันล้าน, Adobe guidance พลาด, ตลาดสรุปแล้วว่า infra ชนะ app software ในยุค agent

## TL;DR
- 11 ก.ย. Oracle ประกาศผล fiscal Q1 2027 — **remaining performance obligations (RPO) พุ่งเป็น $664B** จาก quarter ก่อน (**+~$317B ใน quarter เดียว**); cloud infrastructure revenue **+121% YoY** เป็น $7.4B; new AI cloud contracts **>$30B** ใน quarter เดียว; 850 MW ของ new capacity + 300K GPU deployed
- Q1 EPS 1.47 miss estimate; **ตลาดไม่สน — หุ้น +7%** เพราะ backlog คือ signal จริง; ครึ่งหนึ่งของ $664B คาด convert เป็นรายได้ใน **36 เดือน**
- 10 ก.ย. หลังปิดตลาด **Adobe** report FY guidance **มิสประมาณการ** — Q4 revenue $6.8–6.85B ต่ำกว่า consensus $6.85B midpoint; หุ้น **−8%** วันรุ่งขึ้น, **YTD −25%**; Morgan Stanley เขียน note "serious trouble"
- Signal ที่ตลาดสรุปในวันเดียว — **AI infrastructure = winner; AI-adjacent app software = loser**; Oracle CFO Safra Catz กล่าวว่า backlog มาจากลูกค้า **prepay + BYO hardware** = ไม่กระทบ CapEx ในระดับที่นักลงทุนกลัว

## เกิดอะไรขึ้น

11 ก.ย. ตลาดหุ้นสหรัฐเปิดมาที่ 2 ข่าวที่ปล่อยหลังปิดของวันก่อนหน้า. Oracle report **fiscal Q1 2027** ที่จบ 31 ส.ค. — **remaining performance obligations $664 billion**. ตัวเลขนี้เป็นการ **jump ~$317 billion จาก quarter ก่อน** (จาก ~$347B) และเป็นการเพิ่มขึ้นเชิงตัวเลขที่ใหญ่ที่สุดครั้งเดียวที่บริษัท enterprise software เคยรายงาน. Cloud infrastructure revenue **$7.4B, +121% YoY**. บริษัทเซ็น new AI cloud contract มูลค่า **>$30B ใน quarter เดียว** — รวมดีลระดับ multi-year กับ OpenAI, xAI, Anthropic, และ hyperscaler competitor. Capacity added: **850 MW + 300,000 GPU**. Free cash flow **−$5.4B** จาก CapEx $28.5B — แต่ Oracle ระบุว่าสัดส่วนใหญ่ของ new contract เป็น **prepayment + bring-your-own-hardware** = customer จ่ายค่า infra ล่วงหน้าหรือเอาชิปมาเอง, Oracle เก็บค่า runtime/operations

CFO Safra Catz พูดในการโทรว่า **~half ของ $664B จะ convert เป็น recognized revenue ภายใน 36 เดือน** — คำนวณคร่าว ๆ ~$110B ต่อปี ในระยะ 3 ปีข้างหน้า จาก base cloud runtime ที่ปีก่อนอยู่ประมาณ $25B. หุ้น Oracle **+7% วันประกาศ**; CoreWeave (competitor รายเล็ก) **+4%**; Nebius **+4%**. Larry Ellison กลับขึ้นเป็น **richest person แซง Elon Musk ชั่วขณะ**

ในทางกลับกัน, 10 ก.ย. หลังปิดตลาด **Adobe** report Q3 earnings ที่จริงมีทั้ง revenue + EPS beat, แต่ **guidance ของ Q4** ระบุ revenue **$6.8B–$6.85B** — midpoint ต่ำกว่า consensus $6.85B ที่นักวิเคราะห์ประเมิน. Bloomberg เรียก reaction ตลาดว่า "renewing fears about AI impact"; Adobe หุ้น **−8% วันรุ่งขึ้น**, YTD **−25% จาก start of year**. Morgan Stanley ปรับ note ให้เป็น "**serious trouble**" — วิเคราะห์ว่า Adobe กำลังเสียส่วนแบ่งใน generative image/video/design ให้กับ AI-native competitor (Midjourney, Higgsfield, Freepik, Recraft, Ideogram, Runway, Adobe's own Firefly ที่ยัง lag)

ตัดกันในวันเดียว: หุ้น cloud infrastructure ราคาขึ้น, หุ้น application software ราคาลง. **Startup Fortune** เขียน headline สรุปตลาดในบรรทัดเดียว: "Oracle's Cloud Backlog Hits $664 Billion as Adobe Warns AI Is Hurting Software". นักวิเคราะห์ที่ Invezz อ้างมา: **"selling software into AI is harder than selling the infrastructure AI runs on."**

## ทำไมสำคัญ

**Pattern สำคัญที่สุด — AI stack กำลัง bifurcate อย่างชัดเจนใน equity market**. เดิม 2023-2024 นักลงทุนโบก tag "AI beneficiary" ให้ทุกบริษัทที่แตะ AI. ตอนนี้ตลาดแยกกลุ่มแล้ว:
- **AI infrastructure winner** — Oracle, NVIDIA, Broadcom, TSMC, ASML, CoreWeave, Nebius, hyperscaler compute (AWS, Azure, GCP); revenue = prepay/backlog visibility ยาว
- **AI application loser** — Adobe, Salesforce (แม้ Claudeforce ยัง), Workday, ServiceNow, HubSpot ที่ยัง demonstrate AI moat ไม่ชัด; revenue = seat-based license ที่ AI-native alternative กำลังกัด

Adobe เป็น canary — บริษัทที่มี Firefly + Sensei และเป็น pioneer AI ในสาย creative ยัง missed guidance = ตลาดเชื่อว่า **AI ทำให้ demand เพื่อ tool ของ human ลด**, และ subscription license ที่พึ่ง seat-count จะโดน hit เมื่อ 1 human + AI agent แทน 3-5 human. ระยะยาว = **application software ต้องเปลี่ยน pricing model** จาก seat → outcome-based ที่ agent เป็น buyer

**Signal ที่ 2 — $664B backlog ของ Oracle คือ evidence ว่าคำถาม "AI CapEx bubble" ผิดคำถาม**. บริษัท analyst พูดกันมาปีนี้ว่า NVIDIA + hyperscaler CapEx (~$500B ปี 2026) อาจ overbuild. Oracle disclose ว่า **$664B contract signed แล้ว** — ไม่ใช่ speculative. ครึ่งหนึ่ง = $332B/**36 เดือน** = **$110B/ปี** ของ AI cloud consumption จากลูกค้าที่ **จ่ายล่วงหน้าแล้ว**. คำถามใหม่ไม่ใช่ "จะมี demand ไหม" แต่คือ **"capacity supply-side จะพอทันไหม"** — และคำตอบชัด: **850 MW + 300K GPU per quarter** ก็ยังตามไม่ทัน backlog. Microsoft ประกาศ 38 GW buildout ในวันเดียวกัน = supply side ยังเร่ง

**signal ที่ 3 — "prepay + BYO hardware" คือ innovation ของ Oracle ในเชิง financial engineering**. Cloud model เดิม (AWS/Azure/GCP) = provider สร้าง data center + ซื้อ chip + ให้ลูกค้าเช่า pay-as-you-go. Oracle model ใหม่ = ลูกค้า (OpenAI, xAI, Anthropic) **prepay หรือ ship hardware ของตัวเองมา** ให้ Oracle host operations. ผลคือ Oracle **ไม่ต้องแบกความเสี่ยง GPU depreciation** เหมือน hyperscaler; margin structure จะดีกว่ามาก. Wall Street ตอบว่านี่คือ **Oracle's revenge** — บริษัทที่โดนเรียก legacy 5 ปีที่แล้ว กลายเป็น **shortest path ให้ frontier lab ได้ capacity เร็ว** โดยไม่ต้องเสีย equity

## มุม AI Agent Platform

**สำหรับ Builders** ที่กำลังสร้าง agent platform: pricing model ของ Adobe/Salesforce/Workday ที่ seat-based กำลังถูก AI-native disrupt. builder ที่วางตัวเป็น **"agent that replaces N seats"** ต้องคิด pricing แบบ **outcome/action-based** ตั้งแต่วันแรก — คิดค่าตาม (task completed, revenue generated, ticket resolved, ไม่ใช่ user/month). Framework infrastructure (Anthropic, OpenAI, Google) จะเก็บส่วนของตัวเอง, layer runtime (AWS AgentCore, Vertex Agent Builder) เก็บส่วน infra, และ **vertical agent platform** (Clay ที่ปิด $115M ที่ $7.1B เมื่อ 3 วันก่อน, Sierra, Harvey, Devin, Listen Labs) เก็บส่วน outcome. **ที่ต้องระวัง** — Oracle เข้าเกม vertical agent ยากเพราะ product ecosystem จำกัด, แต่ AWS/Google/Microsoft จะพยายามเก็บทั้ง infra + framework + vertical

**สำหรับ Users / Business**: 3 implication ทันที — (1) ถ้าคุณเป็นลูกค้า Adobe Creative Cloud, Salesforce, Workday, ServiceNow ที่กำลังจะ renew multi-year — **negotiate หนัก**. Vendor ตอนนี้ต่อสู้เพื่อ retention เพราะรู้ว่า seat-count จะลด; ใช้ AI substitution เป็น leverage. (2) **สำรวจ AI-native alternative** ทุก 6 เดือน — landscape เปลี่ยนเร็ว. เดิม 3 ปีเปลี่ยนครั้ง; ตอนนี้อาจ 6-12 เดือน. (3) ถ้าคุณจะ deploy agent runtime ระดับ enterprise ที่ต้องการ dedicated GPU capacity — **Oracle เป็น option ที่ต้อง evaluate** เพราะ **capacity available เร็วกว่า** hyperscaler ที่ waitlist ยาว 6-9 เดือน; ในไทยดูผ่าน Oracle Cloud Bangkok Region

**สำหรับ Ecosystem**: (1) **Salesforce กำลังอยู่ในตำแหน่งอันตราย** — แม้จะ close ดีล Claudeforce กับ Anthropic + ประกาศ Listen Labs $2B, ตลาดยังไม่มั่นใจ; ถ้า Adobe เป็น canary, Salesforce เป็น mine shaft. (2) **SI/consulting play เปลี่ยน** — Accenture ประกาศ Gemini Enterprise Business Group 1,000 FDE (8 ก.ย.), Deloitte + IBM ต้องตามใน 30 วัน. **บริษัทไทย/APAC ที่ทำ SI** (G-Able, MFEC, IBM Thailand, Deloitte SEA) ต้องเริ่ม hire GTM Engineer + Agent Ops Engineer profile ทันที. (3) **Thai cloud provider** (True IDC, NTT, INET) มี window เล็ก ๆ ก่อน Oracle Cloud Bangkok scale เต็ม — ควรวางตำแหน่งเป็น **local data residency + specialized vertical agent runtime** ที่ Oracle ไม่ทำ
