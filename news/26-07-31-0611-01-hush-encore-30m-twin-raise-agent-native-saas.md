# Hush + Encore ระดม $30M คนละราวเดียวกัน — เผยหน้าตา 2 SaaS category ที่ agent workforce ต้องซื้อ

## TL;DR
- **28-29 ก.ค.** — Hush Security ($30M Series A, Akamai lead strategic) + Encore AI ($30M Series A, Team8 led) ปิดรอบพร้อมกัน; รวม $60M ใน 24 ชม.เข้า **สอง layer ที่แตกต่างกันสิ้นเชิง** ของ agent stack
- **Hush = non-human identity + governance** (registry, JIT permission, kill switch, Kyndryl เป็น customer + reseller); **Encore = revenue-generating agent** (Interaction Mining, 10x ROI ใน lending case, ธนาคาร/insurance ที่เป็น customer convert เป็น investor)
- **Gartner (28 ก.ค.):** AI agent จะ outnumber seller **10:1 ภายในปี 2028**, แต่ **<40% ของ seller จะบอกว่า agent เพิ่ม productivity** — Dan Gottlieb (VP Analyst) เรียกว่า "value ceiling"; Melissa Hilbert เสริม "beyond a certain point, more AI does not mean more productivity"
- Signal ที่ pair กัน: **agent workforce กำลังกลาย standard**, แต่ 2 gap ที่ open — governance (Hush's play) และ outcome capture (Encore's play) — คือ SaaS category ใหม่ที่ทุก enterprise จะจ่าย

## เกิดอะไรขึ้น

ในช่วง 24 ชั่วโมงระหว่าง 28-29 ก.ค. สอง startup ที่แทบไม่มีอะไรเหมือนกันเลย ปิด Series A ขนาดเท่ากันเป๊ะ — $30 ล้าน. **Hush Security** ปิดวันที่ 28 นำโดย Akamai ในฐานะ strategic investor ใหม่, พร้อม Battery Ventures + YL Ventures ที่ double down; total funding แตะ $41M จาก stealth เมื่อไม่ถึงปีก่อน. **Encore AI** (rebrand จาก Insait IO) ปิดวันที่ 29 นำโดย Team8, Planven, The Garage — พร้อม Lukatz และ **ธนาคาร/insurance รายใหญ่หลายแห่งที่เดิมเป็น customer** แล้ว convert เป็น investor

สองบริษัทเล่นคนละมุมของ agent stack. Hush เข้าปัญหาที่ security team รู้ว่ากำลังระเบิด — **non-human identity crisis**. Platform ของ Hush enroll agent ทุกตัวเข้า central registry, ถอด standing credential ออกทั้งหมด, ให้เฉพาะ scoped just-in-time permission ตอน runtime, log ทุก action พร้อม kill switch ที่ security team กด terminate ได้ทันที. Founder ทั้งสี่ (Alon Horowitz, Micha Rave — CEO, Chen Niskorn, Shmulik Ladkani) มาจาก background identity/network security; และที่สำคัญ — **Kyndryl (IT infrastructure services ที่ใหญ่ที่สุดในโลก) ไม่แค่ใช้ Hush เอง แต่เริ่ม resell ให้ enterprise client**. Akamai's strategic check ยิ่งชัด — cloud edge vendor ต้องมี agent identity layer

Encore เข้ามุมตรงข้าม — ไม่ใช่ป้องกัน แต่ **ทำเงิน**. Interaction Mining คือเทคโนโลยีที่ analyze พฤติกรรม top performer ในทีม sales/service (voice, chat, email, IVR, form-fill), แยก action ที่ทำให้ conversion + revenue เพิ่ม, encode เป็น agent ที่ทำงานอัตโนมัติหรือคู่กับคน. CEO Dr. Dvir Ginzburg (Ph.D. Geometric Deep Learning, ex-Microsoft) เน้น narrative ที่ contrarian — "ไม่ใช่ deflection agent (ที่พยายาม deflect ลูกค้าไปจาก human agent), เป็น revenue agent". ผลลัพธ์ที่ยกมาโชว์: **10x ROI ภายในไม่กี่เดือน** สำหรับ lending client ขนาดใหญ่รายหนึ่ง; deployment ใช้เวลาไม่กี่สัปดาห์เพราะ ingest ข้อมูล operational ที่มีอยู่แล้ว (call recording, chat log, email thread)

ที่ทำให้ pattern เด่น: **ทั้งสอง signal เดียวกัน** — agent เข้า enterprise ในปริมาณที่ SaaS legacy ไม่เคยเห็นในประวัติศาสตร์. Gartner press release วันเดียวกัน (28 ก.ค.) ระบุว่า **AI agent จะ outnumber seller 10:1 ภายในปี 2028** — บวกกับ forecast 150,000+ agent per Fortune 500 company (จาก <15 ในปี 2025). และ Dan Gottlieb (VP Analyst, Gartner Sales practice) เตือน paradox ตรงนี้ทันที: **<40% ของ seller จะรายงานว่า agent เพิ่ม productivity** — เรียก "value ceiling" ที่เกิดจาก data foundation อ่อน, workflow integration ไม่ครบ, และ seller experience แย่

## ทำไมสำคัญ

**Two-category thesis ชัดขึ้นเรื่อย ๆ**: agent stack ในปี 2027-2028 จะไม่ได้แค่ซื้อ "agent" หรือ "framework" อย่างเดียวเหมือน SaaS 2015-2020. มันจะเป็น bundle ของ (1) **agent runtime** (Anthropic Claude Code SDK / GitHub Copilot SDK / OpenAI Agents SDK), (2) **agent identity + governance** (Hush + emerging competitors จะเข้ามาเยอะ), (3) **outcome capture layer** (Encore กำหนดใหม่ให้ agent = revenue center ไม่ใช่ cost center). ยุคที่ CIO buy "Salesforce + Zendesk + LDAP" จบ; ยุคใหม่คือ "runtime + registry + revenue attribution" ที่ทั้งสาม layer ต้อง interop กัน

**Gartner's value ceiling paradox = แผลใหญ่ที่ทั้ง Hush + Encore กำลัง sell into**. ทำไม <40% ของ seller ถึงบอกว่า agent เพิ่ม productivity? — เพราะ agent ไม่ integrate กับ workflow จริง (identity broken), ไม่วัดผล outcome จริง (revenue attribution broken), เลย feel เหมือน "AI theater" ที่ IT deploy. Hush's registry แก้ integration; Encore's Interaction Mining แก้ attribution. **ทั้งสองบริษัทกำลัง arbitrage ปัญหาเดียวกันจากคนละด้าน** — และตลาดใหญ่พอให้ทั้งคู่โต 10x โดยไม่แย่ง customer กัน

**Akamai's move = infrastructure vendor land grab**. Akamai ไม่ใช่ VC ปกติ — เป็น edge network + security vendor ที่รู้ว่า "AI agent identity" คือ next-decade primitive ที่ต้อง own. หลัง Cloudflare เปิด enterprise MCP reference architecture + AI Gateway ในเดือน เม.ย. (ที่ Enabridge cover แล้วเรื่อง MCP vulnerability); ตอนนี้ Akamai bet ผ่าน equity + strategic partnership. ปี 2027 จะเห็น Cisco, Palo Alto Networks, CrowdStrike, Zscaler ทำ move คล้ายกัน — ไม่ acquire ก็ deep partnership. **ผู้แพ้:** enterprise identity vendor legacy (Okta, Ping) ที่ไม่ปรับ model จาก human-first เป็น agent-first ภายใน 12-18 เดือน

## มุม AI Agent Platform

**สำหรับ builders:** ถ้ากำลังสร้าง agent framework หรือ runtime, ต้อง **treat identity + outcome เป็น first-class primitive ตั้งแต่ v1** — ไม่ใช่ optional module ที่ทิ้งให้ enterprise integrate เอง. specifically: (1) export agent capability declaration ที่ Hush-style registry รับได้ (JSON schema, OAuth-compatible), (2) instrument outcome hook ที่ Encore-style attribution engine query ได้ (per-turn business event log). Framework ที่ไม่มี 2 hook นี้ ในปี 2027 = ขาย enterprise ไม่ได้

**สำหรับ users/business (Fortune 500 + Thai SET50):** ถ้ากำลัง evaluate agent deployment, ต้องถามทุก vendor 3 คำถามใหม่ก่อน sign — (1) *"agent ของคุณ enroll เข้า identity registry ของเราได้ไหม (Okta/Entra/Hush/ในอนาคต)? มี kill switch ที่ security team เรากดได้ไหม?"*, (2) *"outcome attribution instrumentation มีมั้ย? เราคำนวณ ROI ต่อ agent ต่อ interaction ได้ยังไง?"*, (3) *"agent ของคุณ operate under standing credential หรือ JIT? ถ้า standing = ปฏิเสธ deploy ใน production regulated workflow"*. คำถามพวกนี้ปีที่แล้วไม่มีใครถาม; Q4 2026 จะกลายเป็น mandatory ใน RFP

**สำหรับ ecosystem (VC/investor/SI):** สอง sub-category ที่ยัง **crowded น้อยแต่ TAM ใหญ่**: (1) *agent identity/governance* — competitors ของ Hush ที่เห็นเริ่มมา: Astrix Security, Aembit, Slashid — window เปิด 12-18 เดือนก่อน Cisco/PANW acquire; (2) *outcome-based agent SaaS* — competitors ของ Encore: Regal.io (voice), Rox AI (sales agents) — market ยังไม่ crowded, differentiator = vertical depth + attribution accuracy. SI ที่ position "governance + outcome" bundle จะ premium 30-50% เทียบกับ generic agent integrator
