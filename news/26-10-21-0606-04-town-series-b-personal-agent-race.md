# Town ใกล้ปิด $90M ที่ unicorn — Forerunner + Menlo นำ หลัง Index Ventures ถอยเพราะ conflict กับ Instinct; สงคราม personal AI assistant เข้าเฟสจริง

## TL;DR
- 20 ต.ค. report: **Town** (บริษัท personal AI assistant ที่คุยกับ inbox / calendar / Slack / docs / messages ของคุณ) ใกล้ปิด Series B ขนาด **$90M** ที่ valuation **$1B** — ภายใน **4 เดือน** หลัง Series A ($55M นำโดย a16z, 3 มิ.ย.)
- รอบ co-lead โดย **Kirsten Green (Forerunner Ventures, existing)** + **Shawn Carolan (Menlo Ventures, new)**. Lead เดิม Index Ventures **เซ็น term sheet แล้ว แต่ถอน** หลัง **Instinct** (คู่แข่งโดยตรง, มูลค่า $10B หลัง Series C เมื่อกันยา) complain ว่า conflict of interest. Conviction (participated ใน Series A) ก็ถอยเช่นกัน
- **Instinct** ปิด Series C **$1B ที่ $10B valuation** วันที่ 28 ก.ย. โดย Sequoia + Benchmark + Coatue — คู่แข่งโดยตรงของ Town ในหมวด "AI chief of staff สำหรับ consumer"
- รอบนี้ยังไม่ปิด public (per Upstarts Media 3 ก.ย.) และ Town ยังไม่ประกาศทางการ แต่ตัวเลข $108M ที่บาง source อ้างยังไม่ยืนยัน — $90M ที่ $1B คือ figure ที่ corroborate ดีที่สุด

## เกิดอะไรขึ้น

Upstarts Media (Chris Metinko) report เมื่อ 3 ก.ย. และตามด้วย coverage วันที่ 20 ต.ค. ว่า **Town** กำลังปิด Series B $90M ที่ valuation $1B — ภายใน 4 เดือนหลัง Series A ($55M ที่ a16z นำ, มูลค่าไม่ประกาศแต่คาด ~$300-400M). รอบใหม่ co-lead โดย Kirsten Green แห่ง **Forerunner Ventures** (existing investor จาก Series A, ต้องการ double down) + Shawn Carolan แห่ง **Menlo Ventures** (new). ที่ dramatic กว่าตัวเลขคือ **Index Ventures เซ็น term sheet แล้ว** จะเป็น lead ของรอบนี้ตามรายงาน Newcomer เมื่อสิงหา — แต่พอ **Instinct** คู่แข่งโดยตรง complain ว่ามี conflict of interest Index Ventures เลยถอย. Conviction ที่ participated Series A ก็ถอยด้วย

**Instinct** คือ context สำคัญ — บริษัท personal AI agent ของ **Noah Shinn** (research scientist ชื่อดังจาก Reflexion paper) ปิด Series C **$1B ที่ $10B valuation** วันที่ 28 ก.ย. 2026 โดย **Sequoia + Benchmark + Coatue**. 10x ของ Town ชัดเจน, และ Instinct กำลัง scale ไปเป็น "AI chief of staff สำหรับทุกคน" ซึ่งเป็น positioning เดียวกับ Town เป๊ะ — connect ไป inbox, calendar, Slack, Notion, docs, messages, act on your behalf

Product ของ Town focus ที่ **professional (knowledge worker)** — assistant ที่อ่าน email แทน, draft reply, auto-schedule meeting ตาม priority, summarize Slack channel, update CRM, build weekly digest. ยังไม่มี public GA — early access invite only. Angel/investor ของ Series A มี Patrick Collison, Mathilde Collin, Alexandr Wang + a16z ที่ลงเสียงสำคัญ. CEO Vincent Wu ไม่ให้ comment ตอน Upstarts contact และ Town ยัง**ไม่ประกาศ Series B อย่างเป็นทางการ**

Numbers caveat: บาง source (รวม AI Agents Directory ที่สรุปข่าว 20 ต.ค.) อ้างตัวเลข $108M ไม่ใช่ $90M — ความน่าจะเป็นคือ (1) deal ขยายขนาด round หลังเข้าสู่ final close, หรือ (2) typo / report mixup. ให้ยืน $90M เป็น baseline จนกว่า Town จะ announce official

## ทำไมสำคัญ

Personal AI assistant คือ **consumer category ที่ขนาดใหญ่ที่สุดและ unproven ที่สุด** ของ agent wave. B2B agent (coding, SDR, support) มี unit economics ที่ Fortune 500 เขียนเช็คได้อยู่แล้ว — ROI คำนวณจาก seat cost ของ human ที่ถูกแทน. แต่ **consumer personal agent** คนไม่เคย pay $100/เดือนให้ assistant — ยกเว้นคนรวยกับ EA. Instinct กับ Town bet ว่า **generation ที่โตมากับ ChatGPT จะยอมจ่าย $20-50/เดือน** เพื่อให้ agent อ่าน email, จัด calendar, reply Slack, update CRM ให้. ถ้าถูก addressable market คือ 100M+ knowledge worker ทั่วโลก; ถ้าผิด เหลือแค่ early adopter 1-2M

Signal ที่ Index Ventures ถอน (เพราะ portfolio มี Instinct) + Conviction ถอน + Forerunner + Menlo กระโดดเข้ามาคือ **investor ชั้นนำกำลัง pick side** — ไม่ใช่ hedge 2 ม้า. Portfolio conflict ที่ส่วนใหญ่ซ่อนไว้ ตอนนี้ founder รู้แล้วและ demand firm choose. ประวัติศาสตร์มี precedent: Benchmark เลือก Uber แต่ไม่ Lyft, Sequoia เลือก DoorDash ไม่ Postmates. Portfolio decision ชั้นนี้มักกำหนด winner ของ category 5-7 ปีถัดไป

Deeper read: **personal AI assistant ไม่ใช่แค่ agent product — มันคือ data layer ของ consumer**. ใครที่ชนะชั้นนี้จะมี **context window ของทั้งชีวิต user** — email history, calendar pattern, Slack conversation, document ownership, address book. นั่นคือ moat ที่ Google / Microsoft / Apple / Meta มีมา 20 ปี, และตอนนี้ Instinct + Town กำลังสร้างใหม่ด้วย consent-based approach. ถ้าใครขึ้นสู่ unicorn / decacorn ชัดเจน (ตอนนี้ Instinct มี 10x ชัด) → Google / Microsoft น่าจะเสนอซื้อ 2027–2028

## มุม AI Agent Platform

สำหรับ **Builders** ที่สร้าง personal agent / productivity agent: **context layer คือ moat** — ไม่ใช่ model, ไม่ใช่ UI, ไม่ใช่ feature. การ build integration แน่น ๆ กับ 10 app ที่ user ใช้จริง (Gmail, Outlook, GCal, Slack, Notion, Linear, Figma, Salesforce, Chrome, iMessage) ทำให้ user ย้ายไปที่อื่นไม่ได้. การขายทางเดียวที่ชนะคือ **vertical integration ของ context + action**. สำหรับ **Users / Business**: ถ้าพิจารณา deploy personal agent ให้ทีม knowledge worker (sales, consulting, product) → eval Town, Instinct, Dust (ที่ EU), Rewind (ที่ apple-first) และถาม direct ว่า context ของ user **อยู่ที่ไหน, encrypted ยังไง, agent revoke access ยังไงเมื่อ user ออก**. วันที่ Instinct หรือ Town โดน breach คือวันที่ enterprise ทั้งหมด reset trust สำหรับ **Ecosystem**: Google, Microsoft, Apple กำลังสร้างตัวเองของตัวเอง (Gemini, Copilot, Apple Intelligence) — การแข่งขัน incumbent vs. startup ชั้นนี้คล้ายกับ Instagram vs. Facebook ยุคก่อนที่ Facebook ซื้อ. likely outcome: **1-2 startup ขึ้นสู่ decacorn, 1-2 ถูกซื้อ, อีกเป็น 10 ไปไม่รอด**
