# UBS เปิดตัวเลข 12,700 personal agent + 608 use case ใน Q3 — enterprise agent หลุด pilot เข้า production บน banking tier

## TL;DR
- UBS รายงานใน Q3 2026 earnings (28 ต.ค.) ว่าพนักงานใช้ **personal AI agent มากกว่า 12,700 ตัว** ใน workflow ประจำวัน
- **608 live production use case** +81% YoY, อีก **1,090+ use case** กำลัง build. **18,000 นักพัฒนา** ใช้ AI tooling, STAAT advisor สร้างแล้ว **30 ล้าน insight**
- Signal: นี่ไม่ใช่ pilot deck อีกต่อไป — bank tier 1 เปิดตัวเลข agent ใน earnings call เป็นหลักฐานว่า agentic deployment ย้ายจาก “น่าสนใจ” เป็น disclosure item ที่ CFO ต้อง benchmark
- สิ่งที่ยังไม่เปิด: ไม่มีตัวเลข ROI, ไม่บอก headcount รวม, ไม่แยก customer-facing vs internal, ไม่พูดถึง governance ของ personal agent

## เกิดอะไรขึ้น

28 ต.ค. 2026 UBS รายงานผลประกอบการ Q3 — net profit $2.69B +8% YoY ใกล้ consensus $2.71B. ที่โดดจริงไม่ใช่ตัวเลขกำไร แต่คือ **AI agent disclosure block** ที่ Sergio Ermotti CEO เลือกใส่ลง presentation. UBS เปิดว่าพนักงาน (บนฐาน ~110K คน หลัง integration Credit Suisse) **run personal AI agent มากกว่า 12,700 ตัว ใน daily workflow**, และมี **608 live production use case** เพิ่ม 81% จากปีก่อน, พร้อม pipeline อีก **1,090+ use case**

ตัวเลขที่น่าทึ่งอยู่ที่ **STAAT** (Strategic Advisor Assistant Tool) — AI tool สำหรับ financial advisor ที่ **generate insight 30+ ล้าน insight** ใช้งานใน client consultation. ด้าน engineering, UBS ยืนยัน **18,000 developer** ใช้ AI tooling (น่าจะเป็น Copilot + internal LLM + agentic coding assistant mix). บริษัทไม่เปิด vendor stack เต็ม แต่ก่อนหน้านี้ UBS ประกาศดีลใหญ่กับ Microsoft (Azure OpenAI + Copilot) และ Google Cloud

ที่ CFO Todd Tuckner highlight: cost-income ratio ลดจาก 77% เหลือ 72.3% YoY, FTE ลด ~1,500 คนใน quarter เดียว. UBS ไม่พูดตรงๆ ว่า AI คือ driver แต่ **การวาง 12,700/608/30M ไว้ข้างตัวเลข cost ratio** ส่งข้อความชัด — agentic workflow กำลังเป็นหนึ่งใน levers ที่ CFO ยอมรับ

## ทำไมสำคัญ

จุดสำคัญไม่ใช่ตัวเลขดิบ แต่คือ **การย้าย disclosure venue** จาก “keynote demo” → “Q3 earnings slide”. เมื่อ bank tier 1 ตัดสินใจเปิด production agent number ใน earnings call แปลว่า investor relations team และ auditor เห็นว่าตัวเลขนี้ (a) ตรวจสอบได้, (b) ต้อง benchmark กับคู่แข่ง. ปีหน้า JPMorgan / Morgan Stanley / Deutsche Bank มี pressure ต้องเปิดตัวเลขเดียวกัน — ไม่งั้นดูเหมือนตามไม่ทัน

Pattern อีกข้อที่สำคัญ: **personal agent 12,700 ตัว > 608 use case** หลายเท่า. แปลว่า UBS ไม่ได้วาง enterprise agent แบบ top-down (central team สร้าง 608 agent ให้พนักงานใช้) — แต่เป็น hybrid: central team ทำ production use case + พนักงานสร้าง personal agent ของตัวเองหลายหมื่นตัว. นี่คือ **employee-driven agent sprawl** ที่ Mintive (เรารายงานไปเมื่อวาน) เรียกว่าปัญหา governance อันดับหนึ่งของ 2027. UBS อยู่ตรงนั้นแล้ว

สิ่งที่ UBS ไม่พูดสำคัญไม่น้อยกว่าสิ่งที่พูด — **ไม่มี $ saving**, ไม่มี **time-to-decision reduction**, ไม่มี **error rate reduction**. บริษัทเลือกเปิดเฉพาะ activity metric (จำนวน agent, จำนวน use case, จำนวน insight) ไม่ใช่ outcome metric. นี่คือ pattern ที่ Stratechery เตือนบ่อย — ตัวเลขดูใหญ่แต่ยังไม่พิสูจน์ว่าสร้าง alpha. BoA / Citi ที่พูดเรื่อง AI ปีที่แล้วทำแบบเดียวกัน แล้วตัวเลข cost ratio ไม่ขยับเท่าที่คาด

## มุม AI Agent Platform

สำหรับ **builders** (Mintive, Rein, LangChain, Cresta ที่เราคุยในเรื่อง 03): UBS คือ reference customer tier 1 ที่ทุก enterprise agent vendor ต้องชี้ให้ CISO ของ bank อื่นดู. ถ้า UBS กล้าใส่ personal agent 12,700 ตัวบน desktop, bank ขนาด mid tier ไม่มีข้ออ้างว่า “pilot ก่อน” อีกต่อไป. governance layer (identity, audit, cost cap) จะมี demand ก้าวกระโดด

สำหรับ **users / business** ที่กำลัง deploy: UBS แสดงให้เห็นว่า **personal agent sprawl เป็น feature ไม่ใช่ bug** — ถ้ามี governance ที่ cap token spend + audit trail per user, การปล่อยให้พนักงานสร้าง agent เองคือทางที่สเกลเร็วกว่า central team. ตัวเลข 1,090 use case ใน pipeline สะท้อนว่า central team ไม่สามารถเป็น bottleneck ได้. CFO ที่ไทยและ SEA ควรเริ่มคิด **per-employee agent budget** ไม่ใช่ **per-use-case budget** ตั้งแต่ตอนนี้

สำหรับ **ecosystem**: ตัวเลข 18,000 developer ใช้ AI tooling คือสัญญาณว่า **IDE assistant ไม่ใช่ feature แต่เป็น infrastructure** — บวกกับ Cresta เปิด self-service build (เรื่อง 03) และ OpenAI Agents API เพิ่ม Auto Review (เรื่อง 04), developer workflow กำลังถูก re-platform. Microsoft (Copilot), GitHub, Cursor, Anthropic (Claude Code) อยู่ในสงคราม distribution ที่จะชี้ว่า bank/corp 10 ปีข้างหน้าซื้อจากใคร
