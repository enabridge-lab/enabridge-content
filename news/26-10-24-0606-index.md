## 🧭 Signal สำหรับ builder

- **Agent identity กำลังแยกเป็นเลเยอร์ของตัวเอง — ไม่ใช่ feature ของ agent runtime** — 4 ประกาศ 48 ชั่วโมงนี้ (Walmart Agent Gateway approved list + ServiceNow AI Passport silicon-rooted + 1Password credential proxy + ก่อนหน้า AWS Bedrock AgentCore identity + Google Agent Compute Engine session-scoped identity) ทั้งหมดบอกเรื่องเดียวกัน: identity ของ agent ต้องแยกจากตัว agent เพราะ agent หลายตัวจาก vendor ต่างกันทำ task ให้คนเดียวกัน + credential ใน context = attack surface + regulated industry ต้องการ audit trail. ไม่มี unified spec, enterprise ต้อง support 3-4 standards คู่ขนาน. **"Identity adapter"** เป็น greenfield ที่ยังว่าง
- **Agent runtime pricing เข้าสู่ race-to-zero** — ServiceNow bundle Arc ลง base SKU, Oracle bundle 600+ agent ใน Fusion/Industry Apps, Google ACE ให้ compute per-request. agent builder เองหมด premium pricing ภายใน 12 เดือน. เงินจะไปอยู่ที่ **(1) domain context + workflow data** (vertical SaaS incumbent ชนะ), **(2) identity + credential + governance** (neutral vendor อย่าง 1Password, Opsin ชนะ), **(3) compute + silicon** (NVIDIA, AWS Trainium, Google Titanium IPU)
- **MCP กลายเป็น "store door" ของอินเทอร์เน็ต** — Walmart commit MCP เป็น commerce protocol ครั้งแรกของ Fortune 1 retailer. ภายในปี 2027 Target, Costco, Best Buy, Home Depot น่าจะตาม + payment network (Visa Intelligent Commerce, Mastercard Agent Pay) จะวาง settlement layer ให้. Shopify, BigCommerce, Adobe Commerce ต้อง ship native MCP endpoint ไม่ใช่ AI SEO plugin
- **Enterprise AI deployment ตัวเลขเริ่มใหญ่พอ แต่ ROI data ยังไม่เปิด** — VW 330k + 26k agent, Deloitte 450k, Accenture 750k, แต่ **ไม่มีใครเปิด $ saved หรือ outcome per agent**. CFO ตัดสินใจบน vendor claim. ตลาด "AI agent observability + outcome tracking" (Opsin, Arena, Dataiku) จะโตเร็วมากใน 2027 — เพราะ CIO ต้องการ proof ไม่ใช่ marketing deck
- **AAIF roster ขยายเร็วกว่าคาด — 10 projects, 20+ ภายใน Q2 2027** — layer stack ของ agent consolidate ภายใต้ neutral governance ไว. Agent Skills + Open Responses + MCP + A2A + Goose + OpenEnv + OpenSandbox = enterprise purchasing checklist. vendor ที่ไม่พูด standard ครบจะ lose default option. layer ที่ยังว่าง (identity, payment, observability) = greenfield สำหรับ startup ที่ ship + donate ให้ AAIF ก่อน incumbent — จะได้ brand "default standard"
