# Bessemer ปิดกอง $5.75B — $4B growth + $1.75B early — และประกาศ "agentic operating layer" คือ thesis หลัก

## TL;DR
- **23 ก.ย.** — Bessemer Venture Partners ปิดสอง fund รวม **$5.75 พันล้าน**: **$1.75B** สำหรับ seed/early-stage และ **$4B** สำหรับ growth-stage vehicle ใหม่ที่ตั้งมาเจาะ "AI-native ที่อยู่ private นานกว่ารุ่นก่อน". ตั้งแต่ 2022 Bessemer วางเงิน **$3B+** ลง **260+** AI-native cos — Anthropic, Cognition, Perplexity, Legora, Ramp, Waymo อยู่ในกอง
- Explicit agentic thesis: อ้างชื่อ **Cognition (Devin, ARR $900M)** และ **Wonderful** ("agentic operating layer for enterprises worldwide", Series C $550M) เป็นสอง marquee bet — "quadrupled down" ทั้งสอง; วาง Wonderful เป็น one of the fastest growing companies ใน portfolio
- Statement of belief: **"AI-native reaching $100M ARR faster than any technology category in history"** — Bessemer เรียกยุคนี้ว่า "The Agentic Awakening"; growth-stage $4B ตั้งใจ underwrite ราคาสูง เพราะ compound curve ของ agent workload กำลังชันขึ้น

## เกิดอะไรขึ้น

**เช้าวันที่ 23 กันยายน** Bessemer Venture Partners ประกาศปิดสอง fund พร้อมกันรวม **$5.75 พันล้าน**: **BVP Fund XII** ที่ **$1.75B** สำหรับ seed และ Series A/B และ **BVP Century** ($4B) ซึ่งเป็น growth-stage vehicle ที่ตั้งขึ้นใหม่ — ตัดออกจากสาย main flagship — ตั้งใจ underwrite deal ในบริษัทที่ "elect to stay private longer" — ยาก private company ในยุค 2026 ที่ ARR โตเร็วแต่ IPO ยังไม่รีบไป. Natasha Mascarenhas จาก Bloomberg รายงานว่า Bessemer positioning $4B นี้เพื่อเข้า round ที่ valuation สูงมาก ๆ ให้กับ AI-native ระดับ growth ที่ไม่อยากรับ dilution ที่ระดับที่ต่ำกว่านั้น

Bessemer พูดตรง ๆ ว่านี่คือ **AI-focused vehicle** — ตั้งแต่ 2022 firm วางเงิน **$3B ข้าม 260+ AI-native cos** จาก compute layer (Anthropic), agent framework (Cognition, Wonderful), consumer AI (Perplexity), infra ที่ทำงานกับ AI (Ramp, Shopify), และ physical AI (Waymo). Byron Deeter, partner ที่นำ AI practice, เขียนใน announcement blog ตรง ๆ ว่า **"AI-native companies are reaching $100 million in ARR faster than any technology category in history"** — เป็นสถิติที่แม้แต่ยุค cloud SaaS (Salesforce, Workday, Snowflake) ก็ทำไม่ทัน

จุดที่น่าสนใจใน announcement — Bessemer ตั้งชื่อ thesis ยุคนี้ว่า **"The Agentic Awakening"** (ปล่อยเป็น research report แยกวันเดียวกัน) และย้ำสอง marquee bet: **Cognition** ผู้สร้าง Devin ที่ recent round ประเมิน valuation $48B บน ARR $900M (Bessemer เพิ่มลงในทั้ง Series A, B, C), และ **Wonderful** ที่ Bessemer เรียกว่า "agentic operating layer for enterprises worldwide" — เข้าตั้งแต่ seed 2025 แล้ว quadruple down ใน Series C $550M ต้นปี 2026. Bar Winkler (CEO Wonderful) และ Scott Wu (CEO Cognition) ถูกวางในตำแหน่ง "founder-in-residence template" ที่ Bessemer จะใช้เป็น pattern-match กับ deal ต่อ ๆ ไป

**บริบทที่ทำให้ตัวเลขนี้เจ็บกว่า numeric size:** Bain Capital Ventures เพิ่งประกาศ "Life After AGI" fund $1.6B เมื่อวันจันทร์ (22 ก.ย.) — thesis คือ foundation model race จบแล้ว มูลค่าย้ายไป workflow layer. Bessemer $5.75B วางในทิศเดียวกันแต่ scale ต่างระดับ; รวมสองประกาศในสัปดาห์เดียว = VC top tier กำลังโยก **$7B+ ใหม่** เข้า agentic stack. Cambrian VC ระดับ growth ครั้งใหญ่ที่สุดตั้งแต่ยุค cloud infrastructure ปี 2013–2015

## ทำไมสำคัญ

**Growth-stage $4B fund คือ signal ที่ underrated กว่า seed $1.75B.** Seed fund ใหม่ทุกไตรมาสมี VC ประกาศ, แต่ dedicated growth vehicle ขนาด $4B ที่ตัดออกจาก main flagship = statement ว่า Bessemer เห็น pipeline บริษัทที่ **ARR $50M–$500M ต้องการ growth check $50M–$300M ใน 12–24 เดือนข้างหน้ามากพอจะกินเงิน $4B**. ถ้าเทียบกับ deployment pace ของ firm ที่ผ่านมา (ประมาณ 30–40 growth deal/ปี), $4B จะกินเวลา 3–4 ปี — เท่ากับ Bessemer bet ว่า agent economy จะ compound ต่อเนื่องอย่างน้อยจนถึงต้น 2030 โดยไม่มี correction ใหญ่

Pattern ที่เห็นชัดขึ้น: **VC top-tier กำลังเลิก diversify ในกอง traditional SaaS/consumer แล้วโยกน้ำหนักไป AI/agent เกือบ 100%.** ปีที่แล้ว a16z ปิดกอง $20B, Sequoia ปรับ structure ไปเป็น evergreen, และ Founders Fund กับ Lightspeed ปรับ mandate. Bessemer ที่เคยชื่อ Enterprise SaaS มากที่สุดในกอง — Shopify, HubSpot, LinkedIn เป็นต้น — ทีนี้ประกาศตรง ๆ ว่า **default portfolio ของยุคหน้าคือ agentic**. Signal นี้กับ BCV Life After AGI = double confirmation ที่ founder ที่ pitch "workflow SaaS ไม่มี agent core" กำลังจะเหนื่อยกว่าเดิมเยอะ

จุดที่ต้องจับตา 6 เดือนข้างหน้า: **Wonderful กับ Cognition จะเป็น IPO candidate หรือ acquisition target?** Cognition ที่ $48B valuation กับ ARR $900M มี multiple ~53x — สูงแต่ไม่สุดโต่งเทียบกับ Databricks / Snowflake ยุคที่ IPO. Wonderful ที่ยังไม่เปิด ARR แต่ Bessemer ใช้คำว่า "one of the fastest growing" หมายถึงน่าจะ >$100M ARR แล้ว. ถ้ามีตัวใดตัวหนึ่งไป IPO ในต้น 2027, จะเป็น proof point แรกที่ agentic-native ทำ IPO สำเร็จ — และเปิด public market comparable ให้ทุก agent startup ที่ตามมา

## มุม AI Agent Platform

สำหรับ **builders** ที่กำลังสร้าง agent framework / orchestration / vertical agent app — Bessemer $4B growth ที่ open door ให้ deal ระดับ $50M–$300M เข้ามาที่ Series C/D-stage นี้ = **capital availability ไม่ใช่ bottleneck อีกต่อไป** สำหรับทีมที่มี traction ชัด. ที่กลายเป็น bottleneck จริง ๆ คือ **distribution + moat** — ทีมที่ยังตอบไม่ได้ว่า agent ของตัวเองใช้ทำอะไร (ใครใช้ deploy scale ไหน คุ้มค่ากว่า incumbent ยังไง) จะ raise round ยากขึ้น เพราะ investor top-tier มีตัวเลือกมากขึ้น. Cognition / Wonderful pattern = ต้องมีทั้ง technical differentiation + enterprise deployment proof

สำหรับ **users / business** ที่กำลัง deploy agent — Bessemer thesis "quadruple down" บน Wonderful เป็น signal ที่ enterprise buyer ต้องอ่าน: ถ้า VC top-tier เชื่อว่า agentic OS จะเป็น layer ถาวรในทุกองค์กรใหญ่, ทีม IT/procurement ที่ยังไม่มี agent platform strategy จะกลายเป็น laggards ใน 12 เดือน. Playbook แนะนำ: identify 1–2 workflow ที่ agent สามารถแทนที่ได้ก่อน Q4, run pilot, วัด ROI ที่ตัวเลข concrete (คน-ชั่วโมงประหยัด, cycle time, revenue lift) — เตรียมข้อมูลไว้สู้ budget ปี 2027

สำหรับ **ecosystem** (cloud provider, model lab, protocol standards body) — $5.75B ใหม่ที่จะไหลเข้า agent startup ในสาม-สี่ปีข้างหน้า จะสร้าง demand ให้ compute (AWS/GCP/Azure margin), model API call (Anthropic/OpenAI/Google — ที่ commoditize ตัวเองต่อเนื่อง), MCP/A2A protocol adoption, และ observability tool (Raindrop, AIUC, Braintrust). Layer ที่ underinvested ตอนนี้และน่า watch: agent identity/governance (WSO2 Agent Manager, Okta agent tier), agent evaluation (Braintrust, Ragas), agent runtime (Modal, E2B) — เหล่านี้จะเป็น pick-and-shovel play ในสอง-สามปีข้างหน้า
