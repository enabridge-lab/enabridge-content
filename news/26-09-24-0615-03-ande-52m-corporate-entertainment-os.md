# Ande $52M — จอง corporate entertainment $400M/ปีผ่าน agent workflow กับ 60 enterprise รวม Cloudflare / Salesforce / McGraw Hill

## TL;DR
- **22–23 ก.ย.** — **Ande** (New York) exit stealth ประกาศ **combined $52M** seed + Series A นำโดย **Lightspeed** และ **Redpoint** (Duration, Sierra, Bain Capital Ventures co-invest); positioning ตัวเองเป็น "first Entertainment Operating System for Enterprises" — agentic workflow ที่จอง venue, route approval, sign contract, reconcile expense ในระบบเดียว
- **ตัวเลขจริง:** **60+ enterprise** customers รวม **Cloudflare, Salesforce, McGraw Hill** รัน **>$400M/ปี** ผ่าน platform ครอบคลุม network **93,000 venues** ใน **90+ cities**; customer report cost saving **12–15%** เทียบกับ manual booking
- **ทำไม matter:** vertical agent OS แนวที่ Zach Zeliff (CEO) เรียกว่า **"multiplayer workspace"** — EA, office manager, field marketer, GTM team ทำงานร่วมกับ manager ใน single UI ที่ agent ทำ workflow ให้ ไม่ใช่ระบบ chatbot ตัวเดียวรับ input; pattern นี้กำลังกลายเป็น template ของ enterprise agent product

## เกิดอะไรขึ้น

**เย็นวันที่ 22 กันยายน** Ande — startup ที่ก่อตั้งโดย Zach Zeliff (CEO, ex-Sierra product), Nika Iranfar (CTO, ex-Uber staff eng), และ Rebecca Sharfstein (COO, ex-Cvent) — exit stealth หลังทำงานอยู่ 18 เดือนโดยไม่เปิดตัว. Financing announcement รวมทั้ง **seed round** จากช่วงต้น 2025 กับ **Series A** ที่เพิ่งปิดในไตรมาส 3 นี้ — **$52M combined**. Lead investor: **Lightspeed Venture Partners** สำหรับ Series A, **Redpoint** สำหรับ seed. Co-investor รวม **Duration Capital, Sierra Ventures, Bain Capital Ventures** — BCV ที่เพิ่งประกาศ "Life After AGI" fund $1.6B วันจันทร์เข้ามาที่ round นี้ด้วย

**Product positioning:** Ande อธิบายตัวเองว่าเป็น **"first Entertainment Operating System for Enterprises"** — สิ่งที่ประกอบเข้ามาคือ (1) marketplace หลังบ้าน 93,000 venue ใน 90+ city ที่ pre-integrated กับ availability + pricing API, (2) agentic workflow ที่รับ input จาก team lead ("จองที่จัด offsite 50 คนใน SF ต้นเดือนหน้า") แล้ว agent scan availability, generate 3-5 option ให้ EA ยืนยัน, ส่ง approval ไป finance ผ่าน routing rule, sign contract via DocuSign integration, และ reconcile expense เข้า Concur/Ramp/Brex, (3) **multiplayer workspace** ที่ EA, office manager, field marketer, กับ GTM team ทำงานร่วมกันใน single UI

**ตัวเลขที่ Ande เปิดในประกาศ:** **60+ enterprise customer** — Cloudflare, Salesforce, McGraw Hill เป็น anchor logo. รวม **>$400M ต่อปี** ในค่าใช้จ่าย corporate entertainment (offsite, deal-closing dinner, client gift, team building) รันผ่าน platform. Customer report **12–15% cost saving** เทียบ manual booking baseline — driven by volume rate negotiation กับ venue partner ที่ Ande ทำเชิง group

**บริบท founder + market:** Zeliff เคยเป็น product lead ที่ Sierra (agent platform ของ Bret Taylor + Clay Bavor) — บริบทที่ทำให้ Ande architecture ดู "native agent" ไม่ใช่ SaaS workflow ที่ทาบ agent layer ทีหลัง. Corporate entertainment ในสหรัฐเป็น TAM ประมาณ **$110B/ปี** ตามรายงาน Sage Corporate Travel Index; ก่อนหน้านี้ตลาด fragment ระหว่าง Cvent (event management), TripActions/Navan (business travel), และ Marriott/Hilton group booking channels — ไม่มี layer เดียวที่จบ workflow end-to-end. Ande วางตัวเองในช่องนั้น

## ทำไมสำคัญ

**$400M/ปี รันผ่าน platform ก่อน exit stealth = signal ว่า vertical agent SaaS โตเร็วกว่าที่ VC จับได้.** ปกติ agentic startup ที่เพิ่ง exit stealth มี ARR ระดับ $1M-$5M เป็น "impressive". Ande ที่ intermediate $400M gross spend ผ่านตัวเอง (Ande ไม่เปิด take rate แต่ในตลาด travel/entertainment platform ปกติ take 8-15%) = **ARR น่าจะอยู่ในช่วง $32M-$60M ก่อน exit stealth** — เทียบเท่า Series C stage ในยุค SaaS traditional. Bessemer bulldog thesis ที่บอก "$100M ARR เร็วที่สุดในประวัติศาสตร์" ตอนนี้เห็น proof point ที่จับต้องได้

Pattern ที่เริ่มชัด: **vertical agent OS = winning product shape ยุคนี้**. Ande (entertainment), Wonderful (general enterprise OS), Ramp (finance), Harvey (legal), Sierra (customer service), Cursor (coding) — ทั้งหมด follow pattern เดียวกัน: (1) ปิดตลาด vertical แคบพอที่ agent จะแม่นยำสูง, (2) multiplayer workspace ที่ human กับ agent ทำงานร่วมกันไม่ใช่ agent แทน human 100%, (3) integrate เข้ากับ system of record เดิม (DocuSign, SAP Concur, Salesforce) แทนที่จะขอ replace, (4) ราคา per-seat หรือ per-transaction ไม่ใช่ per-token — align กับ enterprise procurement ที่ต้องการ predictable spend

จุดที่ต้องจับตา 6-12 เดือนข้างหน้า: **Cvent, Navan, TripActions ตอบยังไง?** ทั้งสามมี distribution กว้างกว่า Ande มาก (Cvent มี 300,000+ event professional customer, Navan มี Fortune 500 majority) แต่ architecture เป็น legacy SaaS. ในตลาดเดิมพวกเขาชนะ Ande ได้เพราะ integration ที่มีอยู่แล้ว — แต่ถ้า agentic workflow กลายเป็น table stake, ต้อง rebuild backend + workflow layer ครั้งใหญ่. ปีที่ผ่านมา Cvent เพิ่งประกาศ "Cvent AI Agent" — beta ล้วน, ไม่ทันตลาด. Ande position ตัวเองในช่อง "cloud-native agent-native" ที่ incumbent ตามยาก

## มุม AI Agent Platform

สำหรับ **builders** ที่กำลังคิด vertical agent product — Ande case study บอก playbook ชัด: (1) เลือก vertical ที่มี **large but fragmented spend** (entertainment $110B TAM, fragmented across 10+ ช่องทาง), (2) build agent workflow ที่ **integrate เข้าระบบเดิม** ไม่ใช่ replace, (3) charge ตาม **transaction volume** ไม่ใช่ per-agent-call เพราะ enterprise budget คิดแบบนี้อยู่แล้ว, (4) hire early team จาก **domain expert + agent platform experience** (Ande: ex-Cvent COO + ex-Sierra product) เพื่อ credibility กับ enterprise buyer, (5) exit stealth เมื่อมี $100M+ gross volume ผ่าน platform เท่านั้น — ไม่ใช่ตอนมี prototype

สำหรับ **users / business** ที่ deploy agent ในองค์กร — Ande pattern แสดงให้เห็นว่า **agent product ที่ success ในองค์กรใหญ่ไม่ได้แทน human 100%** แต่เป็น "AI-forward workflow" ที่ human ตัดสินใจส่วนสำคัญ (approve budget, ยืนยัน contract) และ agent ทำส่วน grunt work (search venue, draft contract, route approval). Playbook: identify workflow ที่มี **repeatable pattern + high-volume + human decision at critical points** — เหล่านี้คือ candidate ที่ agent ROI ดีที่สุด. Corporate entertainment เป็นตัวอย่างเพราะ 80% ของงานคือ search + coordinate, 20% คือ decision. Agent จับ 80% เร็วกว่า human 10x

สำหรับ **ecosystem** (payment, contract, expense system) — Ande revenue เก็บผ่าน take rate on venue booking + subscription per-seat. แต่ integration ที่สำคัญคือ **DocuSign (contract signing), SAP Concur / Ramp / Brex (expense reconciliation), Slack / Teams (approval routing)**. เจ้าของ payment rail กับ contract signing กำลังเป็น "invisible backbone" ของ agent economy — Ramp, Brex, Mercury, และ Stripe ที่เพิ่งประกาศ Agentic Toolkit ในไตรมาส 2 = infrastructure play ที่ยังไม่ crowd. เจ้าที่จับ agent-driven B2B payment ได้ก่อนจะเก็บมูลค่ามหาศาลใน 3-5 ปีข้างหน้า
