## 🧭 Signal สำหรับ builder

- **Agent runtime คือ layer ที่ hyperscaler ขายได้โดยตรง** — Google ACE + AWS Bedrock AgentCore ตัดสินใจพร้อมกันว่า agent compute เป็น primitive คนละ bucket กับ container/VM เดิม. isolation ระดับ hardware + session-scoped identity + no-secret-on-disk กลายเป็นมาตรฐานที่ regulated workload (finance, healthcare, defense) ต้องการ. framework ที่ compile ลง microVM primitive ได้โดยตรงจะมี distribution advantage; ที่ไม่พูด Agent Substrate/AgentCore protocol จะต้องมี wrapper layer เพิ่ม
- **"Neutral agent cloud" vs "hyperscaler agent cloud" เป็นสนามแข่งใหม่** — Daytona bet $1B valuation ว่า portability จะชนะ lock-in เหมือนที่ Kubernetes ชนะ hyperscaler-specific orchestration. Investor mix ที่มี Qualcomm + Samsung + Okta ชี้ว่า Daytona วางแผนขยาย agent runtime ไป edge + consumer device + identity plane. Cloudflare, Fly.io, Replit น่าจะ pivot เข้า agent runtime positioning ภายในปีนี้แน่
- **Enterprise MCP แยกเป็น 2 tier แน่** — open MCP (DIY, limited context) vs enterprise MCP ที่มี auto-captured context + 46 pre-defined tool + SLA (Quantum Metric, Neural Concept). ปี 2027 "MCP server catalog" จะเป็น SaaS tier เหมือนที่ Zapier/Workato เป็น integration tier เมื่อ 10 ปีก่อน. Zapier, Workato, Tray.ai, n8n ต้อง rebrand เป็น "MCP platform" ภายใน 6 เดือน
- **Vertical MCP คือ gold rush ถัดไป** — Neural Concept wrap CAD/CAE stack ที่ incumbent 20+ ปี ขายต่อเป็น MCP integration vendor. ตลาดที่เปิดเหมือนกัน: medical imaging (DICOM+PACS), legal (iManage+Relativity+Westlaw), finance (Bloomberg+FactSet+MATLAB), biotech (Benchling+Schrodinger). ใครมี domain expertise + ความสัมพันธ์กับ incumbent vendor + ความเร็ว ชนะ
- **Agent-to-agent (A2A) ระดับ team คือ next frontier หลัง individual AI assistant** — Town $1B valuation หลัง launch 4 เดือน = VC เชื่อว่า individual assistant market ลงสู่ความอิ่มตัว. design question ที่สำคัญคือ "identity + authorization graph" ที่กำหนดว่า agent ไหนคุยกับ agent ไหนได้. Google Agent Identity + Okta + Microsoft Entra = ชั้น identity กำลัง consolidate. SaaS incumbent (Slack, Teams, Notion, Linear) ต้องเลือกว่าจะ build native, acquire, หรือ cede team-level AI workflow
