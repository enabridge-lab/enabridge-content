# Instinct ระดม $250M Series B ที่ $2.5B valuation — consumer AI agent ผ่าน SMS + voice, ex-Sierra founder อายุ 23 ปี, 50× ใน 4 เดือน

## TL;DR
- **Instinct** (บริษัทแม่ Spear Street Technology) ปิด **$250M Series B ที่ valuation $2.5B** เมื่อ 26 ส.ค. 2026 — **Index Ventures + Benchmark** co-lead, รวม funding ทั้งหมด $350M
- Founder **Noah Shinn อายุ 23** อดีตวิศวกร Sierra (customer service AI) ก่อตั้งบริษัท 2025; product เป็น consumer-facing personal agent ที่ interface ผ่าน **SMS + voice call** ไม่ใช่ chat interface
- Valuation trajectory ที่ผิดปกติ: **$50M (พ.ค.) → $500M (ต้น ส.ค. Series A นำโดย Kleiner Perkins) → $2.5B (ปลาย ส.ค. Series B)** — 50× ใน 4 เดือน; ยังอยู่ใน private testing phase
- Signal: **consumer AI agent segment ร้อนแรงจริง** — pattern distribution ผ่าน channel ที่ user มีอยู่แล้ว (SMS, phone) แทน chat app ใหม่ = ทางเลี่ยง cold-start problem

## เกิดอะไรขึ้น

Instinct ปิดรอบ $250M Series B ที่ valuation $2.5B โดยมี Index Ventures + Benchmark เป็น co-lead, รวมกับ Series A $75M ที่ Kleiner Perkins นำเมื่อต้น ส.ค. valuation $500M และ seed $25M ที่ Conviction Partners + Greenoaks นำเมื่อ พ.ค. valuation $50M — รวม funding ทั้งหมด $350M ในเวลาไม่ถึง 4 เดือน. เทียบกับ Series A → Series B step-up ปกติของ AI startup ทั่วไป (2-3×) — Instinct ที่ 5× ในเดือนเดียวเป็นสัญญาณว่า Benchmark + Index มองเห็นบางอย่างที่ตลาดยังไม่เห็น.

**Founder Noah Shinn อายุ 23** เป็น ex-Sierra engineer (บริษัท customer service agent ที่ Bret Taylor ร่วมก่อตั้ง ที่รอบล่าสุด rumor $10B) ที่ออกมาก่อตั้ง Spear Street Technology ปี 2025. Product ของ Instinct คือ **personal agent ที่ user ต่อกับ apps + devices ของตัวเอง (calendar, email, banking app, food delivery) แล้ว interact ผ่าน texts + phone calls** — ไม่มี chat interface. User ส่ง SMS "book me a flight to Bangkok next Tuesday under $500" หรือโทรหา agent เพื่อ reschedule นัดหมาย, agent ทำงานให้เสร็จแล้ว report กลับใน channel เดียวกัน.

Product ยัง **private testing** — ยังไม่ open ให้ user ทั่วไป, มี waitlist ที่ TechCrunch รายงานว่ามี viral moment ใน late ส.ค. หลังจาก Casey Neistat โพสต์ demo. Shinn ให้สัมภาษณ์กับ TechCrunch ว่า "การ interface ผ่าน SMS + voice ทำให้ user ไม่ต้องเรียนรู้ app ใหม่ — agent adapts to your existing communication habits". ทีมยังเล็กมาก (< 30 คน) และวางแผน scale infrastructure ก่อน public launch Q4 2026.

## ทำไมสำคัญ

**การเลือก distribution channel ผ่าน SMS + voice call แทน chat app** เป็น strategic bet ที่ไม่ธรรมดา. Chatbot ยุค 2023-2025 ล้วนล้มเหลวเพราะ **cold-start problem** — user ต้อง download app ใหม่, learn UX ใหม่, สร้างนิสัยเปิดใหม่. ChatGPT app ทำได้เพราะ novelty ของ GPT-4 ตอนเปิด; แต่ agent product รุ่นหลังต้อง compete กับ mental space ที่เต็มแล้ว. Instinct เดินอ้อม — SMS/voice = interface ที่ user โต้ตอบมาตั้งแต่เกิด, ไม่ต้อง onboarding, retention เกิดจาก habit ที่มีอยู่. Pattern นี้ echo Perplexity Comet browser หรือ Amazon Alexa+ ที่ตัดสินใจ integrate เข้ากับ surface ที่ user ใช้อยู่แทนสร้างใหม่.

Valuation trajectory ที่ **50× ใน 4 เดือน** ต้องอ่านสองมุม: **มุมที่หนึ่ง (Benchmark POV)** — Bill Gurley + Peter Fenton เห็น engagement metric ที่ waitlist สูงมาก, retention คุณภาพ (SMS/voice ไม่ค่อยมี fake engagement) และ CAC ต่ำจน unit economics ทำ Sequoia scared money. **มุมที่สอง (skeptical POV)** — private testing product ที่ valuation $2.5B โดยไม่มี revenue disclosed = **AI-native consumer agent bubble** ที่คล้าย Character.ai ปี 2023 (valuation $1B โดยไม่มี revenue) ที่จบด้วยการโดน Google acquihire ราคา discount. VC top-tier ยอมเสี่ยงเพราะเชื่อว่า winner-take-most category เดียวที่มี moat = brand + habit lock-in, มาก่อนชนะทุกอย่าง.

pattern ที่กว้างกว่า: **consumer AI agent = category ที่ค้นหา business model ยัง** — Instinct, Manus, Cognosys, Ohm.ai ทุกตัวยังไม่ตัดสินใจว่าจะเก็บเงิน user (subscription $20-40/mo), เก็บจาก merchant (booking commission, ad on completed action), หรือทั้งคู่. ในไทย pattern ที่คู่ขนาน: LINE MAN ที่วางตัวเป็น super-app ผ่าน chat platform หลัก — potential moat หากเพิ่ม agentic layer ที่ทำงานให้ user โดยไม่ต้องกดปุ่ม.

## มุม AI Agent Platform

**Builders** — ถ้าคุณสร้าง consumer agent, ทบทวน distribution — Instinct pattern บอกว่า **channel ที่ user มีอยู่ (SMS, voice, LINE, WhatsApp, Facebook Messenger) beats sink cost app ใหม่**. Twilio + Vapi + LiveKit ที่ provide SMS/voice infrastructure จะเห็น traffic โต 3-5× ใน 12 เดือน — เริ่ม integrate ตั้งแต่วันนี้ ก่อน pricing pressure จาก demand surge.

**Users / Business** — ถ้าคุณเป็น consumer brand (retail, F&B, travel, financial services) ที่มี user base ในไทย — เตรียม **agent-callable API** พร้อม auth flow ที่รองรับ agent-mediated transaction ภายใน 12 เดือน. ถ้าเมื่อ user โทรบอก Instinct ให้จอง flight โดย agent ต้องเลือกระหว่าง Bangkok Airways vs Air Asia — API ที่ dev-friendly + agent-verified checkout จะได้ default choice; API ที่ต้อง scrape web + human intervention จะถูกข้าม.

**Ecosystem** — สำหรับ Big Tech (Apple Intelligence, Google Assistant, Amazon Alexa+): consumer agent segment ที่ startup วิ่งเร็วกว่า incumbent เป็นครั้งแรกในรอบ 10 ปี — Apple ที่มี Messages + phone number identity ควรเปิด SDK ให้ third-party agent access อย่างเปิดกว้าง หรือปล่อยให้ Instinct/Manus/etc ยึด habit ก่อน. สำหรับ telco (AIS/True/DTAC): Rich Communication Service (RCS) + voice AI = new revenue lane; ถ้าไม่เปิด API ให้ agent ecosystem จะโดน bypass เหมือน SMS โดน WhatsApp เมื่อ 12 ปีก่อน.
