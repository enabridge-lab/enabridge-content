## 🧠 สรุป 3 บรรทัดก่อนเริ่มงาน

1. **Enterprise agent platform กำลังชี้ชัดว่าชั้น "control plane + identity + policy" ขายได้ ไม่ใช่แค่ model** — Google ขาย Agent Gateway + SPIFFE ID, Microsoft ขาย Hooks + Managed Runtime, Workday ขาย Agent Harness + Flex Credits. ค่ายไหนไม่มี 3 ชิ้นนี้ภายใน 6 เดือน จะไม่ผ่าน enterprise procurement
2. **Agentic commerce ได้ standard แรกแล้ว** — Amex Intent Intelligence + EMVCo + x402 Foundation; shopping/commerce agent builder ควร integrate Create Intent API ก่อน Q4 จบเพื่อเป็น early adopter; e-commerce merchant ต้องเตรียม validate Intent Token
3. **Enterprise SaaS เลือก "ขาย data gravity + consumption" แทน "ขาย interface + seat"** — Workday Sana ยอมไปอยู่ใน Claude/Gemini/Copilot เพื่อให้ data ถูกเรียกใช้ถี่ขึ้น, Flex Credits เป็น pricing ใหม่. Enabridge ควรทบทวน pricing model ว่า per-seat หรือ per-task
