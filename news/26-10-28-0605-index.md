## 📑 Table of contents

### 01 — OpenAI Dots เปิดราคา $500/เดือน — consumer AI product ตัวแรกที่กล้าตั้งราคาระดับนี้
**[26-10-28-0605-01-openai-dots-500-tier-always-on-agent.md](./26-10-28-0605-01-openai-dots-500-tier-always-on-agent.md)**
OpenAI เปิด **Dots** เป็นผลิตภัณฑ์ always-on agent ที่รันในคลาวด์ VM, เก็บงานข้าม conversation ได้ — pricing structure Pro 100/200/500 ($100/$200/$500 ต่อเดือน) ทุก tier ได้ dot หนึ่งตัว, ชั้น $500 ปลดล็อก Astra Ultra + headroom สูงสุด. **$500/เดือนคือ floor ที่ consumer AI product ไม่เคยกล้าแตะ** — ก่อนหน้าเพดาน consumer อยู่ $200. Rollout ไม่รวม UK/EEA/Switzerland (EU AI Act). Scaling signal: OpenAI รายงานที่ Aug 14 investor meeting ว่า enterprise revenue overtake consumer ครั้งแรก, run rate $40B+ annualized, business customer **+32% ก.ค.** เดือนเดียว, agent features **20M WAU** (Aug 19), overall **+35% QTD / enterprise +50%**. Signal: price anchor consumer AI reset, enterprise shift structural, non-human worker SaaS กำลังก่อ

### 02 — Vercel Drives GA — persistent storage ของ agent sandbox เริ่มเป็น primitive มาตรฐาน
**[26-10-28-0605-02-vercel-drives-ga-ship-2026.md](./26-10-28-0605-02-vercel-drives-ga-ship-2026.md)**
15 ต.ค. ที่ Ship 2026 San Francisco, Vercel ประกาศ **Drives GA** — persistent storage layer ที่ mount เข้า Vercel Sandbox แล้วอยู่หลัง sandbox stop. Default 1 TiB (Hobby 1 GiB), scale ถึง 16 TiB. **Forking also GA** (fork drive = snapshot ปัจจุบันเป็น child, ไม่ merge back) — pattern ใหม่สำหรับ "agent branching". **Vercel Daemons เข้า public beta** = long-running background worker (shift จาก serverless pattern ที่ Vercel เคยปฏิเสธ). **Enterprise-Managed Authorization** ผ่าน Vercel Connect public beta. Vercel ประกาศคู่ว่า **Meta Superintelligence Labs** รัน Vercel และ enterprise AI Gateway token use **โต 4× ใน 3 เดือน**. Signal: agent primitive stack กำลัง layer จริง, Vercel ขยับจาก frontend ไป end-to-end agent platform

### 03 — SailPoint Navigate 2026 — identity-first governance ของ "non-human workforce" เริ่ม GA
**[26-10-28-0605-03-sailpoint-agentic-fabric-navigate-2026.md](./26-10-28-0605-03-sailpoint-agentic-fabric-navigate-2026.md)**
6 ต.ค. Austin, SailPoint เปิด Navigate 2026 ด้วย keynote ที่ **79% ของ enterprise รัน agent in production** แต่ **เพียง 2%** มี identity tool purpose-built สำหรับ agent. Product line ใหม่ชื่อ **Agentic Fabric** 4 ชั้น: (1) discovery scan endpoint + browser + SIEM/XDR + vault หา shadow agent, (2) autonomous agent 3 ประเภท (enforce policy / adjust privilege / protect system), (3) **A-ISPM** = Autonomous Identity Security Posture Management, (4) **conditional JIT provisioning** default zero-standing-privilege ครอบ human + service account + agent. บวก kill switch สำหรับ rogue agent + IdentityIQ 9.0 สำหรับ on-prem. Signal: IGA framework เดิมหมดอายุ (identity ที่ behavior random ตาม prompt), ตลาด non-human HR category ใหม่กำลังก่อ — SailPoint ยืน 60% ของ stack, ช่องว่างคือ performance eval + cost allocation + termination orchestration

### 04 — Google เปิด "Universal Gemini for Work" — agent หนึ่งตัว ครอบ Workspace + Microsoft + Salesforce + Snowflake
**[26-10-28-0605-04-google-universal-gemini-work.md](./26-10-28-0605-04-google-universal-gemini-work.md)**
8 ต.ค. Gemini at Work 2026, Google ประกาศ Universal Gemini agent — productized agent ที่ enterprise เรียกจาก prompt box เดียว ทำได้ทั้ง Q&A, content, coding, workflow. **Private preview**. Cross-app day one: Workspace + Slack + Microsoft 365 + Salesforce + ServiceNow + Snowflake + BigQuery. Early customer: **Shopify, PayPal, On** (Constellation). Governance bundle: agent ได้ identity, activity log, access boundary, และ **hard spending cap per project** (first ของ enterprise agent product). Vertical bundle: financial services + legal preview; government + healthcare + retail next. Underneath = **Google Agent Compute Engine** (brief 23 ต.ค.). Signal: Google position "universal agent" ขัด Microsoft "many Copilots" กับ Salesforce vertical; hard spending cap จะกลายเป็น table-stake ภายในไตรมาส; Slack + Microsoft 365 integration = decoupling agent intelligence จาก productivity suite

### 05 — $5.7B ไหลเข้า agent startup ใน 3 สัปดาห์ — median $15.5M, pattern 4 ชั้น
**[26-10-28-0605-05-agent-funding-wave-october-2026.md](./26-10-28-0605-05-agent-funding-wave-october-2026.md)**
AI funding tracker: 1-21 ต.ค. 2026 มี 59 รอบ รวม $25.7B — $20B+ จาก OpenAI tranche; **ex-OpenAI = $5.68B / 58 รอบ, median $15.5M** (สูงกว่า 2024 Q4 ~2×). รอบเด่นใหม่: **Hone $60M seed** (agent "own business goals หลายเดือน"), **Vitalize $31M Series A** (nurse scheduling), **Mistlabs/Ambi $26M pre-Series A** (ambient agent cross-device), **TrueFoundry $19M Series A** (agent/LLMOps gateway), **Ghost AI $11M** (agent hardware).
