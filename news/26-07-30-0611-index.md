## 🎯 Signal ที่ต้อง action

**สำหรับ builders:**
- **เพิ่ม 3 capability ก่อนที่ regulator จะเรียกร้อง** — (1) capability declaration (agent enumerate tool + network scope + autonomy), (2) kill switch พร้อม audit trail (external control plane terminate ได้ทันที), (3) recursive capability limit (ห้าม spawn agent ที่มี capability สูงกว่าตัวเองโดยไม่มี human authorization)
- **เพิ่ม outcome-tracking layer** — clear definition of resolution, pricing engine ที่คิดเงินเฉพาะ successful outcome, cost model transparent per unit
- **Design agent architecture ให้ token-efficient ตั้งแต่ v1** — cache aggressive, escalate model tier ก่อน escalate token, instrument accounting per action; assumption ว่า inference จะ cheap ต่อไปในปี 2027 จะไม่จริง
- **Framework choice** — Vercel AI SDK ที่มี cost tracker, LangGraph 1.x ที่ support checkpoint + node-level budget + capability declaration จะได้ enterprise adoption มากกว่า framework ที่ไม่มี

**สำหรับ enterprise:**
- **Audit ตัวเองใน 60 วัน** — มี kill switch ที่ business owner (ไม่ใช่ vendor) กดได้ไหม, log agent action retention ไหน, มี approval process ก่อน agent ได้ capability ใหม่ไหม
- **RFP Q3-Q4 ต้องมี 3 clause ใหม่** — (1) outcome pricing option (rate + volume + no-charge on handoff), (2) containment rate SLA (Salesforce baseline 70%), (3) escalation cost cap
- **Lock inference contract ตอนนี้ก่อน spot price ขึ้น 2027** — Anthropic/OpenAI/Google มี volume commitment + reserved capacity discount 20-40% vs on-demand
- **Governance posture certification** — เพิ่มคำถามเกี่ยวกับ pacing / capability declaration / evaluation transparency ใน vendor evaluation ก่อนที่จะกลายเป็น mandatory

**สำหรับ investor / ecosystem:**
- **ผู้ชนะ compute round** — AMD (frontier customer จริง — MI450 pipeline unlocked), SK Hynix (HBM4 lock — stock re-rate), Anthropic (compute + capital + optionality); ผู้แพ้ — Meta ($145B capex ยังไม่พอ), Oracle (OCI ยังไม่มี frontier customer lock), small model providers (mistral, ai21)
- **Salesforce outcome pricing = new competitive floor** — Zendesk, Intercom, Freshworks, ServiceNow ต้อง match ใน 12 เดือน; startup ที่ขาย autonomous agent under $10M ARR without pricing flexibility จะเจอ headwind
- **Regional angle Thailand + SEA** — window เปิดสำหรับ (1) True IDC/INET/TCC partner กับ AMD/Nvidia/SK เรื่อง regional inference hub, (2) SI (Cognizant Thailand, Accenture SEA, Bluebik, G-Able) ขาย outcome-based implementation service ให้ K-Bank/SCB/AIS/PTT/CPALL, (3) Thai regulator (BOT, SEC, OIC, MOPH) align regulatory framework กับ US pacing framework — ก่อน Salesforce Agentforce เข้าตลาดจริง Q1 2027
- **AI governance / observability layer** = category ที่จะโตเร็วที่สุด Q4 2026 - Q2 2027 — Netzilo, Alterion Draco, Anthropic's Clio-style monitoring จะได้ premium multiple
