# Clay ปิด $115M Series D ที่ $7.1B — เขียน narrative ใหม่ว่า "GTM Engineer + Growth Agent" คือ category ต่อไป, valuation คูณสองใน 12 เดือน

## TL;DR
- Clay ประกาศ **Series D $115M** เมื่อวันที่ 9 ก.ย. นำโดย **Wellington Management** ที่ valuation **$7.1B** — เพิ่มขึ้นกว่าเท่าตัวจาก $3.1B (ส.ค. 2025) ในเวลา 12 เดือน
- ใช้เงินสร้าง category ใหม่ที่เรียกว่า **"GTM Engineer + Growth Agent"** — agent ที่ merge company data + external signal เพื่อหาลูกค้า / วัด intent / รัน personalized campaign อัตโนมัติ
- Customer base **17,000 ราย** ครอบ **80% ของ Forbes AI 50** — Anthropic, Google, OpenAI, Stripe, ElevenLabs, Workday, Siemens; syndicate ยักษ์ Sequoia + a16z + StepStone + Meritech + DST + CapitalG ตามเข้ามา
- $1M scholarship fund ฝึก GTM engineer ใหม่ — pitch ชัดว่านี่ไม่ใช่ tool แต่คือ **profession + role** ใหม่ที่ Clay กำลังเปิดตลาด

## เกิดอะไรขึ้น

วันอังคาร 9 ก.ย. — Clay ปิด **Series D $115M** ที่ valuation **$7.1 พันล้าน**. Wellington Management (public equity investor ระดับ mainstream — ไม่ใช่ venture) นั่งเป็น lead. Sequoia, Andreessen Horowitz Perennial (สาย growth ของ a16z), Meritech, DST Global, CapitalG, StepStone, BoxGroup, Boldstart, Bloomberg Beta, Evolution ตามเข้ามาทั้งขบวน. ราคานี้เพิ่มขึ้นกว่าเท่าตัวจาก $3.1B ที่ Clay ปิด Series C $100M เมื่อสิงหาคม 2025 — คูณสองใน **12 เดือน**

ตัวเลขที่น่าสังเกตกว่า valuation คือ **customer count**. Clay อ้างว่ามีลูกค้า **17,000 ราย** และ **80% ของ Forbes AI 50 ใช้ Clay อยู่** — รายชื่อลูกค้าที่ประกาศต่อสาธารณะรอบนี้ ได้แก่ **Anthropic, Google, OpenAI, Stripe, ElevenLabs, Workday, Siemens**. ถ้าอ่านลูกค้ารายชื่อนี้จะเห็นว่าเป็น AI vendor ระดับ frontier + enterprise SaaS ที่มี GTM team ระดับพันคน — แปลว่า Clay ไม่ได้ขาย SMB tier อย่างเดียว แต่ upsell เข้า enterprise motion ได้แล้ว

จุดที่ Clay pitch แตกต่างจากคู่แข่งใน SDR/BDR automation space (Apollo, Outreach, ZoomInfo, 6sense) คือ **framing**. Clay ไม่เรียกตัวเองว่า "sales tool" หรือ "revenue platform" — เรียกตัวเองว่า **AI Growth Engine** และประกาศว่าลูกค้ากำลังจ้าง role ใหม่ที่เรียกว่า **"GTM Engineer"**. GTM Engineer นี้เป็นคนที่ใช้ Clay orchestrate agent หลายตัว — agent ตัวหนึ่งดึง firmographic + technographic signal, ตัวหนึ่ง monitor intent (job change, funding, tech stack change), ตัวหนึ่ง compose + personalize outbound campaign. ทั้งหมด compound เข้ากันจน CEO Clay (Kareem Amin) เรียกมันว่า "GTM system that improves with use"

พร้อมการ raise Clay เปิดตัว **$1M GTME Scholarship** — training program สำหรับ GTM Engineer ใหม่ ที่ Clay จะสอน + certify ทีมงานลูกค้าให้ใช้ platform ระดับ orchestrator. คำนี้ (**GTME = GTM Engineer**) ถูก Clay จดชื่อและใช้เป็น marketing anchor ในทุก press release + community channel — เป็น play เดียวกับที่ Salesforce ทำกับคำว่า "Admin/Trailblazer" หรือ HubSpot กับคำว่า "Growth Hacker": **สร้าง profession แล้ว lock category naming ก่อน**

Wellington เป็น lead investor ที่น่าสนใจเป็นพิเศษ — ปกติ Wellington เข้า late-stage private ก่อน IPO เท่านั้น (Databricks, Stripe, SpaceX). การที่ Wellington นำ round นี้เป็น signal ว่า Clay น่าจะ file S-1 ภายใน 12-18 เดือน หรืออย่างน้อยก็อยู่ใน pre-IPO position ที่ shape narrative ต่อ public market ได้แล้ว

## ทำไมสำคัญ

Pattern ที่เห็นในหนึ่งเดือน — Cognition $2B ที่ $48B (Devin สำหรับ coding agent), Clay $115M ที่ $7.1B (GTM growth agent), Sierra $10B ต้นปี (CX agent), Harvey $5B (legal agent) — คือการที่ **vertical agent platform ทำ valuation แซง horizontal AI infra vendor** ที่ทำมาก่อน. Snowflake ใช้ 5 ปีเดินทางจาก $10B → $70B; Clay/Cognition/Sierra กำลังบีบ curve นั้นเป็น 18 เดือน. Vertical agent = SaaS margin + AI leverage + workflow lock-in ที่ generic model API ไม่มี — public equity investor เห็นแล้วว่านี่คือ **next-generation SaaS ที่ replace incumbent playbook**

ที่คมกว่านั้นคือ **framing ของ "engineer" instead of "operator"**. Clay ไม่ pitch ว่า user คือ marketer หรือ sales — pitch ว่าคือ **engineer ที่เขียน workflow**. เมื่อคู่แข่งเก่า (Apollo, Outreach, 6sense) ยัง frame ว่าเป็น "sales productivity tool" ที่ marketer/rep ใช้ — Clay สร้าง persona ใหม่ที่ทำให้ software มี technical ownership + orchestration budget. นี่ตรง playbook เดียวกับที่ Datadog ใช้ตอน "SRE culture" กลายเป็น standard: **สร้าง role ก่อน, tool follows role, budget follows tool**

signal ที่สำคัญที่สุดสำหรับ observer ในตลาด Thai/APAC คือ **Clay ปฏิเสธ Salesforce/HubSpot integration paradigm เดิม**. Clay ไม่ใช่ plug-in ของ CRM — ทำงานเป็น orchestration layer ที่ **CRM เป็น downstream sink** ตัวหนึ่ง. เมื่อ agent ที่ผลิต pipeline สามารถอยู่เหนือ CRM ได้แล้ว "system of record" กำลังกลายเป็น "system of storage" — และ **primary control point ย้ายไปที่ orchestration layer**. Salesforce ที่กำลังพยายามซื้อ Listen Labs $2B (ดู brief ถัดไป) ก็รู้เรื่องนี้ — เลยพยายามซื้อ voice research agent + integrate เข้า Agentforce เพื่อ **ยกระดับ CRM กลับขึ้นเป็น orchestrator เอง**

## มุม AI Agent Platform

**สำหรับ Builders** ที่กำลังสร้าง agent framework/orchestration/runtime: Clay เป็นตัวอย่างว่า **"agent platform for a job function"** valuation แซง generic framework (LangChain, CrewAI ก็ยังไม่ถึง $2B). สังเกต 3 องค์ประกอบที่ Clay ทำได้: (1) **data moat** — third-party data source (Apollo, LinkedIn, ZoomInfo) ที่ enrich ให้; (2) **workflow template + community** — Clay Community มี GTM playbook นับพัน; (3) **naming ownership** — "GTM Engineer" กลายเป็น title ในทุกที่. builder ที่พยายามสร้าง horizontal agent platform ควรถามตัวเองว่า vertical ไหนที่ยังไม่มี "engineer" title — legal ops engineer? finance ops engineer? HR ops engineer?

**สำหรับ Users / Business** ที่กำลัง deploy agent ใน sales/marketing workflow: อย่ารอให้ ChatGPT + Salesforce integrate แล้ว "AI จะเก่งเอง" — Clay pattern แสดงว่า role change ต้องมาก่อน tool. บริษัทที่ hire GTM Engineer ใหม่ 1-2 คน + จ่าย $2-5K/เดือน สำหรับ Clay จะไล่ทัน enterprise ที่ยังใช้ SDR 20 คน + Salesforce/Outreach $10K/month ได้ในไตรมาสเดียว. **SME/startup ไทย** ที่มี founder ทำ GTM เองอยู่แล้วมี advantage ตรงนี้ — Clay เข้ามาไทยยัง soft; ผู้ที่เข้าใจ workflow orchestration ก่อนจะ leverage AI leverage ได้ก่อน

**สำหรับ Ecosystem** (vendor / cloud / platform): CRM incumbent (Salesforce, HubSpot) กำลังโดน orchestration layer กัด — reaction คือซื้อ vertical agent (Salesforce → Listen Labs, HubSpot → Breeze) แล้ว rebrand เป็น native. คำถามคือ Clay จะยอมโดนซื้อไหม — Wellington-led round + narrative "engineer profession" + $48B ceiling ของ Cognition = **บอกว่า Clay ตั้งใจไป IPO ไม่ใช่ exit ให้ Salesforce**. ถ้าจริง Salesforce ต้องหา acquisition อื่นเร็ว หรือไม่งั้น Agentforce จะเสียเสียง GTM narrative ให้ Clay ในตลาด SMB + mid-market ภายในปี
