## 🧠 สรุป 3 บรรทัดก่อนเริ่มงาน

1. **Agent packaging กำลัง shift จาก API token → seat subscription** — xAI Grok Bot ($120–300/mo bundled ใน Cursor tier) เป็น proof point ที่ใหญ่ที่สุด; CFO อนุมัติง่ายกว่า API budget, mid-market entry cost ลดลง 5–10×, distribution piggyback บน tool ที่ user มีอยู่แล้ว — Enabridge ควร price agent product ของตัวเองใน seat-based tier ทันที
2. **Orchestration layer กำลังกลายเป็น battleground** — Genesys Navigator + Orchestrator, ServiceNow Otto, Salesforce Agentforce, Broadcom Tanzu ประกาศพร้อมกันใน 4 สัปดาห์; Sierra (AI-native) ยอมเป็น partner ของ Genesys = AI-native agent จะกลายเป็น commodity building block, orchestration + context state เป็น value capture layer; buyer จะ commit ใน 6-12 เดือน หลังจากนั้น switching cost สูงมาก
3. **Agent security แตกเป็น 3 sub-layer อย่างชัดเจน** — design-time policy (existing), pre-execution authorization (JetStream Clearance category ใหม่), runtime detection (HiddenLayer/Lakera/Protect AI); enterprise ที่ scale จริงต้องซื้อทั้ง 3 layer เหมือน firewall/IDS/SIEM ยุคก่อน; Proofpoint SOC Analyst Agent เป็น proof ว่า enterprise regulated ยอมให้ agentic AI เข้าถึง sensitive data ถ้ามี human-in-the-loop กำกับชัด — model layer ของอุตสาหกรรม security จะรวมศูนย์ไป OpenAI Daybreak + Google Gemini Security + Microsoft Copilot Cyber
