### [03] — [Cloudflare ปล่อย Kitesurf — browser สำหรับ AI agent ที่รันบน Workers, กิน CPU/memory น้อยกว่า Chromium 3-7 เท่า, สร้างเสร็จใน 12 สัปดาห์](./26-08-10-0617-03-cloudflare-kitesurf-agent-first-browser-workers.md)
**Topic:** agentic-ai · **Read:** 4 นาที
6 ส.ค. Cloudflare launch **Kitesurf** — browser stateless รันบน **V8 isolates + Workers**, ตัด UI/tab/extension/session ทิ้ง เหลือ minimal engine ที่ทำ DOM parse + JS exec + fetch + screenshot + HTML extract; **CPU + memory น้อยกว่า Chromium 3-7 เท่า** สำหรับ agent workload; agent ที่ **10K page/day** จาก **$400-800/month (Chromium 16 vCPU + 32 GB)** เหลือ **$60-150/month (Kitesurf 2-4 vCPU + 4-8 GB)** = cost drop **75-85%**; ฟรี beta ผ่าน Browser Run; สร้างเสร็จใน **12 สัปดาห์** (vs Perplexity Comet 9 เดือน, Anchor Browser 14 เดือน, Brave 2 ปี) — ไม่ fork Chromium, build บน V8 + Workers ที่มีอยู่แล้ว
→ signal: **browser primitive สำหรับ agent unbundled** — เทียบ Browserbase ($40M+ ARR), Anchor Browser, Perplexity Comet; Cloudflare **play ครบ agent stack** (Workers AI + Agent SDK + MCP marketplace + R2 + D1 + Durable Objects + Kitesurf) → คาดประกาศ **"Agent Cloud"** ใน Birthday Week (ก.ย.); Browserbase ต้อง cut price 30-50% + move up-stack ภายใน 30 วัน; **AWS + GCP** จะเปิด agent-first browser service ใน re:Invent; **Enabridge** — Thai enterprise portal workflow (KBank + SCB + BOI + RD Online + DBD e-Filing) migrate ไป Kitesurf ลด cost 60-80%; benchmark 5 workflow ใน 14 วัน; เปิด "Web Agent" tier ราคาต่ำกว่า standard 40-50%; **value shift จาก provide infrastructure → compose + specialize**
