# Anthropic โยน $200B ปี 2028 ให้ IPO underwriter — ตัวเลขนี้ถ้าจริง = Cloudflare + Palantir + SpaceX รวมกัน; ถ้าพลาด = agent bubble แตก

## TL;DR
- **14 ส.ค. 2026 (Reuters)** — Anthropic บอก bankers ว่าคาด revenue **$190B–$200B ในปี 2028** เพื่อ underwrite IPO ที่ mimic valuation ระดับ **$2 trillion** — ใหญ่กว่า OpenAI, Meta, Nvidia (ตอน 2023) และเป็น IPO ที่ใหญ่ที่สุดในประวัติศาสตร์
- Anchor point คือ ARR ปัจจุบันประมาณ **$47B (พ.ค. 2026)** — จาก $1B (ธ.ค. 2024) ถึง $47B ใน 17 เดือน = **growth curve ที่ enterprise software ไม่เคยเห็นมาก่อน**; ต้องโต **4x จากตอนนี้ใน 2 ปี** เพื่อไปให้ถึง target
- Comp ที่ banker ใช้ = **Cloudflare, Palantir, SpaceX** — สาม name ที่ trade เป็น "AI infrastructure play" ไม่ใช่ pure LLM vendor สะท้อนว่าตลาดกำลัง reprice Anthropic เป็น **agent economy infrastructure** ไม่ใช่ chatbot vendor
- Agent SDK + Claude Code + Enterprise 3 product line กำลังโต 7x YoY กับลูกค้าที่จ่าย > $100K/ปี — ถ้าโตต่อได้อีก 2 ปี = ตัวเลข $200B ไม่ผิดสูตร แต่ downside case = **agent hype cycle correction** ก่อน Q1 2028

## เกิดอะไรขึ้น
วันที่ 14 สิงหาคม 2026 Reuters รายงานจาก 2 source ใน bank ว่า Anthropic ในช่วง 6 สัปดาห์ก่อน IPO analyst day (October) กำลังคุยกับ **Goldman Sachs, Morgan Stanley, และ JPMorgan** เรื่อง lead underwriter — และ number ที่ Anthropic ส่งให้ทีม banker ใช้ประเมิน valuation คือ **revenue $190B–$200B ในปี 2028** — ตัวเลขนี้ไม่เคยเปิดเผยที่ไหน จนถึงวันที่ Reuters ปล่อยข่าว

Anchor point เพื่อ valuate = ARR ปัจจุบันประมาณ $47B (ยืนยันโดย Dario Amodei ใน all-hands พ.ค. 2026) เทียบกับตอน December 2024 ที่ ARR อยู่แค่ $1B = โต **47x ใน 17 เดือน** ซึ่งเป็น growth curve ที่ **enterprise software ไม่เคยเห็นมาก่อน** — เทียบ Snowflake จาก $1B → $2.6B ใช้เวลา 2 ปี, Databricks จาก $1B → $3B ใช้ 3 ปี, Salesforce จาก $1B → $2.5B ใช้ 4 ปี

Bankers บอก Reuters ว่าใช้ **enterprise value-to-revenue multiple บน forecast 2 ปีข้างหน้า** ไม่ใช่ trailing revenue — เพราะ trailing model กับ growth rate แบบนี้จะ underprice บริษัทอย่างรุนแรง; ที่ notable คือ comparable ที่ banker หยิบมาใช้ไม่ใช่ SaaS company classic (Salesforce, Adobe, Workday) แต่เป็น **Cloudflare, Palantir, และ SpaceX** — สาม name ที่ trade เป็น "AI infrastructure play" หรือ "AI moonshot" ไม่ใช่ pure SaaS

Sacra คำนวณจาก mix ปัจจุบันว่า **Claude Code รัน $2.5B run-rate** ต้น 2026 และเป็น product ที่โตเร็วที่สุด (weekly retention เทียบ Cursor, GitHub Copilot สูงกว่า) — และ **Agent SDK** (ยัง private beta) มีลูกค้า commit ระดับ $10M+/ปี รวม 15+ ราย ที่ deploy multi-agent workflow ใน production ตัว **Claude for Enterprise** เข้า Fortune 500 กว่า 300 บริษัท, ARR จากลูกค้ากลุ่มนี้โต **169% YoY** — ลูกค้าที่จ่าย > $100K/ปี โต **7x** ในปีที่ผ่านมา

Amazon (via Bedrock, $8B invested), Google (via Vertex AI + $2B invested), และ Salesforce (via Agentforce partnership) เป็น 3 channel ที่ Anthropic ใช้ scale — ไม่ต้องขายตรง เอา partner ขาย = margin structure ต่างจาก OpenAI ที่ทำ direct API เป็นหลัก

## ทำไมสำคัญ
เรื่องนี้เป็น **first honest snapshot ของ AI economy math** ที่ตลาดกำลัง underwrite — ก่อนหน้านี้ number ทุกอย่าง (OpenAI $500B valuation, xAI $200B, Anthropic $170B) เป็น *last round mark* ที่ private investor พร้อมจ่าย แต่ตอนนี้เป็นครั้งแรกที่ **public market analyst** ต้องยอม attach cash flow forecast ให้ตัวเลขที่คนคำนวณจริง จะจับได้ว่า **AI infrastructure = commodity SaaS หรือ moonshot infra**

Pattern สำคัญ 3 อย่าง: หนึ่ง — **$200B revenue ใน 2028 = 40% ของ Microsoft ทั้งบริษัทวันนี้** และเทียบเท่ากับ Adobe + Salesforce + Oracle + Workday รวมกัน; ถ้า Anthropic ไปถึง = ตลาดยอมรับว่า agent economy คือ **layer ใหม่ที่ใหญ่ระดับ platform shift** ไม่ใช่แค่ productivity add-on สอง — **$2T IPO valuation** จะ set precedent ให้ OpenAI (IPO Q1 2027), xAI, และ Mistral ต้องอ้างอิง multiple ที่คล้ายกัน — เท่ากับ **agent AI จะ absorb capital ประมาณ $500B–$800B ต่อปี** จาก public + private market รวม สาม — **downside case น่ากลัวกว่า upside** ถ้า 4x growth 2 ปีทำไม่ได้ (โต 60% YoY แค่นี้ก็ยาก) = IPO จะ crash ที่ multiple compression และดึง valuation ทั้งวงการลง 50-70% ในไตรมาสเดียว

Signal ที่ตลาดจะเฝ้าดู 6 เดือนข้างหน้า: **Q3 2026 revenue print** ต้องแตะประมาณ $65B–$70B ARR (จาก $47B พ.ค. โต ~40% Q-on-Q) ถ้าโตช้ากว่า = banker จะ reprice ทันที และ IPO อาจถูก delay ไป 2027 — และ **Claude Code retention** ต้องคงที่เหนือ 70% weekly เพราะเป็น bellwether ว่า agent product คน stick กับ workflow จริง ไม่ใช่ trial burn

## มุม AI Agent Platform
**Builders** ที่สร้าง agent framework บน Claude: Anthropic กำลังยิง **Agent SDK** เป็น flagship + Claude Code เป็น product ตัวหลัก; ถ้าคุณ build บน API layer เดียว = ต้องพร้อมที่ Anthropic จะ move up-stack (bundle prompt cache, tool router, observability) และ competitor คุณอาจกลายเป็น native Anthropic feature ภายใน 12 เดือน ที่ปลอดภัยกว่า = **build on multi-provider abstraction layer** (LiteLLM, Portkey) หรือ **specialize deep vertical** (legal, healthcare, coding) ที่ Anthropic ยังไม่ vertical-ize

**Users / business** ที่ deploy Claude ใน production: การ commit ระยะยาว (2-3 ปี contract) กำลัง valued เป็น anchor customer ที่ Anthropic ใช้ pitch investor — negotiate discount ตอนนี้ก่อน IPO price lock. อีกด้าน CFO ต้อง scenario plan: ถ้า Anthropic IPO ไม่ผ่าน หรือ delay ปี ถึง 2 ปี = pricing อาจแพงขึ้น เพราะต้อง cover cost แทนที่ VC subsidy — plan multi-vendor exit strategy (Gemini, GPT, open-source Llama derivative) ก่อน renewal ปีหน้า

**Ecosystem**: คนได้ประโยชน์ = **agent infrastructure vendor** ที่ trade ตาม multiple ของ Anthropic — Cloudflare (agent hosting), MongoDB (vector), Datadog (observability), Snowflake (data plane) — จะเห็น multiple expand ล่วงหน้า IPO 3-6 เดือน ตามที่เกิดกับ private company รอบ ๆ Snowflake IPO ปี 2020 คนเสีย = **pure LLM API reseller** (small model host, cheap Llama frontend) ที่จะโดน squeeze margin เพราะ Anthropic + OpenAI ใช้ scale advantage lower prices ก่อน IPO เพื่อ take share
