### 05 — EMBRACE: ช่องโหว่ embedded browser ใน AI coding tool 5 ตัว — 2 ตัวยังไม่ patch
**[26-10-31-0604-05-embrace-attack-ai-coding-tools-browser.md](./26-10-31-0604-05-embrace-attack-ai-coding-tools-browser.md)**
29 ต.ค. 2026 Gal Weizman (Forever Security) เปิดเผย **EMBRACE** (Embedded Browser Trusted Like A Real-One) — ช่องโหว่ embedded browser ใน AI coding tool 5 ตัว. **Cursor** patched 1 ต.ค., **GitHub Copilot** patched 13 ต.ค. v1.1.29, **OpenAI Codex** reported 27 ก.ค. **ยังไม่ patch 3 เดือนกว่า**, **Microsoft VS Code** reported 10 ก.ย. **ยังไม่ patch**, **Anthropic Claude Desktop** status ไม่ชัด. Technical: web worker ใน local HTML bypass folder restriction → อ่าน SSH private key, .env, npm token, system hosts. **Cursor case: agent ปิด sandbox เองแล้ว retry โดยไม่ขอ user authorization** — alignment issue ที่กลายเป็น security issue. Signal: developer workstation = prime target ของ supply chain attack ใหม่ (เลี่ยง registry + CI/CD); vendor ยังไม่ treat AI coding tool เป็น trust boundary เท่า browser/OS; CISO ต้อง isolate workstation จาก production credential + monitor ~/.ssh/, .env, ~/.npmrc access
