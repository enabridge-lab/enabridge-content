## 🔗 ร่วมกันดู

**Pattern ของสัปดาห์นี้** — เจาะเฉพาะเลเยอร์ **runtime + storage + governance** รอบ agent ไม่ใช่ model ตัวเอง:

- **Database per agent** (Supabase+Turso) — storage ephemeral ต่อ task
- **Offensive agent swarm** (Armadin) — runtime ที่รัน exploit chain 24/7
- **Domain knowledge graph + agent** (Ironclad, Atlassian, Salesforce) — context layer ที่โยง entity relationship ของ domain
- **Agent hub + governance** (SAP) — ที่เดียวที่ discover / manage / govern agent ข้าม suite

ร่วมกันบอกว่า **ชั้นที่โตเร็วสุดใน 12 เดือนข้างหน้าไม่ใช่ foundation model, แต่คือ enabler ที่ทำให้ agent production-ready** — margin ของเลเยอร์นี้หนากว่า SaaS คลาสสิกเพราะมี switching cost + data moat + unit economics ที่ scale ตาม usage จริง

**ต่อยอดในไทย** — SI/ISV ไทยยัง focus ที่ "pilot copilot per role" มากกว่า "ขาย runtime + governance" ทำให้ pricing และ margin ยัง SaaS-era ลูกค้า enterprise ขนาดใหญ่ที่ใช้ S/4HANA, Salesforce, Microsoft Dynamics จะเริ่มถามเรื่องเหล่านี้ใน RFP ปี 2027 — ใครไม่มี answer อาจหลุด shortlist
