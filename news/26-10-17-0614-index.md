## 🧭 Signal สำหรับ builder

- **"ที่อยู่ของ agent" ชัดขึ้น** — Microsoft Copilot Studio, Cisco Webex, Kakao Kanana ทั้งหมด claim ว่า agent ควรรันที่ layer ของ productivity/collab/messenger ไม่ใช่ cloud sandbox. Framework vendor (CrewAI, LangGraph) ต้องตัดสินใจว่าจะ interop กับ identity + distribution channel เหล่านี้หรือเสีย enterprise segment.
- **Vertical incumbent สร้าง agent OS ของตัวเอง** — Honeywell ลงมา productize physical AI พร้อม pilot 6 แห่ง สัญญาณว่า vertical ที่ domain data หลักอยู่ที่ incumbent (building, factory, utility) จะยากที่ horizontal framework จะ compete ต้อง strategy เสียบใต้ (model + twin layer) ไม่ใช่ compete ตรง.
- **VC premium ให้ AI service firm** — RapidCanvas Series B $29M เพิ่ม data point ว่า "70% agent / 30% human" business model โดนใจ VC. Mid-market ซื้อ outcome ไม่ซื้อ framework. ถ้าทีมใครคิด bootstrap platform-only ไม่มี managed service — segment นี้จะยาก.
