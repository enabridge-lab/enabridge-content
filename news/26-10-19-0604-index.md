### 03 — OpenCode ยอมรับ breach — API key ของ OpenAI/Anthropic/Google หลุดจาก legacy system
**[26-10-19-0604-03-opencode-distillation-breach.md](./26-10-19-0604-03-opencode-distillation-breach.md)**
17 ต.ค. OpenCode (open-source coding agent ของ Anomaly Innovations เดิม SST) disclose breach — กระทบ ~1.4% ของ Console user, exposed API key ของ **OpenAI, Anthropic, Google**. Entry point คือ **legacy system** ที่บริษัทวางแผนปลดระวางอยู่แล้ว. Framing เป็น "large-scale distillation attack" — pattern เดียวกับ 24,000 fraudulent accounts ที่ Anthropic report ก.พ. 2026 แค่ย้าย target จาก account signup มา dev tool. User บางคนรายงาน Anthropic charge ~$400 ที่ไม่คุ้นเคย (unverified). Defense perimeter ของ frontier model ไม่ใช่ API เอง — แต่คือ wallet ของ developer หลายล้านคนใน SaaS tool หลายสิบตัว ตัว weakest link ตัดสิน

### 04 — Anthropic ยอมแบ่ง 5% equity เข้า Public Benefit Fund — แต่ LLC, ไม่ใช่ nonprofit
**[26-10-19-0604-04-anthropic-public-benefit-fund-5-percent.md](./26-10-19-0604-04-anthropic-public-benefit-fund-5-percent.md)**
18 ต.ค. Bloomberg รายงาน Anthropic ประกาศแผน pledge 5% ของ shares เข้า Anthropic Public Benefit Fund ใหม่ — ยังต้อง stockholder approval. Structure: **LLC ที่ Anthropic owns 100%** (ไม่ใช่ nonprofit แยกตัวแบบ Patagonia). Scaling clause: board เพิ่มได้อีก **2% ทุกครั้ง valuation ขึ้น 50% เหนือ threshold**. Scope: outside giving — donation ก้อนใหญ่ + direct cash distribution ให้ population ที่โดน impact จาก AI (ตัวอย่าง $200M labor-market work). **No political lobbying**. ประเมิน 5% @ $2T IPO = $100B, ถ้า scaling trigger 3 รอบไปถึง 11% @ $8T = $880B — ใหญ่กว่า Harvard endowment 17 เท่า

## 🧭 สิ่งที่ควร pay attention ต่อ

1. **Agent mandate standard** — ตัวที่ MCP 2026-07-28 + A2A (ที่ Google โอนให้ Linux Foundation Agentic AI Foundation มิ.ย. 2025) ยังไม่มี คือ **signed user mandate** / cryptographic authority. ใครเสนอ spec ที่ law firm + agent framework ยอมรับร่วมกันก่อนจะได้ moat จริง
2. **Agent security consolidation** — Opsin + Reco + รุ่นต่อไป คาดว่าจะมี Series B $100M+ รอบใหม่ 2027 และ CrowdStrike/Palo Alto ซื้อตัวเล็ก consolidate category
3. **Dev tool identity hardening** — หลัง OpenCode breach ผู้เล่น frontier model (Anthropic/OpenAI/Google) น่าจะเร่ง publish "approved tools" program ที่มี security audit standard คล้าย PCI compliance ของ Stripe
4. **Pre-IPO frontier lab governance race** — Anthropic set bar 5% + scaling clause + no lobbying. OpenAI, Google DeepMind, xAI ต้องตอบ — ไม่ว่าจะด้วย similar pledge หรือ counter narrative
