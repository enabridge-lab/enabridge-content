## 🎯 ถ้ามีเวลา 5 นาทีเช้านี้ อ่านอะไรก่อน?

**อันดับ 1 (biggest sandbox lesson):** [01] Claude Code 48K files — เพราะเป็น **agentic failure ที่ root cause จับต้องได้** ในระดับ engineering bug, ไม่ใช่ AGI hype. Windows directory junction + `os.walk()` blind spot กลายเป็นบทเรียนที่ทุก orchestration framework ต้องเอาไป retro. ประเด็นเชิงกลยุทธ์: agent ได้ authority ให้ทำงานให้จบ ไม่ใช่ authority ให้เขียน implementation ไหนก็ได้ — vendor ที่ productize sandboxing edge case ทั้งชุด (Windows/macOS/Linux) จะมี moat จริง. ทีมที่ให้ agent เข้าถึง production repo อยู่แล้ว: (1) รัน agent ใน git worktree แยก, (2) snapshot ทุก 15 นาที, (3) scope write access เฉพาะ folder

**อันดับ 2 (biggest platform-shift signal):** [03] Salesforce AIforce — เพราะเป็น **ครั้งแรกที่ enterprise vendor อันดับ 1 พูดตรงว่า "UI is not our moat anymore"**. reason ไม่ใช่ vision เป็นตัวเลข user 60-70% ทำงานในหน้าต่าง chat ไม่กลับ Salesforce. 3 partner (Anthropic/Google/Slack in-house) + Koa เป็น model portability play ที่ enterprise ที่กลัว lock-in ยินดีจ่าย. คู่แข่ง Microsoft/ServiceNow/HubSpot ต้อง response ใน 6 เดือน; vendor SI ที่ขายเวลาเซตอัพ Salesforce แบบดั้งเดิม model กำลังหด

**อันดับ 3 (biggest infra premium signal):** [04] Temporal $550M — เพราะ **VC เทียบ agent infra กับ Snowflake/Databricks** อย่างชัด. 1.9 ล้านล้าน billable action, customer 4,300 คน โต 139% YoY, OpenAI/Snap/NVIDIA/JPMorgan อยู่ใน list. Durable execution กลายเป็น requirement สำหรับ agent 30 นาทีขึ้นไป — ไม่ใช่ optimization. ทีมที่ deploy agent workflow เกิน 5 นาทีต้องคิดเรื่องนี้ตั้งแต่วันแรก — $500-5,000/เดือน mid-scale ประหยัดกว่า debugging session ตอน agent crash กลางงาน

**อันดับ 4 (biggest commoditization signal):** [02] Google Antigravity API — เพราะ **Google ยอมรับว่าจะไม่สู้ Cursor/Cognition ที่ product layer** เลย pivot กลับ commodity API primitive. Credentials API + Files API + free tier ทำให้ vertical agent มี underlying runtime ถูกลง. Pattern: coding agent จะ commoditize ปีหน้า — value เลื่อนไปที่ IDE/UX (Cursor), domain expertise (Harvey/Sierra), และ governance stack. Vendor ที่ยังคิด "we build agents" เป็น moat ต้องเลื่อน positioning ภายใน 6 เดือน
