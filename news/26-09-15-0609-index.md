## 🎯 ถ้ามีเวลา 5 นาทีเช้านี้ อ่านอะไรก่อน?

**อันดับ 1 (vertical squeeze):** [01] Claude for FA + 12 connectors — pattern บอกชัดว่า frontier lab เดินขึ้นตรง vertical ที่ข้อมูลชัด. ถ้าคุณเป็น startup vertical AI ในไทย (fintech / legaltech / medtech) — reposition รอบ proprietary data ตอนนี้ ก่อน Anthropic/OpenAI เข้ามาแข่งด้วย suite ของตัวเอง

**อันดับ 2 (build/buy reset):** [02] Agents API — orchestration layer ที่ startup ครึ่งวงการขายอยู่ ตอนนี้ OpenAI แจกฟรี. เกม value เปลี่ยนไปที่ **domain logic + proprietary connector + trust boundary** ไม่ใช่ session/sandbox/context compaction. ถ้าคุณกำลังจะ buy agent platform — เจรจา no-lock-in ทั้ง model + orchestration + observability

**อันดับ 3 (economics unlock):** [03] Smaug + router pattern — ถ้า agent ของคุณ volume สูง (10M+ interaction/เดือน) ต้อง test open-weight ทันที. เลข 10–100× cost gap ทำให้ ROI POC ที่เคย fail เพราะ margin ผ่าน ROI test ใหม่. **CFO conversation** เปลี่ยนจาก "ทำได้แต่แพง" เป็น "ไม่ทำแพงกว่า"

**อันดับ 4 (security floor):** [04] Deadbugz + metadata poisoning — ทุกทีมที่ deploy agent + MCP ใน production ต้อง audit MCP endpoint ที่ต่ออยู่ + สร้าง sanitization layer สำหรับ tool description. **นี่ไม่ใช่ theoretical risk** — 23 PR ใน 74 นาที คือ scale ที่ attacker ทำได้ด้วย automation

## 🧠 สรุป 3 บรรทัดก่อนออกจากห้อง

1. **Stack ปี 2027 กำลังก่อรูป 4 ชั้นพร้อมกัน** — vertical suite (Claude for FA), hosted orchestration (Agents API), open-weight cost layer (Smaug), และ trust/security layer (MCP allowlist หลัง Deadbugz). สี่ชั้นนี้ไม่ใช่ trend แยก — เป็น requirement matrix ที่ enterprise procurement จะเช็คทุกช่องในสัปดาห์ต่อจากนี้

2. **Frontier lab อ้วนขึ้นในทั้งสองทิศทาง** — Anthropic/OpenAI push ขึ้น vertical (แข่ง startup ที่พึ่ง API เดิม) และดัน orchestration ลงไปฟรี (commoditize framework wrapper). Startup ที่รอดคือ (a) vertical ที่มี proprietary data + workflow depth ที่ frontier ไม่ negotiate ได้ง่าย, และ (b) infrastructure ที่ deploy บน customer infra (LangGraph, Mastra, Google ADK, on-prem)

3. **ตลาดไทยมี window ปีเดียว** — Smaug + open-weight ทำให้ SME/vertical agent ไทยพลิก unit economics ทันที; แต่ต้อง (i) มี security posture เรื่อง MCP audit ก่อน enterprise เซ็นสัญญา, (ii) เจรจา no-vendor-lock กับ model + orchestration ตั้งแต่ contract, (iii) ทีม data ต้อง cleanup schema/governance ก่อน AI team join. Enabridge บน bet นี้ — pack MCP allowlist + router + connector graph ให้เป็น first-class ใน platform ที่ขาย ASEAN 2027
