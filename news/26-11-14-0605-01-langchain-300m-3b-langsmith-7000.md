# LangChain พิมพ์ตัวเลขที่ agent tooling market รอมาทั้งปี — $300M, $3B valuation, LangSmith 7,000 องค์กร

## TL;DR
- LangChain ปิด Series C $300M ที่ valuation $3B — โตมากกว่าเท่าตัวจาก $1.25B ที่ IVP นำเมื่อปีก่อน
- CapitalG (Alphabet) นำรอบ, GIC + DFJ Growth เข้าใหม่, IVP + Sapphire ลงเพิ่ม — เป็นรอบที่บอกว่า "agent observability = infrastructure layer"
- LangSmith มี 7,000 องค์กร: NVIDIA, Toyota, Salesforce, Harvey, Rippling, LinkedIn, Workday, Bridgewater — จากตัวเลขนี้ LangChain อาจเป็น Datadog ของยุค agent

## เกิดอะไรขึ้น
วันที่ 13 พฤศจิกายน LangChain ประกาศ Series C มูลค่า $300 ล้าน valuation $3B นำโดย CapitalG ซึ่งเป็น growth fund ของ Alphabet ที่ลงรอบเก่ามาแล้ว เสริมด้วย GIC จากสิงคโปร์, DFJ Growth สองรายใหม่ และ IVP + Sapphire Ventures ที่เคยลงอยู่แล้วเติมเพิ่ม เทียบกับรอบก่อนหน้า $125M ที่ valuation $1.25B เมื่อตุลาคมปี 2025 — ตัวเลขใหม่คือ 2.4 เท่าในเวลา 13 เดือน และสำหรับ infrastructure startup ที่ขายให้ developer ไม่ใช่ consumer ถือว่าเป็น curve ที่หายาก

ตัวเลขที่ลึกกว่า valuation คือ customer count — LangChain เปิดเผยว่า LangSmith ซึ่งเป็นผลิตภัณฑ์ agent observability + evaluation ของบริษัท ปัจจุบันมี 7,000 องค์กรใช้งาน รายชื่อ customer ที่ release ออกมารวม NVIDIA, Toyota, Salesforce, Harvey, Rippling, LinkedIn, Workday และ Bridgewater — ทั้ง startup native AI และ Fortune 100 incumbent การที่ Salesforce อยู่ใน list น่าสนใจเป็นพิเศษเพราะ Salesforce เองก็ขาย Agentforce platform ที่แข่งใน layer ใกล้เคียง — Salesforce กำลังสร้าง agent ของตัวเองด้วย LangChain

ภาคที่ CapitalG และ GIC น่าจะดูคือ LangSmith revenue ไม่ใช่ open-source download — framework LangChain free ตั้งแต่ปี 2022 แต่ LangSmith เป็น paid product ที่ organization จ่ายต่อ seat ยัง ไม่เปิดเผยตัวเลข ARR แต่ 7,000 orgs ถ้าเฉลี่ย $20K-$50K/ปีจะอยู่ประมาณ $140M-$350M ARR ซึ่ง justify valuation $3B ที่ 10-20x multiple นี่คือ market anchor ที่นักลงทุน growth stage ใช้ปัจจุบัน ของบริษัท agent infrastructure

LangChain ประกาศด้วยว่าจะมี release event วันที่ 20 พฤศจิกายน เพื่อเปิดตัว LangSmith capabilities ใหม่ — ตีความกันว่าน่าจะเป็น agent runtime หรือ orchestration layer ที่ชาร์จต่อ run ไม่ใช่ต่อ seat — เพื่อ unlock pricing เพิ่มเติม

## ทำไมสำคัญ
เมื่อหนึ่งปีก่อนตลาดยังถกเถียงกันว่า LangChain เป็นแค่ developer library ที่จะโดน OpenAI / Anthropic กลืน หรือเป็น infrastructure ที่ยืนได้ด้วยตัวเอง รอบนี้ตอบคำถามนั้นชัดเจน — CapitalG และ GIC ไม่ได้ลง $300M ให้ open-source library รอบ Series C นี้เป็น vote ว่า agent observability + evaluation + orchestration คือ control plane ที่ทุก enterprise ต้องมี ไม่ว่าจะใช้ model ไหน vendor ไหน — เหมือน Datadog ของยุค microservice, Snowflake ของยุค data warehouse

เลข 7,000 orgs ของ LangSmith เทียบกับตัวเลข Salesforce Agentforce 185,000 users ที่ออกมาสัปดาห์ก่อน บอกอะไรต่างกัน — Agentforce นับ "คนที่ใช้ agent" ส่วน LangSmith นับ "องค์กรที่สร้าง agent" กลุ่มหลังเล็กกว่าแต่หนาแน่นกว่า ในทาง value capture แปลว่า LangChain เก็บ margin ของ infrastructure (สูง, sticky) ไม่ใช่ end-user seat (เปลี่ยน vendor ง่ายกว่า)

Caveat สำคัญ — ตัวเลข 7,000 เป็น self-reported ของ LangChain ไม่มี third-party audit และ "องค์กรใช้ LangSmith" รวม trial free tier หรือเฉพาะ paid เป็นคำถามที่ไม่ได้ตอบ CapitalG น่าจะเห็น ARR จริงก่อนลง แต่สาธารณะยังไม่รู้ อย่าเพิ่งเอาตัวเลขไปคำนวณ market share จนกว่าจะมี disclosure ชัด

## มุม AI Agent Platform
Builders — ถ้ากำลังสร้าง agent framework หรือ orchestration ของตัวเอง นี่คือสัญญาณที่ชัดว่า "observability + evaluation" ไม่ใช่ feature แต่เป็น standalone product ที่ลูกค้าจ่ายแยก เพราะฉะนั้นอย่า bundle เข้ากับ runtime ของตัวเอง ต้องมี integration point เปิดให้ LangSmith และคู่แข่ง (Braintrust, Arize, Humanloop) ลงได้ นอกจากนั้น release event วันที่ 20 ควรดูว่า LangChain เปิด runtime หรือ orchestration pricing แบบไหน เพราะจะเป็น anchor ของตลาด

Users/business — องค์กรที่ deploy agent ใน production ควรแยกชั้นให้ชัดระหว่าง model layer (OpenAI/Anthropic/Gemini), runtime layer (LangGraph, OpenAI Agents SDK, custom), และ control plane layer (LangSmith, Braintrust) — ชั้นที่สามเป็นชั้นที่มักถูกลืมใน POC แต่พอ scale production จะกลายเป็น bottleneck ลูกค้าไทยที่ Enabridge ดูแลควร benchmark ค่าใช้จ่ายของชั้น control plane กับขนาด agent fleet ของตัวเอง — เริ่มเล็กได้ แต่อย่า build เอง เพราะ LangSmith ที่ $20K-$50K/ปี ต่อ org ถูกกว่า dedicated team

Ecosystem — Alphabet (ผ่าน CapitalG) กำลังเก็บ position สองชั้น — Gemini ในชั้น model และ LangSmith ในชั้น observability หมายความว่า Google ไม่พยายามครอง agent framework ด้วยตัวเอง (เทียบกับ Microsoft ที่ปลูก Copilot Studio) แต่ไปถือหุ้นใน vendor-neutral tool แทน strategy นี้ถ้าเวิร์คจะทำให้ Google ได้ประโยชน์จากทุก agent ที่ enterprise สร้าง ไม่ว่าจะใช้ model ใคร
