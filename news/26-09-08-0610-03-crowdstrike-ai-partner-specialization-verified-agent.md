# CrowdStrike เปิด "AI Partner Specialization" — Verified Agent certification + Falcon Marketplace ตั้งเป็น "official channel" สำหรับ agent ที่ CISO จะ deploy

## TL;DR
- CrowdStrike เปิด **AI Partner Specialization** ภายใต้ Accelerate Partner Program (31 ส.ค. 2026) — new ecosystem model สำหรับ "securing the agentic enterprise"
- 4 partner pathway: **Resell (Falcon Flex) / Manage (managed services) / Build (Charlotte AI AgentWorks + Falcon Foundry) / Verified Agent certification**
- **Verified Agent** เป็นตราที่ CrowdStrike stamp บน third-party agent — ตัด bespoke evaluation process ของ CISO ทุกครั้ง; distribute ผ่าน **Falcon Marketplace**
- คู่ Broadcom AgentMinder + Tenable CyberAgents Exchange + OpenAI cyber ecosystem = สัปดาห์เดียว **agent governance category กลายเป็น table stakes ของ enterprise procurement**

## เกิดอะไรขึ้น

เช้าวันที่ 31 ส.ค. CrowdStrike ประกาศ **AI Partner Specialization** เป็น extension ของ Accelerate Partner Program ที่ปูมาตั้งแต่ปี 2024. Framing ที่ George Kurtz (CEO) ใช้คือ **"securing the agentic enterprise"** — ไม่ใช่ "AI security tool" — สื่อว่า CrowdStrike ตั้งใจ position ตัวเองเป็น **security substrate ที่ enterprise agent ต้องเดินผ่าน** ไม่ใช่ product line เสริม

Program แบ่งเป็น 4 partner pathway ที่ชัดเจน. **Resell** ผ่าน **CrowdStrike Falcon Flex** — partner ขาย AI-powered security แบบ consumption-based เข้าคู่กับที่ enterprise กำลัง shift budget จาก perpetual license มา consumption. **Manage** — managed service provider ให้บริการ deploy + scale CrowdStrike AI ที่ endpoint + cloud + identity workload. **Build** — ISV + system integrator พัฒนา AI-powered agent เข้ากับ **Charlotte AI AgentWorks + Falcon Foundry** และ publish ผ่าน CrowdStrike Marketplace. **Deliver** — partner ทำ implementation + training + support

จุดที่สำคัญที่สุดคือ **Verified Agent certification**. CrowdStrike ตั้งเป็น **สัญลักษณ์ที่บอก CISO ว่า agent ตัวนี้ผ่าน security review ของ CrowdStrike แล้ว — ไม่ต้อง bespoke evaluation อีกรอบ**. Verified Agent เข้ามาช่วยตัดขั้นตอนที่ enterprise บ่นเยอะที่สุดคือ **"agent จาก vendor A vs B ปลอดภัยเท่ากันไหม?"** ต่อไปคำตอบคือ "check Verified Agent status ใน Falcon Marketplace"

Positioning นี้เชื่อมกับ **CrowdStrike + OpenAI expanded partnership** ที่ประกาศเมื่อกลางปี — Charlotte AI Agents ใช้ OpenAI models เป็นตัวเลือก, ตอนนี้ Charlotte AI AgentWorks เปิดให้ partner build agent ที่ integrated กับ Falcon telemetry. **CrowdStrike ตั้งเป้าเป็น "gate keeper" ของ agent ที่ deploy บน endpoint**, พร้อม Falcon Marketplace เป็นช่องทาง distribution

## ทำไมสำคัญ

สัปดาห์นี้ (31 ส.ค. → 3 ก.ย.) มี 3 announcement ที่พูดเรื่องเดียวกัน — **Verified Agent (CrowdStrike) + AgentMinder deny-by-default runtime (Broadcom) + CyberAgents Exchange Inspector (Tenable) + Proofpoint SOC Analyst Agent**. หมายความว่า **agent governance category ตกผลึกใน 7 วัน**. ไม่ใช่ emerging space อีกแล้ว — CISO ที่ evaluate agent stack ใน Q4 2026 จะเจอ 3 competitor vendor ที่ pitch ทาบซ้อนกัน: pre-deploy inspection (Tenable), runtime containment (Broadcom), verified marketplace (CrowdStrike), และ SOC investigation agent (Proofpoint)

**Bet ที่สำคัญ**: ภายใน 90 วัน จะเห็น **partner cross-listing** — partner คนเดียวได้ทั้ง Verified Agent (CrowdStrike) + inspected ที่ Tenable Exchange + policy-compliant ที่ Broadcom AgentMinder. เป็น multi-badge trend เดียวกับที่เกิดใน Kubernetes ecosystem ปี 2019-2020 (CNCF certified). enterprise buyer จะดูมัลติแบดจ์เป็น "safe-to-deploy checkbox" ก่อน trial

จุดที่ CrowdStrike ได้เปรียบคือ **installed base**. Falcon platform อยู่ในองค์กร Fortune 500 กว่า 60% แล้ว — agent ที่ผ่าน Verified Agent = distributed ทันทีถึงลูกค้าที่ subscribe Falcon Flex. ต่างจาก Broadcom (VMware base ที่ shrink) และ Tenable (Vulnerability Management installed base เล็กกว่า). ในสงคราม "gate keeper สำหรับ agent" **installed base = distribution advantage** — CrowdStrike น่าจะได้ market share ใหญ่กว่า Tenable ในการเป็น certification issuer

Cisco/Splunk เงียบเรื่องนี้จนน่าประหลาด — ทั้งที่ Splunk + Duo + Talos น่าจะเป็น natural home สำหรับ "Verified Agent" equivalent. bet ผมคือ Cisco จะ launch ที่ Cisco Live EMEA (ต.ค. 2026) หรือ Splunk .conf26 (ต.ค. 2026) เพื่อไม่ตกขบวน — และคำที่ Cisco จะเลือกน่าจะเป็น **"Trusted Agent"** (differentiate จาก Verified) หรือ **"Signed Agent"** (technical framing)

## มุม AI Agent Platform

**Builders**: ถ้าคุณสร้าง agent สำหรับ enterprise, สัปดาห์นี้ ceiling ของ RFP ถูกยกใหม่ — ไม่ใช่แค่ "MCP-compatible" อีกแล้ว, ต้องพร้อม submit ให้ **Verified Agent (CrowdStrike) + Exchange Inspector (Tenable)** อย่างน้อย 1 ใน 2 program ภายใน Q4. เตรียม documentation: threat model, data flow, credential handling, prompt injection test results, output policy. Investment ~2-4 sprint แต่ payback = ตกจาก shortlist ไม่ได้อีก

**Users / business**: enterprise ที่กำลัง evaluate agent, ตั้ง procurement policy ใหม่ว่า **"agent ที่ deploy บน endpoint ต้องมี Verified Agent (CrowdStrike) หรือ equivalent"**; agent ที่ไม่ผ่าน ต้อง justify + wrap ใน isolated runtime (Tanzu/AgentMinder). ผลตรง: **time-to-deploy ยาวขึ้น 30-60 วัน** แต่ risk exposure ต่ำลง — trade-off ที่ regulated industry ยอมได้

**Ecosystem**: **agent registry ecosystem จะแตกเป็น 3 layer** — (1) discovery layer (Anthropic MCP Registry, GitHub, Bedrock Marketplace) → (2) inspection layer (Tenable Exchange, third-party audit) → (3) certification layer (CrowdStrike Verified Agent, Broadcom Tanzu-signed, Microsoft Defender AI-verified). ใครเป็น builder ต้อง submit ให้ทั้ง 3 layer; ใครเป็น buyer จะดู layer 3 เป็น gate
