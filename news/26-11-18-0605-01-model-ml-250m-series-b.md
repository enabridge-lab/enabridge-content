# Model ML ได้ $250M ที่ $1.5B — agent สำหรับ banker ขึ้น unicorn ใน 18 เดือน หลังออกจาก stealth

## TL;DR
- Model ML ปิด Series B $250M นำโดย General Atlantic + QED Investors ที่ valuation $1.5B — รวมเงินระดมแล้ว $350M, ขึ้น unicorn ใน 18 เดือนหลังออกจาก stealth
- Agent รุ่นนี้เจาะ workflow investment banking และ consulting ตรง — สร้าง financial model, pitch deck, DD report ต่อตรงกับ Excel/PowerPoint ของลูกค้า
- จุดต่างคือ model-routing: ไม่ผูกกับ frontier model เดี่ยว ๆ แต่เลือก model per task ตาม quality/latency/cost — บริษัทอ้างว่า operating cost เหลือ ~2% ของการใช้ frontier อย่างเดียว

## เกิดอะไรขึ้น
วันที่ 17 พฤศจิกายน สองพี่น้อง Chaz กับ Arnie Englander ประกาศว่า Model ML — สตาร์ตอัปลอนดอนที่สร้าง personal agent สำหรับ banker, consultant กับ investor — ปิด Series B $250M ที่ valuation $1.5B รอบนี้นำโดย General Atlantic กับ QED Investors ซึ่งเป็น backers เดิมที่ลงใน Series A $75M เมื่อปลายปี 2025 รวมเงินระดมทุนทั้งหมดอยู่ที่ $350M แล้ว และนับเป็น unicorn ตัวใหม่ของวงการ AI agent สำหรับ financial services

สิ่งที่ Model ML ขายไม่ใช่ chatbot หรือ copilot ทั่วไป — มันเป็น agent ที่เสียบตรงเข้ากับ system ของลูกค้า แล้ว execute งานที่ banker junior ใช้เวลาเป็นคืน ๆ: สร้าง financial model ใน Excel, ประกอบ pitch deck ใน PowerPoint, เขียน due diligence report จาก data room บริษัทนำเสนอว่า agent ของตัวเองไม่ได้เก่งกว่า Claude หรือ GPT ที่ไหนเป็นพิเศษ — แต่เก่งกว่าในแง่ที่ route งานแต่ละ sub-task ไปหา model ที่ cost ถูกที่สุดโดยคุณภาพยังผ่าน benchmark ทำให้ operating cost เหลือประมาณ 2% ของการเรียก frontier model ล้วน ๆ (ตัวเลขนี้เป็นของบริษัทเอง ยังไม่มี third party verify)

Englander บอกว่าเงินรอบนี้ไปที่สองก้อน engineering กับ deployment ลูกค้าในเวลาเดียวกัน — เหตุผลคือ sales cycle ของ banker ยังยาวกว่า SaaS ทั่วไป ต้องมี forward-deployed engineer ช่วย customize ให้แต่ละ desk บริษัทไม่เปิดเผยจำนวน ARR หรือรายชื่อลูกค้าชัด ๆ แต่ General Atlantic มีประวัติลงเฉพาะทีมที่มี revenue จริงระดับ 8-figure ขึ้นไปในรอบที่ลง

## ทำไมสำคัญ
ตลาด agent สำหรับ financial services เป็นหนึ่งใน vertical ไม่กี่ตัวที่ willingness-to-pay สูงพอจะคุ้มค่า token — banker junior ที่ Goldman หรือ JPM มี fully-loaded cost เกือบ $300K/ปี การลด cycle time ของงานหนึ่งจาก 8 ชั่วโมงเหลือ 30 นาที คือ ROI ที่ CFO ไม่ต้องถาม Model ML ไม่ใช่รายแรก — Rogo, Hebbia, Linq Alpha ลงสนามก่อน — แต่เป็นรายแรกที่ได้ valuation $1.5B ที่ Series B ซึ่ง sign ว่า tier-1 investor เชื่อว่า banker agent ไม่ใช่ wrapper บน OpenAI แล้ว แต่เป็น category ของตัวเอง

สิ่งที่น่าจับตาคือ model-routing strategy — ถ้าตัวเลข 2% ของ cost เป็นจริง (หรือแม้แค่ 10%) เส้นทางนี้จะกลายเป็น default สำหรับ vertical agent ที่ volume สูง ความได้เปรียบไม่ได้อยู่ที่ model แต่อยู่ที่ orchestration layer ที่รู้ว่า task ไหนต้อง Opus 4.7, task ไหน Haiku 5.5, task ไหนเรียก open-source model local พอ — ซึ่งเป็น insight ที่ท้าทาย narrative "frontier model จะเจ้าของ end-user" ของ OpenAI กับ Anthropic โดยตรง

## มุม AI Agent Platform
สำหรับ **Builders** — Model ML เป็น proof ว่า vertical agent ที่ลึกถึง workflow จริงของ user ยังมีช่องให้ไปต่อ แม้ frontier lab จะปล่อย general agent เพิ่มทุกไตรมาส key moat ไม่ใช่ model แต่เป็น integration ลึกกับ Excel/PPT กับ data room และ routing layer ที่เลือก model ถูก task สำหรับคนสร้าง platform นี่คือ signal ให้คิดเรื่อง "model portfolio" เป็น feature ไม่ใช่ wrapper

สำหรับ **Users / business** ที่ deploy agent — การที่ GA + QED ลงเงินใหญ่กับ vertical agent ที่คิด per-seat (ไม่ใช่ per-action) sign ว่า enterprise พร้อมจ่าย fixed price สำหรับ agent ที่ทำงานซ้ำ ๆ ของมืออาชีพระดับสูง การประเมิน vendor agent ต่อจากนี้ ควรถามให้ชัดว่า cost structure ของเขา resilient กับการขึ้น token price ของ frontier lab แค่ไหน — ถ้า dependency 100% กับ GPT-5 หรือ Claude 5.5 margin ของ vendor คือ margin ของคนขาย API เท่านั้น
