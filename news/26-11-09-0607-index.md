## Pattern ประจำสัปดาห์

**Sovereign + enterprise + agent = deal pattern ใหม่** — ADNOC x OpenAI x G42 ยืนยัน model vendor ยอมแยก compute แลกกับ national-scale enterprise deal Stargate UAE ไม่ใช่ outlier; เป็น template ของ 2027-28

**Vertical beats horizontal (ระยะสั้น)** — Traversal ORCA-bench ที่ frontier agent ทำได้แค่ 25% ชี้ว่า general coding agent ยังไม่พอ vertical agent (SRE, legal, security, sales) จะเก็บ market แยกจาก horizontal foundation ภายใน 12-18 เดือน

**Async + memory = agent จริง** — Snowflake, Claude Code, Cognition Devin, OpenAI Operator ไปทางเดียวกัน long-running + resumable + stateful กลายเป็น table stake เลิก request-response stateless

**MCP เป็น commerce protocol** — Walmart commit MCP ใน customer-facing gateway บอก MCP โตจาก dev tool เป็น default protocol ของ enterprise + commerce ถ้าคุณสร้าง agent หรือ merchant ไม่รู้ MCP = ตกยุค
