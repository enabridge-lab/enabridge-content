### 03 — Anthropic เปิดซอร์ส sandbox-runtime — MCP server sandboxing โดยไม่ต้องมี container
**[26-10-25-0605-03-anthropic-sandbox-runtime-opensource.md](./26-10-25-0605-03-anthropic-sandbox-runtime-opensource.md)**
24 ต.ค. Anthropic เปิดซอร์ส sandbox-runtime (srt) ที่อยู่หลัง Claude Code — tool สำหรับ OS-level sandbox arbitrary process ภายใต้ Apache 2.0, npm package `@anthropic-ai/sandbox-runtime` v0.0.81. ใช้ Seatbelt บน macOS, bubblewrap บน Linux, Windows alpha; policy YAML/JSON compile เป็น native profile — ไม่ต้องสร้าง container หรือ VM. จุดสำคัญคือ "drop-in sandboxing of MCP servers" ซึ่งก่อนหน้านี้ไม่มี isolation layer ที่น่าเชื่อ — Fortune 500 CISO เกินครึ่งปฏิเสธ MCP server ของ internal engineer. Signal: sandbox-safe agent runtime คือ prerequisite ใหม่, Anthropic สะสม primitive portfolio ก่อน IPO กลาง พ.ย.
