# Shackleton AI โผล่จาก stealth $5M — operator-founder ที่ทำ $35M revenue มาก่อน ขาย "agentic OS" ให้วงการก่อสร้าง

## TL;DR
- Shackleton AI ปิด seed $5M นำโดย Battery Ventures (Brick & Mortar + Trust Ventures ร่วมด้วย) — เปิด stealth 4 พฤศจิกายน
- 3 founder (Ragheb, Yasin, Kaltsev) build platform ใน contracting business ของตัวเอง "Ernest" จนโต $35M revenue และบริหาร project value รวมกว่า $1B ใน 15 รัฐ
- เสนอตัวเป็น "operating system" ที่รวม development + construction management + agent automation แทน point tool แบบเดิม

## เกิดอะไรขึ้น
วันที่ 4 พฤศจิกายน Shackleton AI เปิด stealth พร้อม seed round $5M นำโดย Battery Ventures Michael Brown, GP ของ Battery, บอกว่าเหตุผลที่ลงทุนคือ operator experience กับ bet ว่า "project management ที่ตัวเองเป็น agent" จะชนะ SaaS ที่ human ต้องกรอกเอง

เรื่องที่น่าสนใจกว่าตัวเลข funding คือ origin story: 3 founder — Michael Ragheb, Hassan Yasin, Olexandr Kaltsev — ไม่ได้มาจาก big tech แล้วเดา construction workflow แต่ build platform ตัวนี้ขึ้นมาใน contracting business ของตัวเอง "Ernest" ซึ่งโตถึง $35M revenue และบริหาร project value รวมกว่า $1B ใน 15 รัฐ (ตัวเลข $1B นี้มาจาก source เดียว — บริษัทรายงานเอง ยังไม่ 3rd party verify) หลังจาก run เอง 2-3 ปีเห็นว่า agent ที่ handle RFI (Request for Information), change order, submittal, daily log ฯลฯ แบบอัตโนมัติประหยัดเวลา PM 15-20 ชั่วโมงต่อสัปดาห์ — ก็ spin off เป็น product company

Product play คือรวม 3 layer: (1) development management — track permit, zoning, financing milestone, (2) construction management — schedule, RFI, submittal, inspection, (3) agent layer ที่ "do" ไม่ใช่แค่ track — agent ส่ง RFI ให้ architect เอง, approve change order ที่อยู่ในกรอบ, generate daily report จาก field photo + sensor ตัว scope นี้กินทั้ง Procore (construction management), PlanGrid (field collab), และ CoConstruct (residential) ที่ปัจจุบันเป็น 3 tool แยกกัน

## ทำไมสำคัญ
Pattern ที่ repeat ชัดในปี 2026 — vertical agent startup ที่ founder มาจาก industry เอง และ build product ภายในธุรกิจตัวเองก่อน spin off กำลัง raise ที่ valuation สูงกว่า pure tech startup ที่ดูอยู่ข้างนอก Rebar (HVAC agent, $14M Series A) และ Cresta (contact center, scale-up ล่าสุด) เดินสคริปต์เดียวกัน — ของจริงคือ **operator moat** ก่อน code moat

Construction เป็น $2 trillion industry ใน US ที่ productivity คงที่มา 50 ปี — McKinsey วัดได้ว่า sector ยังไม่ได้ digitize จริงจัง (ต่างจาก manufacturing) ส่วนหนึ่งเพราะ workflow ขึ้นกับ paper, phone, field decision ที่ SaaS รุ่นก่อนจับได้ไม่หมด — agent ที่ "see" (OCR invoice, parse drawing, understand photo) + "do" (ส่ง email, update CRM, trigger payment) ตัดตรงช่องนั้นได้ ถ้า Shackleton proof point ใน Ernest replicate ได้กับ customer ภายนอกก็เป็น template สำหรับ vertical agent play ใน trade อื่น (plumbing, electrical, HVAC sub)

Caveat: seed $5M เล็กเกินกว่าจะ scale GTM กว้าง — น่าจะต้อง Series A ภายใน 12-18 เดือน ถ้า revenue outside-Ernest ไม่โตเร็ว round นี้จะยาก และ moat ของ "operator ที่ทำ $35M revenue" ป้องกัน competitor ได้ไม่กี่ปี เมื่อ Procore ออก agent layer ของตัวเอง (ซึ่งน่าจะมี) และราคา enterprise lower

## มุม AI Agent Platform
**Builders** — สคริปต์ "operator ที่ build product ให้ตัวเองก่อน spin off" กลายเป็น default playbook สำหรับ vertical agent startup — ถ้าคุณไม่ได้มาจาก industry ที่กำลัง build ให้ แต่คือ outsider ที่ตั้งสมมติฐาน workflow ด้วย founder-friend ใน Zoom โอกาสระดม Series A ตก มีนัยด้วยกับ Enabridge: การทำ pilot กับลูกค้าใน vertical ก่อน productize ตัว pattern ก็ตัดลูป risk แบบเดียวกัน

**Users / business** — ธุรกิจก่อสร้างไทย (ผู้รับเหมาใหญ่, developer condo, EPC) ควรเริ่ม evaluate agent layer บน workflow RFI/change order/submittal เพราะ overhead ต่อ project 5-8% ของต้นทุนรวมเป็น admin overhead ซึ่ง agent แก้ตรง ๆ Shackleton อาจยังไม่พร้อม Southeast Asia — แต่ pattern เอามา build local version ได้ ถ้า team มี operator experience จริง

**Ecosystem** — Procore (publicly listed, ~$10B market cap), Autodesk (construction cloud), Oracle Textura — ต้องเลือกว่า build agent layer เอง หรือ acquire startup อย่าง Shackleton ก่อน valuation ชนเพดาน — 12-18 เดือนข้างหน้าน่าจะเห็น M&A activity ในวงการนี้เยอะขึ้น
