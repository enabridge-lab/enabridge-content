## 🧭 มุมมองของรอบ

เมื่อวาน (Claude Dashboards + Motion, SAP Autonomous Enterprise, Restate, Ironclad, Kore.ai) ชี้ **4 primitive ใหม่ของ enterprise agent**: data surface + execution runtime + domain knowledge graph + continuous evaluation.

วันนี้ชี้ชัดกว่าว่า **"AI Agent Platform" ปี 2026 Q4 ไม่ใช่ 1 ชั้นแล้ว** — เป็น **5-layer stack** ที่ enterprise ต้องเดินทาง procurement แยกกัน:

1. **Identity** (Baselayer / Cyera-Oasis) — ใครเป็น agent, ขอ resource อะไรได้บ้าง
2. **Runtime security** (Rein / Lasso / Prompt Security) — block action ก่อน execute
3. **Self-improve loop** (DigitalOcean / AWS Bedrock Observability) — Insights → Signals → Eval → Rollback
4. **Orchestration + routing** (Google Gemini Agent / Portkey / TrueFoundry) — เลือก backbone, assign sub-task, maintain persistent identity
5. **Governance + inventory** (Dataiku / Collibra / Credo AI) — รายการ agent cross-platform, risk classification, evidence trail

Vendor ที่มี **1 ใน 5 primitive** = หลุด enterprise RFP ใน 24 เดือน. Vendor ที่มี **2+ primitive คู่กัน** = M&A target ของ hyperscaler ภายใน 18 เดือน. **Builder** ที่สร้าง agent ให้ลูกค้า — ต้อง integrate กับ 5 layer นี้แบบ "assume will exist" ไม่ใช่ "optional add-on" — ไม่งั้น enterprise customer จะ reject ตอน security review

**Open-source angle:** Nous Hermes ที่ ARR $36M ชี้ว่า **closed-source model vendor ไม่มี pricing power แบบ unlimited** อีกต่อไป. CFO ที่ sign ChatGPT Enterprise + Claude for Enterprise ภายใน 6 เดือน — ขอ POC Hermes คู่กันเพื่อ hedge. **70% workflow coverage ที่ 10x cheaper = negotiation power ใหม่**.
