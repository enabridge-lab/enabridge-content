# Omnichat เปิด Agentic AI Platform + ตั้งเป้า Series A+ $10M — APAC agent play ที่ Thai founder ควรจับตา

## TL;DR
- **Omnichat** (HQ ฮ่องกง, agentic CX platform สำหรับ APAC) เปิด **"Omni AI Agents"** platform เมื่อ 27 ต.ค. 2026 + ตั้งเป้า **Series A+ $10M** เพื่อ expand ไป **Japan + Korea + Australia**
- **Traction:** revenue โต **8x ใน 3 ปี**, ARR ปัจจุบัน **>$10M**, backer ปัจจุบัน: AppWorks, 91APP, Palm Drive Capital, Cornerstone Ventures, AVA Angels
- **Product:** 3 agent core — **AI Customer Service Agent** (24/7 support), **AI Copilot Agent** (marketing campaign ops), **AI Sales Agent** — ครอบ WhatsApp, LINE, Messenger, Instagram, WeChat, SMS, email, voice ในแพลตฟอร์มเดียว
- Signal: **APAC-regional agentic CX player** กำลังก่อตัว — Decagon ($250M Series D, US-centric) + Sierra (US enterprise) + Omnichat (APAC omnichannel) = category แยกตามภูมิภาค; Thai founder/VC ยังไม่มี equivalent ที่ชัด

## เกิดอะไรขึ้น

27 ตุลาคม 2026, **Omnichat** (HQ ฮ่องกง, ก่อตั้ง 2017) ประกาศเปิด **Omni AI Agents** — agentic CX platform ที่ครอบ 3 agent core สำหรับงาน retail/e-commerce ของแบรนด์ APAC พร้อมตั้งเป้าปิด **Series A+ $10M** ภายในสิ้นปี เพื่อ (ก) deepen R&D ของ Omni AI Agents, (ข) ขยายไป Japan + Korea + Australia, (ค) build go-to-market team ใหม่ในตลาดเหล่านั้น

**Business number ที่เปิดเผย:**
- **Revenue 8x ใน 3 ปี** (เทียบ Shopify stage 2016-2019 ที่ 5-6x)
- **ARR >$10M** ปัจจุบัน (ไม่เปิดเลขละเอียด)
- **Backer:** AppWorks (Taiwan accelerator+VC ที่ลง SE Asia 100+ บริษัท), 91APP (Taiwan e-commerce SaaS listed), Palm Drive Capital, Cornerstone Ventures, AVA Angels
- **Previous round:** Series A June 2025 (ไม่เปิดเลข)

**Product scope:** Omni AI Agents ครอบ 3 agent class:
1. **AI Customer Service Agent** — 24/7 ตอบลูกค้า, resolve FAQ, escalate ไปหาคน, ครอบ WhatsApp + LINE + Messenger + Instagram + WeChat + SMS + email + voice
2. **AI Copilot Agent** — ช่วย marketer launch campaign, segment audience, A/B test creative, measure ROI
3. **AI Sales Agent** — qualify lead, book meeting, close deal บน conversational channel

Positioning ที่ชัด: **"omnichannel-first + conversational-first + APAC-first"** — ไม่ใช่ US SaaS ที่พยายามเจาะ APAC. Omnichat เน้นว่า **LINE + WeChat + WhatsApp** คือ primary channel ของผู้บริโภค APAC (ไม่ใช่ email + web chat แบบ US) ซึ่ง US-origin agent platform (Intercom, Zendesk, Sierra) **ไม่ได้ optimize สำหรับ chat-first APAC behavior**

Named customer base ยังไม่เปิดเต็ม แต่ Omnichat บอกว่าครอบ enterprise retail/beauty/fashion brand ใน Hong Kong + Taiwan + Singapore + Malaysia + Thailand รวมหลายร้อยราย (Pandora, Clarins, Fairtex, Watsons, 7-Eleven HK เคยอยู่ใน case study ปีก่อน)

## ทำไมสำคัญ

ประเด็นที่หนึ่ง — **"Agentic CX platform ของ APAC" คือ category ที่ยังไม่มี category leader ชัด**. Decagon ($1.5B valuation, $250M Series D ม.ค. 2026) เป็น US enterprise; Sierra ($4.5B valuation, Bret Taylor) เป็น US enterprise + voice; Chatfuel + ManyChat ครอบ SMB global แต่ไม่ agentic เต็มที่. APAC middle (Hong Kong, Taiwan, Singapore, Thailand, Malaysia, Indonesia, Vietnam) มี 650M consumer + 20M SMB — TAM ใหญ่พอให้มี regional player ขนาด $500M-1B valuation ได้ง่าย. Omnichat 8x growth + $10M ARR = วางตำแหน่งที่ **Series B $15-20M ปี 2027 เป็นไปได้**

ประเด็นที่สอง — **Omni-channel ของ APAC ต่างจาก US มาก**. US: email + web chat + SMS. APAC: LINE (JP+TW+TH), WeChat (CN+HK+SG), WhatsApp (SG+MY+ID+PH), KakaoTalk (KR), Zalo (VN), Facebook Messenger (ทั่ว SEA). แต่ละ channel มี **API semantics, rate limit, template format, และ compliance requirement** ของตัวเอง. US agent platform ที่ขยายมา APAC มักจะใช้เวลา 18-24 เดือนเพื่อ reach feature parity กับ regional incumbent. Omnichat ที่ก่อสร้างจากฝั่ง APAC = **9+ ปี of channel-specific optimization** ไม่ใช่ชั้นที่ Decagon/Sierra copy ได้ง่าย

ประเด็นที่สาม — **Thai VC ยังไม่มี agentic CX thesis**. SCB10X portfolio เน้น crypto/web3 + developer tool, Krungsri Finnovate เน้น fintech, True Digital Fund เน้น media/content, 500 TukTuks เน้น SE Asia generalist. ไม่มี Thai VC ที่ปัจจุบันถือ agentic CX startup ที่ scale regional — ช่องว่าง opportunity ใหญ่. Thai founder ที่กำลัง build conversational-AI startup ควรดู Omnichat trajectory และ **go-regional ตั้งแต่ seed stage** (ไม่ใช่ "Thailand first then expand") เพราะ TAM ไทยเดี่ยว ไม่พอ build $100M+ company

## มุม AI Agent Platform

สำหรับ **Builders**: ถ้า build conversational agent สำหรับ APAC, โฟกัสที่ **"channel-specific LLM fine-tune"** = moat. LINE sticker response ต่างจาก WhatsApp emoji response ต่างจาก WeChat voice message. US-origin agent framework (LangChain, CrewAI) ไม่ได้ model สิ่งเหล่านี้ — ต้อง build adapter + fine-tune ของตัวเอง. Framework ไทยที่กำลังเกิด (Enabridge, Pathumwan, บริษัทไทยอื่น ๆ) ควร positioning เป็น **"APAC agent framework"** ไม่ใช่ "AI chatbot builder"

สำหรับ **Users / Business**: Thai brand ที่มี LINE OA + Facebook + Instagram + ขายข้าม e-commerce หลาย platform (Lazada, Shopee, TikTok Shop) ควร **evaluate agentic CX platform** ภายใน Q1 2027. Vendor comparison: (ก) Omnichat (HQ HK, ครอบไทย), (ข) Yellow.ai (HQ Bangalore, มีลูกค้าไทย), (ค) ChocoCRM/Choco Group (HQ ไทย, ครอบ SMB), (ง) Build in-house (ไม่แนะนำเว้นเทีมมี 10+ ML engineer). ตัวเลขที่ควรขอ: cost per resolved ticket, deflection rate, upsell conversion rate — ไม่ใช่แค่ "AI percent"

สำหรับ **Ecosystem**: Omnichat Series A+ $10M เป็น proof ว่า **APAC Series A agentic startup สามารถระดมเงินได้จาก regional investor** (ไม่ต้องรอ US VC). Pattern ที่ Thai founder ควรเรียนรู้: (ก) AppWorks (Taiwan) ลง Pre-A/Series A, (ข) 91APP (Taiwan listed) เป็น strategic investor ที่ให้ distribution, (ค) Palm Drive + Cornerstone (US Asia-focused) ลง growth, (ง) AVA Angels (angel network APAC) ลง seed. Thai founder ที่ตอนนี้ pitch SCB10X/Krungsri Finnovate แล้วไม่ติด = ลอง Taiwan + Hong Kong + Singapore ก่อนไป SF
