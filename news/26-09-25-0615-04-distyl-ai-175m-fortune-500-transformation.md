# Distyl AI ระดม $175M Series B — valuation $1.8B ขึ้น 9x ใน 22 เดือน; Palantir alumni รีดราคา AI transformation ให้ Fortune 500

## TL;DR
- **23 ก.ย. — Distyl AI ระดม $175M Series B** — นำโดย **Lightspeed + Khosla**, Coatue + DST Global + Dell Technologies Capital ร่วม — valuation **$1.8B** = **9x** จาก Series A ($200M valuation, พ.ย. 2024)
- **Founder: Arjun Prakash + Derek Ho — Palantir alumni** — สาย forward-deployed engineer ที่รู้ playbook "เอา engineer เข้าไปนั่งกับ CIO ใน Fortune 500 → ผ่านช่วง pilot → ยึด workflow"
- **Signal:** VC ประเมิน **AI transformation consultancy = SaaS-multiple** (9x ใน 22 เดือน) = ตลาด service ที่ Accenture/Deloitte/BCG ถือ = โดน re-priced ต่อสาธารณะ; Enabridge platform ที่แข่งใน "governed agent for Fortune 500" ต้อง reposition ใน 6 เดือน

## เกิดอะไรขึ้น

23 กันยายน 2026 — Distyl AI ประกาศ **Series B $175M** ที่ **valuation $1.8B** — round นำโดย **Lightspeed Venture Partners + Khosla Ventures** และ syndicate อีกชั้น: **Coatue, DST Global, Dell Technologies Capital**. รวมทุนตั้งบริษัทตั้งแต่ปี 2022 = **>$200M**

Founder-team คือ **Arjun Prakash + Derek Ho** — ทั้งคู่มาจาก Palantir. ที่ Palantir ทั้งคู่รัน forward-deployed engineering — playbook คือ ส่ง engineer เข้าไปนั่งกับ customer, สร้าง solution เฉพาะ workflow, และ **ยึด mission-critical process** จน customer ยกเลิกไม่ได้. Distyl ยก playbook นี้มาทำใน context AI — pitch คือ ช่วย Fortune 500 กลายเป็น **"AI-native enterprise"** โดย Distyl ส่งคนเข้าไป custom-build agent stack ให้ customer แต่ละราย ไม่ใช่ SaaS สำเร็จรูป

Sector ที่ Distyl claim ทำอยู่แล้ว: **healthcare, telecommunications, insurance, manufacturing, financial services** = pattern ตรงกับที่ Palantir ทำ 15 ปีที่แล้ว. Fenwick (law firm ที่ represent Distyl ใน deal) เปิดเผยว่า deal ปิดเร็ว = signal ว่า Lightspeed + Khosla มองเห็น traction ที่ shortlist บริษัทมี ARR run rate จริงและ retention สูง (Lightspeed rarely put $50M+ ในบริษัทที่ retention ต่ำกว่า 120% net)

Valuation math ที่น่าจับตา: จาก **$200M Series A (พ.ย. 2024)** → **$1.8B Series B (ก.ย. 2026)** = **9x ใน 22 เดือน** ในตลาดที่ VC ยังบ่นว่า late-stage compress เพราะเงินหายาก = **exception ไม่ใช่ rule** = ตัวเลข underlying ต้องแรง

## ทำไมสำคัญ

Distyl round นี้เป็นตัวชี้ **thesis สำคัญที่ VC เดิมพันกันอยู่ในตอนนี้**: **service layer สำหรับ AI transformation ที่ Fortune 500** เป็น **software-margin business** ไม่ใช่ consulting-margin. เดิม Accenture + Deloitte + IBM Consulting + BCG ครองตลาด transformation ที่ ~$300B/ปี ด้วย gross margin 25-30% (ต้องจ่ายค่า consultant). Distyl (+ Palantir + Anthropic professional services + สิ่งที่ SapiensAIP เมื่อวัน 23 ก.ย. ทำ) พยายามพิสูจน์ว่าถ้า agent stack ทำ 70% ของงาน → engineer 10 คนบวก agent = ให้ผลลัพธ์เท่า consultant 100 คน = gross margin ขึ้นเป็น 60-70% แบบ SaaS

ประกอบกับที่ Bain Capital Ventures ปล่อย **"Life After AGI" fund $1.6B** เมื่อวัน 22 ก.ย. ที่ pivot thesis จาก foundation model → application/vertical layer, และ **Ema ระดม $77M ที่ยืนยัน AI Employee deployment scale** — pattern ที่ตลาดกำลังเลือกคือ: **foundation model layer = commoditize, application/service/platform layer = พรีเมี่ยม**

Palantir alumni network เป็น talent pool ที่ VC follow ทั้งหมด — ทั้งคู่ Alex Karp / Peter Thiel network + forward-deployed engineer playbook = product-market fit ในตลาด enterprise ที่ Big Tech แตะยาก (defense, healthcare, insurance ที่ compliance หนัก). Distyl เป็นเจน 3 ของ Palantir spin-out = signal ว่า playbook นี้กำลัง franchise

## มุม AI Agent Platform

**Builders** — Distyl ไม่ได้ขาย agent framework แต่ **ขาย custom deployment**; builder ที่มี framework/SDK ต้อง partner กับ Distyl-class บริษัท (หรือ Fortune 500 ตัวจริง) เพื่อ distribution — ขายตรงยาก. **Users/business** — CIO Fortune 500 ที่ได้ Distyl-class engagement จะ **compress timeline transformation จาก 3 ปีเหลือ 12-18 เดือน**; แต่ **cost per project จะสูง** (ประเมิน $5-15M ต่อ deployment) — เหมาะเฉพาะ mission-critical process. **Ecosystem** — Enabridge platform ที่ position เป็น "governed agent orchestration for enterprise" **มี window แข่ง** เพราะ Distyl model คือ **bespoke, ไม่ scalable ต่ำกว่า Fortune 500** = ตลาด mid-market ($100M-$5B revenue) ยังว่างมาก; ถ้า Enabridge สร้าง productized version ของ Distyl playbook = ตลาดต่ำกว่านั้นเปิดกว้าง
